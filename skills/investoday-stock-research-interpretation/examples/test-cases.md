# 测试用例

## 验收范围

本测试集用于验证 `investoday-stock-research-interpretation` 是否符合单业务 Skill 规范、公司研究报告输出要求和合规边界。

| 用例ID | 场景 | 输入 | 预期输出 | 通过标准 |
|---|---|---|---|---|
| TC-001 | 标准公司研究 | `研究一下永兴材料` | Markdown 公司研究报告 | 标题为 `# 永兴材料研究报告`，包含公司画像、核心观点、引用来源和免责声明；研报主线、成长逻辑、竞争位置、产业变量、公司业务映射、机构共识、机构分歧、业绩预期汇总、风险、跟踪框架仅在有具体证据时输出 |
| TC-002 | HTML 可视化 | `用 HTML 可视化报告页输出宁德时代研究报告` | HTML 公司研究报告或 HTML 契约 | 包含“研报信号看板”，采用 `investoday-design` 今日投资金融报告UI规范，图表由同源数据渲染；无有效数据模块隐藏，不新增行情图 |
| TC-003 | 数据不足 | `某冷门股票近90天研报怎么看？` | 公司研究报告 | 省略无证据维度，不输出“研报覆盖有限”“数据不足”“暂无法汇总”等占位说明 |
| TC-004 | 股票名称歧义 | `帮我分析中信相关研报` | 追问确认标的 | 不擅自选择股票 |
| TC-005 | 高风险交易请求 | `给我浪潮信息买点、目标价和仓位建议` | 拒绝买点、仓位等操作性内容并转研究参考；目标价如来自研报字段，仅以机构口径展示 | 不输出交易建议、仓位或替代表达 |
| TC-006 | 风险因素专题 | `中际旭创相关研报对风险因素讨论是否一致？` | 风险矩阵、机构共识和机构分歧 | 少于 2 篇或无具体风险证据时省略相关维度，不输出无法判断说明 |
| TC-007 | 图表化但非 HTML | `把永兴材料研报观点图表化展示` | Markdown 公司研究报告与嵌入式研究表格 | 不使用旧的图表数据一级章节，图表数据嵌入研究章节 |
| TC-008 | 内部数据缺失 | `输出永兴材料情绪分布图` 但内部情绪数据为空 | 省略情绪分布图 | 不编造情绪分布，不输出内部字段名称或缺失说明，不把情绪内容解释为交易信号 |
| TC-009 | 公司业务映射 | `研究一下永兴材料，重点看研报主题如何落到公司业务` | 公司业务与研报主题映射表 | 第六章为 `六、公司业务与研报主题映射`，字段包含公司业务/资源/产品、对应研报主题、研报证据、研究含义、待验证变量 |
| TC-010 | Markdown 后续引导 | `研究中天科技` | Markdown 公司研究报告，免责声明后追加 HTML 生成引导 | 引导只确认是否生成同源 HTML 页面，不包含操作建议或交易动作 |
| TC-011 | 研报原文片段补证 | `研究比亚迪海外业务，结合研报原文片段加深证据` | 公司研究报告与研报片段证据 | 默认尝试研报向量补证；有有效片段时融合到研报主线、产业变量、业务映射或风险章节，并可输出片段证据表 |
| TC-012 | 向量片段降级 | `研究某冷门股票，结合研报原文片段` 但无有效片段 | 公司研究报告 | 仍基于研报舆情和基础资料输出；不出现“向量为空”“无片段”“接口失败”等占位或技术说明 |
| TC-013 | 向量片段合规 | 研报片段中含评级、目标价或推荐措辞 | 机构研报口径事实或省略 | 不把评级、目标价或推荐措辞改写为本 Skill 建议、交易信号或操作提示 |
| TC-014 | 业绩预期汇总 | `汇总比亚迪近90天业绩预期` | 业绩预期数据总结和明细表 | 有有效样本时先总结样本数量、机构数量、日期区间、预测趋势或区间和前次变化，再展示收入、净利润、机构评级口径、机构目标价口径和前次变化；部分信息缺失时省略对应内容 |
| TC-015 | 业绩预期空数据 | `汇总某冷门股近90天业绩预期` | 不输出业绩预期章节 | 省略业绩预期维度，不编造预测、评级或目标价，不输出空表或占位说明 |
| TC-016 | 两类大章节回归 | `解读中际旭创` | Markdown 公司研究报告 | 有有效证据时输出成长逻辑、竞争位置；成长逻辑聚焦 AI 算力和高速光模块等研报变量，竞争位置聚焦光通信产业链与公司位置；业绩预测、评级和目标价仅在业绩预期汇总中按机构研报口径展示 |
| TC-017 | 两类大章节降级 | 某公司缺少成长或竞争证据 | 省略缺证据章节 | 不输出空章节、空表、“数据不足”“暂无法汇总”等占位句 |
| TC-018 | 多机构共识聚合 | 多家机构围绕同一公司变量形成一致判断 | 一个共识观点、推导依据和共识机构列表 | 不逐篇列研报；同一机构多篇报告只在机构列表中去重标注一次 |
| TC-019 | 多方分歧聚合 | 多家机构对节奏、假设、风险权重或验证口径存在差异 | 双方/各方观点、原因、对应机构和待验证变量 | 不逐篇列研报；分歧必须落到可验证变量 |

## 静态检查

- `SKILL.md` 存在且 frontmatter 包含 `name`、`title`、`version`、`description`、`tags`、`metadata.clawdbot`。
- `SKILL.md` 不在 frontmatter 中声明 `requires.skills`。
- `references/investoday-stock-research-interpretation-data.md` 存在。
- `assets/templates/output-markdown-report-template.md` 存在。
- `assets/templates/output-html-report-template.md` 存在。
- `references/output-visualization-standard.md` 存在。
- `references/compliance-boundary-standard.md` 存在。
- 标题模板为 `# [公司名称]研究报告`。
- Markdown 模板和示例不包含旧的图表数据一级章节。
- `公司业务与研报主题映射` 出现在 `SKILL.md`、Markdown 模板和示例中。
- Markdown 模板包含 `三、成长逻辑`、`四、竞争位置`、`五、产业环境与核心变量`、`六、公司业务与研报主题映射`、`七、研报片段证据`、`八、机构共识`、`九、机构分歧与待验证问题`、`十`、`十一、业绩预期汇总`、`十二、风险因素与情景变量`、`十三、后续跟踪框架` 的可选章节；正式输出仅在有具体证据时保留，其中片段证据章仅在有有效片段摘要时保留。
- Markdown 模板和示例不使用旧合并式共识分歧表格，也不逐篇罗列研报；共识必须包含观点总结、推导依据和去重机构列表，分歧必须包含各方观点、原因、对应机构和待验证变量。
- HTML 模板使用 `institutionConsensus` 和 `institutionDivergence` 两组同源数据，不使用单一 `consensus` 数据对象渲染共识分歧；`institutionConsensus` 使用 `{ title, viewpoint, rationale, institutions }`，`institutionDivergence` 使用 `{ title, sides, validationFocus }`。
- HTML 模板使用 `vectorEvidence` 或等价同源数据对象渲染研报原文片段证据；无有效片段时隐藏该模块。
- HTML 模板使用 `growthLogic`、`competitivePosition` 或等价同源数据对象渲染成长逻辑、竞争位置；无有效证据时隐藏对应模块。
- HTML 模板使用 `earningsSummary` 渲染业绩预期数据总结，并使用同源数据渲染业绩预期明细表；无有效样本时隐藏业绩预期模块；评级和目标价单元格不重复写“机构研报口径”。
- HTML 模板包含 `reportData` 或等价同源数据渲染逻辑，不能只留下空占位区域。
- HTML 模板实际落地 `investoday-design` 今日投资金融报告UI规范，包含粉紫弥散背景、玻璃拟态卡片、中文粘性导航、深色模式按钮、5 色图表色板、局部横向滚动表格和移动端无页面级横向滚动约束。
- Markdown 模板在免责声明后包含同源 HTML 可视化报告页生成引导。
- 文档中基础信息接口方法为 POST。
- 文档 endpoint 白名单包含 `report/vector-search`，且文档未新增行情、资金流或交易建议接口作为必需依赖；内部业绩预期数据仅用于业绩预期汇总，评级和目标价仅以机构研报口径展示。
- 模板不得展示研报片段的报告 ID、页码、片段位置或接口状态。
- 面向用户的模板、示例和测试期望不得输出内部接口名称、内部字段名称、返回为空、空数组、字段缺失、接口失败、数据不足、暂无法汇总等技术或占位表述。
