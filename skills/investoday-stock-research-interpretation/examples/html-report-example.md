# HTML 报告示例

> 本文件说明 HTML 公司研究报告应包含的区块。示例内容为演示口径，不代表实时真实研报结论。正式 HTML 必须由真实 Markdown 公司研究报告同源生成。

## UI 规范

正式 HTML 必须实际采用 `investoday-design` 的“今日投资金融报告UI规范 / Investoday Premium Diffused”：粉紫弥散背景、玻璃拟态卡片、中文粘性导航、紫色强调系统、5 色图表色板、局部滚动表格、深色模式 token 和移动端无页面级横向滚动约束。不得只在说明文字中声明采用规范，也不得改成营销落地页、交易操作面板或其他 UI 风格。

## 页面区块

| 区块 | 内容 | 要求 |
|---|---|---|
| 首屏信息 | 公司名称、股票代码、主营业务摘要、分析日期、数据来源、时间范围、黄色提示卡 | 第一屏可见，紧凑报告标题卡，不使用营销 Hero |
| 核心观点 | 公司定位、研报主线、验证重点、风险边界 | 只保留有证据支撑的观点 |
| 公司画像 | 公司全称、上市板块、主营业务、基础资料日期 | 来源于公司基础资料 |
| 研报信号看板 | 时间线、主题热度、风险矩阵、机构共识卡片、机构分歧卡片、研报原文片段卡片 | 与 Markdown 研究内容同源，并由内联数据渲染 |
| 研究框架 | 成长逻辑、竞争位置 | 使用 `growthLogic`、`competitivePosition` 同源数据渲染；无有效证据时隐藏 |
| 公司业务映射 | 公司业务/资源/产品与研报主题关系 | 对应 Markdown 第六章 |
| 业绩预期汇总 | 业绩预期数据总结、机构、报告标题、收入预测、净利润预测、机构评级口径、机构目标价口径、前次变化说明 | 有真实预测样本时先总结再展示明细；评级和目标价只作为机构研报口径 |
| 研报证据表 | 日期、标题、关键事由、观点、风险 | 支持横向滚动 |
| 研报片段证据 | 片段主题、片段摘要、对应研究问题、可补强章节 | 有有效片段时展示；不展示报告 ID、页码或片段位置 |
| 引用来源 | 今日投资数据市场、研报标题和日期 | 不编造新闻或公告 |
| 免责声明 | 固定免责声明 | 不可省略 |

## 禁止内容

- 买入、卖出、仓位、交易时机、止盈止损，以及把评级、目标价或推荐文字表达为本报告建议。
- 目标价、评级、买入/推荐等若来自机构研报，只能在业绩预期表或证据表中作为机构研报口径展示。
- 价格走势、K 线、支撑压力位。
- “立即行动”“操作建议”等按钮或行动提示。
- 无真实数据时展示虚构图表。

## 图表渲染要求

- 正式 HTML 应把真实研报内容聚合为同源数据对象。
- 图表颜色必须使用 `investoday-design` 5 色图表色板；柱状/横向柱状图使用粉色权重阶，不随机配色；真实涨跌方向数字才使用 A 股涨红跌绿。
- 时间线、主题热度、成长逻辑、竞争位置、风险矩阵、机构共识卡片、机构分歧卡片和研报原文片段卡片必须有可见渲染结果；无有效数据时隐藏对应模块。
- 业绩预期模块必须先由 `earningsSummary` 渲染数据总结，再由同源业绩数据渲染明细表；无有效预测样本时隐藏对应模块，不展示空态文案。
- 表格必须放入 `.table-wrap`，移动端只允许表格容器横向滚动，页面本身不得横向滚动。
- 机构共识卡片使用 `{ title, viewpoint, rationale, institutions }` 聚合结构，展示观点总结、推导依据和去重机构列表。
- 机构分歧卡片使用 `{ title, sides, validationFocus }` 分组结构，展示各方观点、原因、对应机构和待验证变量。
- 图表只表达研报覆盖、主题、成长逻辑、竞争位置、研报原文片段摘要、风险、机构共识、机构分歧和业绩预期汇总，不表达交易信号。
