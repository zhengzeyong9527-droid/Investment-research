# Markdown 公司研究报告输出模板

本模板用于 `investoday-stock-research-interpretation` 的默认 Markdown 输出。正式报告必须基于真实获取的公司资料、研报内容与可用的业绩预期数据生成；缺少数据时省略对应维度，不得输出空表、空值说明、内部接口名称、内部字段名称、返回为空或“数据不足/暂无法汇总”等占位句式。

Markdown 报告以公司研究叙事为主，不使用独立的图表一级章节。需要图表化时，Markdown 仅保留研究表格，HTML 报告负责渲染可视化图表。

```markdown

> 分析日期：YYYY-MM-DD | 数据来源：今日投资 | 时间范围：近90天 | 研究定位：公司研究与信息整理

## 核心观点

- 公司定位：结合主营业务和研报主题，说明公司处于哪些产业链环节。
- 研报主线：概括近90天机构最集中讨论的 2-3 个变量。
- 成长逻辑：仅在有研报或基础资料证据时，概括增长来自需求、产品代际、客户结构、价格/结构升级或利润弹性中的哪些变量。
- 竞争位置：仅在有产业链、技术路线、客户认证、交付能力、规模或同业比较证据时，概括公司位置；不得编造排名。
- 片段补证：仅在有有效研报原文片段时，概括其补强的具体变量；无有效片段时不写该条。
- 业绩预期：仅在有有效机构预测样本时概括收入和净利润；评级和目标价如有返回，仅作为机构研报口径说明。无有效样本时不写该条。
- 验证重点：说明后续最需要观察的业务、产业或宏观变量。
- 风险边界：提示主要风险因素，不输出任何操作建议。
```

## 必须遵守

- 第一行必须是 H1，格式为 `# [公司名称]研究报告`。
- 必须包含分析日期、数据来源、时间范围和研究定位。
- 必须包含核心观点、公司画像、引用来源和免责声明；研报主线、成长逻辑、竞争位置、产业变量、公司业务与研报主题映射、研报片段证据、机构共识、机构分歧、业绩预期汇总、风险因素、后续跟踪框架仅在有具体证据时输出。
- 默认 Markdown 报告必须在免责声明后追加同源 HTML 可视化报告页生成引导。
- Markdown 不得使用旧的图表数据一级章节。
- 表格必须写清列名、日期口径和数据来源；不得输出空值含义、空表或数据不足占位。
- 未使用新闻、公告时不要编造引用来源。
- 不得输出买卖建议、交易时机、仓位、止盈止损或支撑压力位；目标价、评级、买入/推荐等仅可作为机构研报口径出现在业绩预期汇总或证据表中，并必须标注机构口径。
- 研报片段证据只展示归纳摘要，不展示报告 ID、页码、片段位置、接口状态或原文长段。
- 最终报告不得出现内部接口名称、内部字段名称、返回为空、空数组、字段缺失、接口失败、数据不足、暂无法汇总等技术或占位表述。
