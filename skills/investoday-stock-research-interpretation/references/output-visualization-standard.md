# 图表与可视化输出规范

本规范约束 `investoday-stock-research-interpretation` 的 Markdown 研究表格和 HTML 可视化报告页。图表只用于展示研报研究线索、样本结构、主题分布、成长逻辑、竞争位置、研报原文片段摘要、公司业务映射、风险因素、机构共识、机构分歧和业绩预期汇总，不得表达交易信号或操作建议。

## 基本原则

- 图表数据必须来自真实获取的公司资料和研报内容；最终图表标题、说明和空态不得暴露内部接口名称或字段名称。
- 研报原文片段只展示归纳摘要和研究问题，不展示报告 ID、页码、片段位置、接口状态或原文长段。
- Markdown 默认输出公司研究报告，不使用独立的图表一级章节。
- Markdown 中的结构化数据只能以研究表格嵌入对应章节，例如研报主线、成长逻辑、竞争位置、产业变量、公司业务映射、风险因素和后续跟踪框架。
- HTML 可将同源数据渲染为“研报信号看板”，优先使用单文件内联数据、CSS 和轻量 JS/SVG/Canvas 渲染，不依赖外部行情或交易图表库。
- 业绩预期汇总可使用内部业绩预期数据中的收入、净利润、机构评级和机构目标价内容；评级和目标价必须标注为机构研报口径，不得渲染为本 Skill 的建议卡片或操作提示。
- 缺少真实数据时不渲染对应图表、表格或模块；不得展示“数据不足”“字段未返回”“返回为空”“空数组”“暂无法汇总”等占位文案，不得使用编造数据。
- 图表标题和说明不得包含买卖点、目标价、仓位、交易时机、支撑压力位等操作性表达。
- HTML 与 Markdown 内容同源，不新增未经证据支撑的结论。

## Markdown 研究表格映射

| Markdown 章节 | 数据来源 | 表达方式 | 必出规则 | 空值处理 |
|---|---|---|---|---|
| 公司画像与业务定位 | 公司基础资料 | 公司基础资料表 | 有基础信息时输出 | 基础信息缺失时仅输出可确认的代码和名称 |
| 近90天研报覆盖与关注主线 | 研报日期、标题、核心内容和观点 | 关注主线表 | 有研报样本时输出 | 无有效样本时省略 |
| 成长逻辑 | 基础资料、研报摘要、有效片段和机构预测口径 | 成长逻辑表 | 有增长驱动证据时输出 | 无有效证据时省略 |
| 竞争位置 | 主营业务、研报主题、有效片段和多篇研报对比 | 竞争位置表 | 有产业链、技术、客户、交付、规模或同业比较证据时输出 | 无有效证据时省略 |
| 产业环境与核心变量 | 研报观点、关键事由和情绪分析 | 产业变量表 | 有主题证据时输出 | 证据不足时省略 |
| 公司业务与研报主题映射 | 主营业务和研报主题 | 公司业务映射表 | 有基础信息和主题证据时输出 | 无法映射时省略 |
| 研报片段证据 | 有效研报原文片段摘要 | 片段证据表 | 有有效片段摘要时输出 | 无有效片段时省略 |
| 机构共识 | 多篇研报观点对比 | 观点聚类总结、推导依据、共识机构 | 至少 2 家不同机构支持同一具体观点时输出 | 不满足时省略 |
| 机构分歧与待验证问题 | 多篇研报观点对比 | 各方观点、原因、对应机构、待验证变量 | 至少 2 家不同机构形成可归纳差异时输出 | 不满足时省略 |
| 业绩预期汇总 | 机构研报业绩预测内容 | 数据总结 + 业绩预期表 | 有业绩预测样本时输出 | 无样本时省略 |
| 风险因素与情景变量 | 研报风险提示 | 风险因素表 | 有风险证据时输出 | 无风险证据时省略 |
| 后续跟踪框架 | 前述分析结果 | 观察指标表 | 有可跟踪变量时输出 | 无具体变量时省略 |

## HTML 组件规范

| 组件 | 推荐图表类型 | 数据来源 | 交互要求 | 降级方式 |
|---|---|---|---|---|
| 研报发布时间线 | 时间线、散点图、折线点图 | 研报日期和标题 | hover 显示标题和关键事由 | 无有效样本时不渲染 |
| 主题热度 | 横向柱状图 | 研报关键事由聚合 | hover 显示代表证据 | 无有效主题时不渲染 |
| 成长逻辑 | 段落卡片、二维表 | 基础资料、研报摘要、有效片段和机构预测口径 | 展示驱动、证据、商业逻辑和待验证变量 | 无有效证据时不渲染 |
| 竞争位置 | 段落卡片、关系图 | 主营业务、研报主题、有效片段和多篇研报对比 | 展示位置维度、证据、位置归纳和验证问题 | 无有效证据时不渲染 |
| 公司业务映射 | 矩阵图、关系图 | 主营业务和研报主题 | hover 或展开查看研报证据 | 无有效映射时不渲染 |
| 风险矩阵 | 矩阵卡片、二维表 | 研报风险提示归类 | hover 或展开查看证据 | 无风险证据时不渲染 |
| 机构共识 | 段落卡片 | 多篇研报对比 | 展示共识观点、推导依据和去重后的共识机构 | 无具体共同内容时不渲染 |
| 机构分歧 | 段落卡片 | 多篇研报对比 | 展示各方观点、原因、对应机构和待验证变量 | 无具体差异时不渲染 |
| 研报原文片段 | 段落卡片或表格 | 有效研报片段摘要 | 展示片段主题、摘要、对应研究问题和可补强章节 | 无有效片段时不渲染 |
| 业绩预期汇总 | 总结卡片 + 横向滚动表格 | 机构研报业绩预测内容 | 表格前展示样本数量、机构数量、日期区间、预测趋势或区间、前次变化和机构口径提示；再展示机构、报告、收入、净利润、机构评级口径、机构目标价口径和前次变化 | 无预测样本时不渲染 |
| 研报证据表 | 研报日期、标题、核心内容、观点和风险 | 表格 | 支持横向滚动 | 无有效样本时不渲染 |

## HTML 视觉要求

- HTML 必须按 `investoday-design` 的“今日投资金融报告UI规范 / Investoday Premium Diffused”实现，而不是仅在文案中声明采用该规范。页面必须同时具备粉紫弥散背景、玻璃拟态卡片、紫色强调系统、5 色图表色板、紧凑首屏、局部滚动表格和可切换深色模式。
- 必须使用与 `investoday-design` 一致的核心 token：背景三段渐变 `#FFFCFE`、`#FFF5FB`、`#F9F4FF`，主强调色 `#7C3AED`，图表色板 `#FF5F9D`、`#FF958A`、`#7C3AED`、`#8669FF`、`#B3A1CB`，表头底色 `#FFEFF5`，深色模式背景以 `#1A1025`、`#1E1230`、`#200E28` 等深紫为主。
- 顶部导航品牌必须使用中文“今日投资｜研究报告”，并提供深色模式切换；导航必须为粘性玻璃拟态栏，tab 支持横向滚动，移动端不得挤压正文或造成页面级横向滚动。
- 首屏使用紧凑报告标题卡，包含公司名称、股票代码、分析日期、时间范围、数据来源、研究定位、黄色提示卡和摘要正文；第一屏应尽量露出指标卡或下一模块，不得做营销落地页式大 Hero、封面页或产品宣传首屏。
- A 股涨红跌绿语义仅可用于数值涨跌或资金流向；本 Skill 默认不接入行情和资金流，因此不应使用涨跌色表达研报观点。
- 图表色板固定为 `#FF5F9D`、`#FF958A`、`#7C3AED`、`#8669FF`、`#B3A1CB`；柱状/横向柱状图使用粉色权重阶，最高值 `#FF5F9D`、最低值 `#FFDFEB`。
- 卡片使用半透明背景、`backdrop-filter`、细边框和紫色调柔和阴影；内容卡片 hover 只增强投影，指标卡可使用 `#7873F5 -> #EC77AB` 渐变描边，不得使用强烈缩放、旋转、发光或随机高饱和颜色。
- 表格必须放入局部横向滚动容器，移动端不能横向撑破页面。
- 表格表头使用柔和粉色底，表格字号 16px；第一列为对象/维度轴，数字列右对齐并使用 tabular nums，评级、状态和机构口径列居中。
- 图表必须提供标题和数据口径；不得显示内部字段来源或数据不足状态。
- 图表必须能从 `reportData` 或等价同源数据对象渲染，不得只保留空容器。
- 业绩预期模块必须能从 `earningsSummary` 与 `earningsForecasts` 或等价同源数据对象渲染；评级和目标价列名必须包含“机构”或“研报口径”。
- 深色模式必须预留完整 CSS token 或等价变量切换，深色背景使用深紫，不使用纯黑；切换后导航、卡片、表格、提示卡和图表文字颜色必须同步更新。
- 页面根元素和正文必须防止页面级横向滚动；只有 `.table-wrap`、导航 tabs 等局部容器可以横向滚动。固定宽度表格、长标题、长研报名和图表标签必须通过局部滚动、换行或 `min-width: 0` 处理。

## 禁止图表

- 价格走势、K 线、支撑压力位、目标价变化、仓位建议、买卖点图。
- 资金流向、主力净流入、盘口、龙虎榜等交易行为图。
- 用 `sentiment` 或 `comScore` 生成交易信号、短线情绪周期或操作建议。
- 将机构评级、机构目标价渲染为本 Skill 的推荐、目标价格卡片、按钮或行动提示。
- 无数据时用演示数据冒充真实图表。

## 验收清单

- Markdown 标题为 `# [公司名称]研究报告`。
- Markdown 不使用独立的图表一级章节。
- 图表数据能追溯到数据契约，但最终页面不暴露内部接口或字段名称。
- 图表标题为研究参考口径。
- HTML 图表具备真实渲染逻辑或等价可执行组件，不只是占位文案。
- HTML UI 不仅声明采用 `investoday-design`，还实际包含粉紫弥散 token、中文粘性导航、深色模式按钮、玻璃卡片、指标卡渐变描边、表格局部滚动、固定图表色板和移动端无页面级横向滚动约束。
- 图表未包含操作性交易结论。
- 数据不足时省略对应图表或模块，不输出占位说明。
- HTML 与 Markdown 使用同一组数据与结论。
