# Changelog

## 1.6.3 - 2026-07-05

- 将机构共识从逐研报罗列调整为“共识观点、推导依据、共识机构”的聚合输出，并要求机构名称去重。
- 将机构分歧调整为“各方观点、原因、对应机构、待验证变量”的分组输出，不再逐篇列研报观点。
- 业绩预期汇总新增表前数据总结，先概括样本数量、机构数量、日期区间、预测趋势或区间、前次变化和机构口径提示，再展示明细表。
- 同步更新 `SKILL.md`、Markdown/HTML 模板、可视化规范、示例和测试用例；HTML 新增 `earningsSummary`，并调整共识/分歧数据结构。

## 1.6.2 - 2026-07-04

- 删除独立估值预期分析章和对应 HTML 数据对象，仅保留成长逻辑、竞争位置两个四字研究章节。
- 同步更新 Markdown/HTML 模板、可视化规范、数据契约说明、合规边界、示例和测试用例；HTML 仅保留 `growthLogic`、`competitivePosition` 同源数据对象。
- 明确评级、目标价和前瞻 PE 等机构预测字段只在业绩预期汇总中按机构研报口径展示，不再单独形成估值预期分析模块。

## 1.6.0 - 2026-07-04

- 新增研报向量原文片段补证能力，接入 `report/vector-search`，默认标准报告尝试用有效 `chunk` 加深主题、风险、业务映射和证据链。
- 明确向量片段为空、超时或弱相关时静默降级，不在最终报告中展示接口缺口、报告 ID、页码或片段位置。
- 同步更新 `SKILL.md`、数据契约、Markdown 模板、HTML 模板、可视化规范和测试用例，增加研报片段证据表与 HTML 片段证据模块。
