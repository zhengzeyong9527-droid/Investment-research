# 研报报告生成

本原子 Skill 负责把上游研报类原子 Skill 的标准输出组织成用户可读的中文研报解读报告。它不直接取数，不调用底层数据接口，不处理非今日投资研报库内容，不补造研报观点。

默认产出为 Markdown 报告正文。只有主 Skill 确认用户明确需要 HTML、H5、Demo、页面、看板或研究报告页时，本 Skill 才提供同源 HTML 映射建议；HTML 的具体模板由主包 `assets/templates/output-html-report-template.md` 约束。

## 输入要求

### 可接受输入

- 研报查询结果：研报标题、发布机构、发布日期、摘要、机构观点、证据片段、评级、目标价、EPS、净利润预测、预测变化和 `source_refs`。
- 场景解读结果：个股研报解读、行业研报解读、指定研报解读、多篇研报对比、证据抽取、预测评级解读的标准输出。
- 用户任务：个股解读、行业解读、指定研报解读、多篇研报对比、证据检索、预测评级解读或 HTML 同源映射。
- 输出上下文：是否需要默认 Markdown、是否已确认继续生成同源 HTML。

### 最小输入

| 报告类型 | 最小输入 | 缺失处理 |
|---|---|---|
| 个股研报解读 | 股票对象 + 至少一条可定位研报记录 | 缺研报来源时不生成强结论，返回需要补充样本。 |
| 行业研报解读 | 行业/主题对象 + 至少一条可定位研报记录 | 缺行业或研报来源时不生成强结论。 |
| 指定研报解读 | 研报标题、发布机构和发布日期 | 无法定位时要求主 Skill 补检索结果。 |
| 多篇研报对比 | 至少两篇可定位研报 | 当前样本少于两篇时输出不能对比的原因。 |
| 证据抽取 | 查询文本 + 至少一个可定位片段或空结果说明 | 无片段时只输出缺口和可调整条件。 |
| 预测评级解读 | 股票对象 + 预测评级样本或空结果说明 | 当前样本不支持计算时不计算比例。 |
| HTML 同源映射 | 已有 Markdown 报告内容 + 用户确认需要 HTML | 未确认时不生成 HTML 映射。 |

### 默认假设

- 未确认 HTML 时，只输出 Markdown 报告。
- Markdown 报告末尾必须询问用户是否需要继续生成同源 HTML。
- HTML 只能来自同一份 Markdown 报告，不新增观点、指标、来源或结论。
- 上游未执行的场景模块必须显式标注，不用空结论填充。
- 原子 Skill 输出冲突时必须保留冲突和来源，不静默覆盖。
- 默认报告结构为：结论卡片、样本口径摘要、近期研报舆情、研报观点/分歧/风险、预测评级与盈利预测、综合结论、数据来源与代表性研报、免责声明。
- 近期代表性研报清单只在末尾来源附录展示；前部仅保留样本口径摘要。

## 输出契约

| 输出项 | 类型 | 是否必出 | 来源/生成方式 | 空值处理 | 说明 |
|---|---|---|---|---|---|
| Markdown 报告正文 | Markdown | 是 | 上游标准输出 + 主包 Markdown 模板 | 证据不足时降低结论强度 | 默认输出形态。 |
| 结论卡片 | Markdown 表格 | 报告类必出 | 综合研报观点和场景解读摘要 | 证据有限时降低结论强度 | 先给用户可读结论。 |
| 样本口径摘要 | Markdown 段落 | 报告类必出 | 研报查询结果 | 仅说明当前取得样本口径 | 用一句话说明数量、机构、时间范围和最近日期；不前置代表性研报清单。 |
| 近期研报舆情 | Markdown 段落/表格 | 条件必出 | 研报舆情结果 | 舆情为空时写明当前样本未取得可用研报舆情 | 放在样本摘要后、观点风险前。 |
| 研报观点、分歧与风险 | Markdown 段落/表格 | 报告类必出 | 场景解读结果 + 研报舆情 + 片段证据 | 无明确分歧时不强行生成分歧 | 合并核心共识、主要分歧、关注重点/跟踪指标和主要风险；分歧必须说明各方观点。 |
| 预测评级与盈利预测 | Markdown 段落 + 单一表格 | 个股/预测评级场景条件必出 | 预测评级解读结果 | 样本有限时说明当前样本口径 | 表前说明样本范围、目标价有效样本统计、评级分布、预测修正方向和可比性；只保留一个明细表。 |
| 数据来源与代表性研报 | Markdown 表格/清单 | 报告类必出 | `source_refs`、研报列表和预测评级样本 | 来源不可定位时标注需进一步确认 | 位于末尾，展示日期、机构、标题、评级、目标价和用途。 |
| 冲突与缺口 | Markdown 表格/清单 | 条件触发 | 多来源差异和缺失信息 | 无冲突时可简述“当前样本未发现明显观点对立” | 优先并入“研报观点、分歧与风险”。 |
| HTML 同源映射建议 | Markdown 清单 | 用户确认 HTML 后输出 | Markdown 章节映射 | 未确认时不输出 | 供主 Skill 按 HTML 模板生成页面。 |
| HTML 后续询问 | 文本 | 默认必出 | 输出自检 | 不适用 | 固定询问：`是否需要我继续基于内容生成HTML研究报告页？` |

## 输出结构原则

所有报告采用“结论先行、舆情概览、观点风险合并、预测一表承载、来源附录收口”的结构：

1. 结论卡片。
2. 样本口径摘要段。
3. 近期研报舆情。
4. 研报观点、分歧与风险。
5. 预测评级与盈利预测，或任务关键字段。
6. 综合结论。
7. 数据来源与代表性研报。
8. 免责声明。
9. HTML 后续询问。

个股研报解读默认不生成独立证据链顶层章节；研报标题、机构、日期、评级和目标价应进入末尾“数据来源与代表性研报”，支持判断进入预测明细表。用户明确要求“找证据”“证据链”“片段证据”时，才按证据抽取任务输出证据片段表。

## HTML 同源规则

当用户确认需要 HTML 时，本 Skill 只提供 Markdown 到 HTML 的内容映射建议：

| Markdown 章节 | HTML 映射 |
|---|---|
| 结论卡片 | 首屏摘要、关键指标卡、核心风险提示 |
| 样本口径摘要 | 报告元信息、覆盖机构指标，不展示前置研报清单 |
| 近期研报舆情 | 舆情概览卡 |
| 研报观点、分歧与风险 | 主题卡，包含核心共识、主要分歧、关注重点/跟踪指标和主要风险 |
| 预测评级与盈利预测 | 预测数据总结和最近 5 家机构评级/目标价/EPS/净利润预测单表 |
| 证据片段/来源附录 | 仅在证据抽取、行业、指定研报或多篇对比任务中映射为证据表、来源卡、附录 |
| 数据来源与代表性研报 | HTML Appendix、来源表或 footer 附近的来源区 |
| 免责声明 | HTML footer 或附录 |

HTML 不得新增 Markdown 中没有的观点、指标、来源或结论。缺少可展示样本时使用“—”或说明“当前结论仅基于已取得研报样本”，不得填入看似真实的数值。

## 表达规则

- 使用中文投研表达，结论必须绑定研报证据。
- 不展示内部 Skill 名称、接口名、字段名、技术命令、数据包名称、调试状态或文件路径。
- 每个关键观点必须标注来源机构、研报标题、发布日期或当前样本口径说明。
- 近期研报舆情必须位于观点风险之前；未取得舆情时说明“当前样本未取得可用研报舆情”。
- 核心共识、主要分歧、关注重点/跟踪指标和主要风险必须在同一顶层模块中输出。
- 主要分歧必须说明分歧各方分别怎么看；没有实质分歧时不强行列分歧。
- 评级、目标价、EPS 和净利润预测必须说明样本范围和时间范围；个股和预测评级场景默认列出最近 5 家机构明细，且只保留一个预测评级与盈利预测明细表。
- 最近 5 家机构明细表按研报发布日期倒序、同一机构只保留最新一篇；固定列为日期、机构、研报、评级、目标价、T+1 EPS、T+2 EPS、T+3 EPS、T+1 净利润预测、预测/评级变化、支持的判断；空字段统一写“—”。
- 目标价平均值只基于可解析的数值样本计算；空值、区间无法解析、非数字文本不纳入平均，并说明有效样本数。
- 趋势分析优先使用 `forecastRevisionSummary`；若不可比，则只说明当前样本不支持计算上调/下调占比。
- 具体研报标题、机构、日期、评级和目标价清单只放在末尾“数据来源与代表性研报”。
- 面向用户的最终报告不得出现中文缺失占位词；表格空项统一使用“—”，正文使用当前样本口径说明。
- 不输出买卖建议、目标仓位、交易时机、止盈止损、收益承诺或确定性涨跌判断。
- 允许出现的专业英文缩写仅限行业和投研常用术语，如 A 股、EPS、ASP；出现时尽量配中文解释。

## 缺失处理

- 缺少研报来源：不生成强结论，要求补充可定位研报。
- 多篇研报时间跨度过大：明确时点差异，不合并为当前共识。
- 证据片段缺少明确对象或数值：只作为弱文本线索。
- 上游原子 Skill 未执行：说明未执行原因，不输出该维度强结论。
- 来源冲突：列出冲突来源、差异原因和暂定处理，不静默覆盖。

## 输出自检

交付前检查：

- 是否先给结论卡片。
- 是否只在前部展示样本口径摘要和时间范围，不前置大块代表性研报清单。
- 是否将近期研报舆情放在观点风险之前；舆情为空时是否说明缺口。
- 是否将观点、分歧、关注重点和风险合并到同一模块。
- 是否没有强行生成不存在的分歧；若有分歧，是否说明各方分别怎么看。
- 是否只输出一个预测评级与盈利预测明细表，并在表前说明样本范围、目标价统计、评级分布、趋势口径和可比性。
- 是否将代表性研报清单下沉到末尾来源附录。
- 是否每个关键观点绑定来源。
- 是否保留冲突、未执行、样本限制和证据缺口。
- 是否删除内部字段、接口名、技术命令、调试信息和文件路径。
- 是否包含非投资建议声明。
- 是否在 Markdown 末尾询问：`是否需要我继续基于内容生成HTML研究报告页？`

## 安全与合规

- 不直接取数、不调用底层接口、不处理凭证。
- 不记录、不存储用户查询记录。
- 不输出投资建议、收益承诺、目标仓位或交易指令。
- 不把研报评级、目标价或盈利预测包装成交易建议。
- 不把文本片段包装成确定事实。

## 免责声明

本报告基于公开研报样本生成，仅用于研究参考。研报观点、评级、目标价、EPS 和净利润预测均来自机构样本，不代表确定性判断，也不构成投资建议、交易指令或收益承诺。市场有风险，投资需谨慎。
