# 个股研报解读

本原子 Skill 只消费 `investoday-research-report-query` 的标准输出，不直接调用接口。它将个股相关研报列表、舆情、证据片段、预测评级和评级变动组织为用户可读的个股研报解读摘要。

## 输入要求

### 可接受输入

- 股票名称或代码。
- 研报样本：标题、发布机构、发布日期、作者、摘要。
- 研报观点：核心内容、机会、风险、情绪、关键事由。
- 预测评级：评级、目标价、EPS、净利润预测、预测修正摘要。
- 证据片段：与增长驱动、盈利假设、行业变量、催化因素、风险相关的片段和 `source_refs`。
- 用户关注维度：机构共识、评级变化、目标价区间、盈利预测、风险因素、分歧点。

### 最小输入

| 输入项 | 是否必需 | 缺失处理 |
|---|---|---|
| 股票对象 | 是 | 要求主 Skill 补充或解析股票对象。 |
| 至少一条可定位研报 | 是 | 不生成强结论，只返回样本缺口。 |
| `source_refs` | 是 | 来源不可定位时不得进入结论卡片。 |

## 输出契约

| 输出项 | 类型 | 是否必出 | 说明 |
|---|---|---|---|
| 个股研报解读摘要 | Markdown 段落/表格 | 是 | 一句话结论、样本范围、证据强度。 |
| 样本口径摘要 | Markdown 段落 | 是 | 覆盖机构、研报数量、时间范围、最近研报日期；不输出前置代表性研报大表。 |
| 近期研报舆情 | Markdown 段落/表格 | 条件必出 | 核心内容、机会、风险、情绪倾向和关键事由；无舆情时说明当前样本未取得可用研报舆情。 |
| 研报观点、分歧与风险 | Markdown 表格/段落 | 是 | 核心共识、主要分歧、关注重点/跟踪指标、主要风险；每条观点尽量标注来源机构。 |
| 预测评级与盈利预测 | Markdown 段落 + 表格 | 条件必出 | 表前给出样本范围、目标价统计、评级分布、预测修正方向和可比性；表格为最近 5 家机构预测明细单表。 |
| `source_refs` | 结构化列表 | 是 | 传递给最终写作 Skill。 |

## 业务规则

- 评级、目标价和盈利预测只作为机构样本展示，不转化为收益承诺。
- 预测评级与盈利预测默认按研报发布日期倒序展示最近 5 家机构；同一机构多篇研报只保留最新一篇，少于 5 家则如实展示已取得样本。
- 预测明细表只保留一个，固定列为：日期、机构、研报、评级、目标价、T+1 EPS、T+2 EPS、T+3 EPS、T+1 净利润预测、预测/评级变化、支持的判断。
- 预测明细表前必须输出预测数据总结：样本时间范围、机构数、样本数、目标价最小/最大/平均值或中位数、评级分布、预测修正方向和样本可比性说明。
- 目标价平均值只基于可解析的数值样本计算；空值、区间无法解析、非数字文本不纳入平均，并说明有效样本数。
- 趋势分析优先使用 `forecastRevisionSummary`；若不可比，则只说明当前样本不支持计算上调/下调占比。
- 如果报告日期和预测年度能可靠映射，可将 T+1/T+2/T+3 展示为具体年份；不能可靠映射时保留 T+1/T+2/T+3。
- 空字段统一写“—”，不得补估或编造。
- “支持的判断”必须来自同一篇研报的标题、摘要、正文片段、核心观点或预测评级样本；若只有标题和评级字段，使用保守表述并标注“标题/预测样本支持”。
- 多篇研报时间跨度较大时，必须说明时点差异。
- 当前预测样本不支持可比计算时，不计算上调占比。
- 证据片段缺少对象、时间或数值时，只作为弱证据。
- 近期代表性研报清单只传递给最终写作 Skill 的“数据来源与代表性研报”，不作为个股报告前部模块。
- 主要分歧必须说明各方观点分别是什么；当前样本没有实质分歧时，不强行列分歧，可写“当前样本未发现明显观点对立”。
- 不输出买入、卖出、持有、仓位、交易时机或确定性涨跌判断。

## 验收标准

- 输入来自研报查询标准输出。
- 每个关键观点能追溯到研报标题、机构和发布日期。
- 个股默认报告不单独生成独立证据链顶层章节，证据体现在预测明细表的“支持的判断”和末尾“数据来源与代表性研报”中。
- 前部不输出大块代表性研报清单。
- 近期研报舆情位于观点风险之前。
- 核心共识、主要分歧、关注重点/跟踪指标和主要风险合并输出。
- 预测评级与盈利预测只输出一个明细表。
- 不出现非研报数据验证。
- 不输出交易建议。
