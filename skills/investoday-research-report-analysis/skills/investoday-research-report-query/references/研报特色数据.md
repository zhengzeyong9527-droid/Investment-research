# 研报特色数据

---

## 研报舆情

接口路径：`research/sentiment`  
请求方式：**`POST`**  
tool_id：`list_research_sentiment`

接口说明：按报告 ID、标题、股票代码、行业代码、概念代码、机构代码、发布时间范围、情绪倾向和相关度筛选研报衍生信息，返回核心内容、分析观点、投资机会、投资风险、情绪分析和关键事由。适用于快速整理研报观点和风险机会线索。

**输入参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|---|:---:|---|---|---|
| `guid` | — | string | 报告 id | `0236EC2B-2416-455E-BF82-E4ED96E91DB0` |
| `title` | — | string | 标题模糊查询 | `宏观` |
| `sentiment` | — | integer | 情绪偏向 | `1` |
| `beginTime` | — | string | 发布开始时间，格式 `yyyy-MM-dd HH:mm:ss` | `2025-01-01 00:00:00` |
| `endTime` | — | string | 发布截止时间，格式 `yyyy-MM-dd HH:mm:ss` | `2026-06-16 23:59:59` |
| `stockCode` | — | string | 股票代码 | `000001` |
| `industryCode` | — | string | 行业代码 | `370000` |
| `conceptCode` | — | string | 概念代码 | `CLS81936` |
| `institutionCode` | — | integer | 机构代码 | `142` |
| `minRelevance` | — | integer | 实体相关度下限，范围 `1-6` | `1` |
| `pageNum` | — | integer | 页码，最小值 `1` | `1` |
| `pageSize` | — | integer | 页长，最大值 `500` | `20` |

**输出参数**

| 字段名 | 说明 |
|---|---|
| `date` | 发布时间 |
| `guid` | 报告 id |
| `title` | 标题 |
| `coreContent` | 核心内容 |
| `analysisViewpoint` | 分析观点 |
| `investmentOpportunity` | 投资机会文本 |
| `investmentRisk` | 投资风险文本 |
| `comScore` | 综合得分，范围 `-5` 到 `5` |
| `sentiment` | 情绪偏向 |
| `keyReason` | 关键事由 |
| `sentimentAnalysis` | 情绪分析 |
| `analysisFramework` | 分析框架 |
| `stockName` | 股票名称 |
| `stockCode` | 股票代码 |
| `minRelevance` | 关联度 |

**使用说明**

- “投资机会”字段只能作为研报文本线索，不得输出买入建议。
- “投资风险”为空不等于不存在风险，只能说明该字段在当前样本中为空。
- 舆情得分和情绪字段是辅助口径，不应单独作为最终判断。
- 需要具体原文位置时，补充调用研报向量搜索。

**接口示例**

```bash
investoday-api research/sentiment --method POST --body-json '{"stockCode":"000001","beginTime":"2025-01-01 00:00:00","endTime":"2026-06-16 23:59:59","pageNum":1,"pageSize":20}'
```

## 研报向量搜索

接口路径：`report/vector-search`  
请求方式：**`POST`**  
tool_id：`list_report_vector-search`

接口说明：使用必填查询文本，结合股票代码、行业代码、机构代码或分类代码过滤范围进行研报语义搜索，返回研报 ID、发布时间、文本片段、页码、文本块起止位置和片段位置。适用于从研报中定位行业渗透率、市场份额、CR3/CR5、ASP、产能、库存、开工率、供需缺口、TAM/SAM、技术路线、渠道动销等文本证据。

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|---|:---:|---|---|---|
| `stockCode` | — | string | 股票代码；与行业、机构、分类参数至少传一个 | `002594` |
| `industryCode` | — | string | 行业代码 | `740000` |
| `institutionCode` | — | string | 机构代码 | `37` |
| `categoryCode` | — | string | 分类代码 | `000100` |
| `beginDate` | — | string | 开始日期，格式 `yyyy-MM-dd` | `2025-01-01` |
| `endDate` | — | string | 结束日期，格式 `yyyy-MM-dd` | `2026-06-16` |
| `topK` | — | integer | 返回条数 | `5` |

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|---|:---:|---|---|---|
| `query` | ✅ | string | 查询文本 | `新能源汽车` |

**输出参数**

| 字段名 | 说明 |
|---|---|
| `reportId` | 研报 ID |
| `pubDate` | 发布时间 |
| `chunk` | 文本片段 |
| `page` | 页码 |
| `blockStart` | 文本块起始位置 |
| `blockEnd` | 文本块结束位置 |
| `position` | 片段位置 |

**使用说明**

- 必须同时具备 `query` 和至少一个过滤范围；只传 `query` 会返回过滤条件为空。
- Query 文本建议使用中文逗号连接多个概念，例如 `渗透率，市场空间，份额`。
- 返回片段是文本证据，不是已清洗结构化字段。
- 片段缺少对象、时间、数值或口径时，只能作为弱证据。
- 上层 Skill 使用时，应保留 `reportId`、`pubDate`、`page` 和 `position` 以便追溯。

**接口示例**

```bash
investoday-api report/vector-search --method POST stockCode=002594 topK=5 --body-json '{"query":"销量，ASP，产能，市场份额"}'
investoday-api report/vector-search --method POST industryCode=740000 topK=5 --body-json '{"query":"渗透率，市场空间，竞争格局"}'
```

PowerShell 环境中如果 JSON 引号被拆分，可使用：

```powershell
investoday-api report/vector-search --method POST stockCode=002594 topK=5 --body-json '{\"query\":\"销量，ASP，产能，市场份额\"}'
```
