# 研报基础数据

---

## 研究报告

接口路径：`report/research`  
请求方式：**`POST`**  
tool_id：`list_report_research`

接口说明：按股票代码、行业代码、一级行业代码、研究机构代码、栏目分类代码和发布日期范围筛选证券研究报告列表，返回报告编号、标题、作者、发布时间、机构、关键字、内容摘要和分类代码。适用于查询个股研报、行业研报、机构研报和后续文本证据入口。

**输入参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|---|:---:|---|---|---|
| `stockCode` | — | string | 股票代码；与行业、机构、分类参数组成多选条件，至少传一个 | `600519` |
| `industryCode` | — | string | 申万二级行业代码 | `740100` |
| `industryCodeLv1` | — | string | 申万一级行业代码 | `640000` |
| `institutionCode` | — | integer | 研究机构代码 | `37` |
| `categoryCode` | — | string | 栏目分类代码 | `000100` |
| `beginDate` | — | string | 开始日期，格式 `yyyy-MM-dd` | `2025-01-01` |
| `endDate` | — | string | 结束日期，格式 `yyyy-MM-dd` | `2026-06-16` |
| `pageNum` | — | integer | 页码，最小值 `1` | `1` |
| `pageSize` | — | integer | 页长，最大值 `500` | `20` |

**输出参数**

| 字段名 | 说明 | 示例 |
|---|---|---|
| `guid` | 报告编号 | `B761EA4B-7146-436E-9C4E-03CE948A6DD4` |
| `reportId` | 报告 id | `795857` |
| `title` | 标题 | `PICC Property and Casualty...` |
| `author` | 作者 | `孙梦曦,王欢` |
| `date` | 发布时间 | `2016-01-04 09:54:27` |
| `institutionName` | 机构名称 | `Morgan Stanley` |
| `keyword` | 关键字 | `岭南控股...` |
| `content` | 内容摘要 | `我们将未来12个月...` |
| `categoryCode` | 栏目分类代码 | `000100` |
| `reportLanguage` | 报告语种 | — |
| `categoryCodeLv2` | 栏目二级分类代码 | `000111` |

**使用说明**

- 至少提供股票、行业、机构或分类范围之一；不要无过滤条件拉全量。
- 用户说“最近研报”时默认近 12 个月，可按产品场景缩短至 3 或 6 个月。
- 行业研报优先使用行业代码，不要优先使用行业名称模糊替代。
- `content` 可能只是摘要或片段，不等同于完整 PDF 原文。
- 需要语义定位具体指标时，使用 `report/vector-search` 补充片段证据。

**接口示例**

```bash
investoday-api report/research --method POST --body-json '{"stockCode":"600519","beginDate":"2025-01-01","endDate":"2026-06-16","pageNum":1,"pageSize":20}'
investoday-api report/research --method POST --body-json '{"industryCodeLv1":"640000","pageNum":1,"pageSize":20}'
```

## 研究机构列表

接口路径：`report/institutions`  
请求方式：**`POST`**  
tool_id：`list_report_institutions`

接口说明：按机构名称模糊查询有效研究机构列表，返回机构代码和机构名称。适用于用户指定机构名称后，先解析 `institutionCode`，再用于研报列表、舆情或向量搜索过滤。

**输入参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|---|:---:|---|---|---|
| `institutionName` | — | string | 机构名称模糊查询 | `高盛` |
| `pageNum` | — | integer | 页码，最小值 `1` | `1` |
| `pageSize` | — | integer | 页长，最大值 `500` | `20` |

**输出参数**

| 字段名 | 说明 | 示例 |
|---|---|---|
| `institutionCode` | 机构代码 | `337` |
| `institutionName` | 机构名称 | `高盛` |

**使用说明**

- 不得猜测机构代码；需要机构过滤时先查机构列表。
- 多个机构候选时，应输出候选并让用户确认。
- 机构名称为空时，可返回默认分页结果，但不应作为用户指定机构的证据。

**接口示例**

```bash
investoday-api report/institutions --method POST --body-json '{"institutionName":"高盛","pageNum":1,"pageSize":20}'
```
