# 行业研报解读

本原子 Skill 只消费 `investoday-research-report-query` 的标准输出，不直接调用接口。它把行业、板块或主题相关研报组织为研报视角的行业解读，不使用非研报数据。

## 输入要求

### 可接受输入

- 行业、板块、主题或概念名称。
- 行业/主题研报列表、摘要和 `source_refs`。
- 研报舆情：核心观点、机会、风险、情绪。
- 向量片段：产业链、竞争格局、政策、渗透率、市场空间、产能、价格、技术路线、催化剂和风险。
- 用户关注维度：共识主线、分歧、政策、竞争、空间、风险、跟踪指标。

### 最小输入

| 输入项 | 是否必需 | 缺失处理 |
|---|---|---|
| 行业/主题对象 | 是 | 要求主 Skill 补充过滤范围。 |
| 至少一条可定位研报 | 是 | 不生成强结论，只输出空态和建议扩大范围。 |
| `source_refs` | 是 | 来源不可定位时不得进入核心结论。 |

## 输出契约

| 输出项 | 类型 | 是否必出 | 说明 |
|---|---|---|---|
| 行业研报解读摘要 | Markdown 段落/表格 | 是 | 一句话结论、样本范围、证据强度。 |
| 覆盖热度 | Markdown 表格 | 是 | 研报数量、机构、时间范围、最近研报日期。 |
| 机构共识主线 | Markdown 段落/表格 | 是 | 产业链、竞争格局、政策、空间、催化剂。 |
| 关键片段证据 | Markdown 表格 | 条件必出 | 片段摘要、来源、支持判断、证据强度。 |
| 分歧与风险 | Markdown 清单 | 是 | 乐观/谨慎观点、风险因素、样本局限。 |
| `source_refs` | 结构化列表 | 是 | 传递给最终写作 Skill。 |

## 业务规则

- 只写“研报中如何表述”，不把研报观点包装成已验证事实。
- 行业空间、渗透率、份额、产能、政策等必须来自研报片段或研报摘要。
- 多个机构观点冲突时保留冲突，不强行合并为单一共识。
- 不输出行业交易建议、板块配置建议或个股推荐。

## 输出骨架

```markdown
## 行业研报解读摘要

## 研报覆盖热度

## 机构共识主线

## 关键指标与片段证据

## 分歧、风险与跟踪指标

## 来源
```

## 验收标准

- 输入来自研报查询标准输出。
- 每个行业判断绑定研报来源或片段证据。
- 不出现非研报结构化分析。
- 不输出交易建议。
