# 指定研报解读

本原子 Skill 只消费 `investoday-research-report-query` 已定位的单篇研报记录及相关舆情、片段和预测评级输出，不直接取数。

## 输入要求

### 可接受输入

- 可定位研报：标题、发布机构、发布日期、作者、相关标的或行业。
- 研报摘要、核心内容、机会、风险、情绪和关键事由。
- 该研报相关片段证据。
- 该研报或同对象预测评级字段：评级、目标价、EPS、净利润预测。
- 用户关注维度：摘要、核心假设、风险、评级、预测、逻辑评估。

### 最小输入

| 输入项 | 是否必需 | 缺失处理 |
|---|---|---|
| 研报标题 | 是 | 要求主 Skill 补充检索结果或序号。 |
| 发布机构 | 是 | 缺失时不能作为可定位来源。 |
| 发布日期 | 是 | 缺失时不能作为强来源。 |

## 输出契约

| 输出项 | 类型 | 是否必出 | 说明 |
|---|---|---|---|
| 研报信息 | Markdown 表格 | 是 | 标题、机构、发布日期、对象。 |
| 核心摘要 | Markdown 段落 | 是 | 研报主旨和关键结论。 |
| 核心假设 | Markdown 表格/清单 | 是 | 增长、盈利、行业变量、催化剂。 |
| 结构化信息 | Markdown 表格 | 条件必出 | 评级、目标价、EPS、净利润预测；若同时展示多项预测字段，合并在同一张表中。 |
| 证据链 | Markdown 表格 | 是 | 关键证据、来源、支持判断。 |
| 风险与跟踪指标 | Markdown 清单 | 是 | 研报风险、薄弱点、后续观察。 |
| `source_refs` | 结构化列表 | 是 | 传递给最终写作 Skill。 |

## 业务规则

- 只能解读已定位研报，不根据标题猜测内容。
- 缺少正文片段时，可基于摘要和舆情输出弱解读，但必须标注证据不足。
- 评级、目标价和预测字段必须说明来自机构样本，不拆成多个相邻顶层表格。
- 不输出买卖建议、收益承诺或仓位建议。

## 输出骨架

```markdown
## 研报信息

## 核心摘要

## 核心假设与证据

## 预测评级与盈利预测

## 风险与跟踪指标

## 数据来源与代表性研报
```

## 验收标准

- 能定位研报标题、机构和发布日期。
- 不编造研报正文。
- 不直接取数。
- 不输出交易建议。
