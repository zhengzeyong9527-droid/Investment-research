# 预测评级解读

本原子 Skill 只消费 `investoday-research-report-query` 的 `forecast_rating`、`rating_change`、`forecastRevisionSummary` 和 `source_refs` 输出，不直接调用接口。

## 输入要求

### 可接受输入

- 股票名称或代码。
- 预测评级样本：评级、目标价、扩展目标价、EPS、净利润预测、发布日期、机构、研报标题。
- 评级变动记录：预测、评级或目标价变化方向及原因。
- 可比预测修正摘要：样本数、上调/下调/持平数量、计算口径。
- 用户关注维度：评级趋势、目标价区间、盈利预测、预测修正、上调占比。

### 最小输入

| 输入项 | 是否必需 | 缺失处理 |
|---|---|---|
| 股票对象 | 是 | 要求主 Skill 补充或解析股票对象。 |
| 预测评级样本或空结果说明 | 是 | 无样本时只输出缺口。 |
| `source_refs` | 条件必需 | 有样本时必须传递来源。 |

## 输出契约

| 输出项 | 类型 | 是否必出 | 说明 |
|---|---|---|---|
| 样本范围 | Markdown 表格/段落 | 是 | 时间范围、机构数、样本数。 |
| 预测数据总结 | Markdown 段落 | 条件必出 | 样本时间范围、机构数、样本数、目标价最小/最大/平均值或中位数、评级分布、预测修正方向和样本可比性说明。 |
| 最近 5 家机构预测明细表 | Markdown 表格 | 条件必出 | 日期、机构、研报、评级、目标价、T+1/T+2/T+3 EPS、T+1 净利润预测、预测/评级变化、支持的判断。 |
| 评级分布、目标价区间、EPS/净利润预测、预测修正摘要 | 结构化摘要 | 条件必出 | 不再各自生成独立顶层表格，必须汇入预测数据总结和同一张明细表。 |
| 评级变动原因 | Markdown 清单/表格字段 | 条件必出 | 优先进入“预测/评级变化”列或预测数据总结。 |
| `source_refs` | 结构化列表 | 条件必出 | 传递给最终写作 Skill。 |

## 业务规则

- 目标价只作为机构样本字段展示，不计算或暗示收益空间。
- 默认按研报发布日期倒序展示最近 5 家机构预测明细；同一机构多篇研报只保留最新一篇，少于 5 家则如实展示已取得样本。
- 目标价和盈利预测不得拆成多个相邻顶层表格；最终只输出一个“预测评级与盈利预测”明细表。
- 明细表前必须输出预测数据总结：样本时间范围、机构数、样本数、目标价最小/最大/平均值或中位数、评级分布、预测修正方向和样本可比性说明。
- 目标价平均值只基于可解析的数值样本计算；空值、区间无法解析、非数字文本不纳入平均，并说明有效样本数。
- 趋势分析优先使用 `forecastRevisionSummary`；若不可比，则只说明当前样本不支持计算上调/下调占比。
- 如果报告日期和预测年度能可靠映射，可将 T+1/T+2/T+3 展示为具体年份；不能可靠映射时保留 T+1/T+2/T+3。
- 空字段统一写“—”，不得补估或编造。
- “支持的判断”必须和具体机构、研报标题、发布日期绑定；若只有预测评级样本和标题，使用保守表述并标注“标题/预测样本支持”。
- 预测修正必须基于可比样本；当前样本不支持可比计算时不计算上调占比。
- 同一研报样本只计入一次。
- 不同机构口径差异必须保留，不强行平均。
- 不输出买入、卖出、持有、仓位、交易时机或确定性涨跌判断。

## 输出骨架

```markdown
## 预测评级样本范围

## 预测数据总结

近 <时间范围> 共取得 <预测样本数> 条预测评级样本，覆盖 <机构数> 家机构。目标价有效数值样本 <有效样本数> 条，区间为 <最小值>-<最大值>，平均值/中位数为 <数值>；不可解析目标价样本 <数量> 条未纳入统计。评级分布为 <评级分布>。预测修正方向基于 <forecastRevisionSummary 或当前样本口径>；当前样本不可比时，不计算上调/下调占比。

## 预测评级与盈利预测明细

| 日期 | 机构 | 研报 | 评级 | 目标价 | T+1 EPS | T+2 EPS | T+3 EPS | T+1 净利润预测 | 预测/评级变化 | 支持的判断 |
|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |

## 样本缺口与风险提示

## 数据来源与代表性研报
```

## 验收标准

- 输入来自研报查询标准输出。
- 默认输出预测数据总结和最近 5 家机构预测明细单表，并绑定具体机构、研报日期和研报标题。
- 目标价平均值只基于可解析数值样本计算，并说明有效样本数。
- 评级分布、目标价区间、EPS/净利润预测和预测修正不得拆成多个独立顶层表格。
- 当前样本不支持可比计算时不计算比例。
- 目标价不被包装成收益承诺。
- 不直接取数。
