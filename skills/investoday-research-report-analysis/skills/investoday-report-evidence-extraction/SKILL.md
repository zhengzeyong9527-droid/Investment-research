# 研报证据抽取

本原子 Skill 只消费 `investoday-research-report-query` 的向量搜索、研报舆情和 `source_refs` 输出，不直接调用接口。

## 输入要求

### 可接受输入

- 查询文本，例如 `渗透率`、`市场份额`、`产能`、`库存`、`ASP`、`价格`、`技术路线`、`催化剂`、`风险`。
- 过滤范围：股票、行业、机构、分类或明确研报集合。
- 向量片段：片段摘要、研报标题、机构、发布日期、证据强度。
- 研报舆情：观点、机会、风险和关键事由。

### 最小输入

| 输入项 | 是否必需 | 缺失处理 |
|---|---|---|
| 查询文本 | 是 | 要求主 Skill 补充要找的指标或说法。 |
| 过滤范围 | 是 | 要求主 Skill 补充股票、行业、机构或分类。 |
| 片段结果或空结果说明 | 是 | 无结果时输出空态和可调整条件。 |

## 输出契约

| 输出项 | 类型 | 是否必出 | 说明 |
|---|---|---|---|
| 查询口径 | Markdown 段落 | 是 | 查询文本、过滤范围、时间范围。 |
| 证据片段表 | Markdown 表格 | 条件必出 | 片段摘要、来源、支持判断、证据强度。 |
| 证据强弱判断 | Markdown 清单 | 是 | 强/中/弱证据和原因。 |
| 缺口说明 | Markdown 清单 | 是 | 无结果、对象不明确、数值缺失、来源不足。 |
| `source_refs` | 结构化列表 | 条件必出 | 传递给最终写作 Skill。 |

## 业务规则

- 不得全库裸搜；必须有查询文本和过滤范围。
- 不得选择性筛选片段证明预设结论；需要同时保留反向或不支持证据。
- 片段没有明确对象、时间、指标或数值时，证据强度降级。
- 不展示内部报告编号、页码、片段位置、接口名或字段名。

## 输出骨架

```markdown
## 查询口径

## 证据片段
| 片段主题 | 来源 | 日期 | 摘要 | 支持判断 | 证据强度 |
|---|---|---|---|---|---|

## 证据强弱与缺口

## 可调整检索方向
```

## 验收标准

- 同时具备查询文本和过滤范围。
- 证据片段可追溯到研报标题、机构和发布日期。
- 不把片段包装成确定事实。
- 不直接取数。
