# 多篇研报对比

本原子 Skill 只消费 `investoday-research-report-query` 的多篇研报样本、舆情、片段和预测评级输出，不直接调用接口。

## 输入要求

### 可接受输入

- 至少两篇可定位研报：标题、机构、发布日期、摘要。
- 研报观点、机会、风险、情绪和关键事由。
- 评级、目标价、EPS、净利润预测样本。
- 片段证据和 `source_refs`。
- 用户指定对比维度：共识、分歧、评级、目标价、预测、风险、催化剂。

### 最小输入

| 输入项 | 是否必需 | 缺失处理 |
|---|---|---|
| 至少两篇可定位研报 | 是 | 当前样本少于两篇时说明无法对比。 |
| 研报来源信息 | 是 | 缺标题/机构/日期时不得作为强对比来源。 |

## 输出契约

| 输出项 | 类型 | 是否必出 | 说明 |
|---|---|---|---|
| 对比范围 | Markdown 表格 | 是 | 研报数量、机构、日期范围、对象。 |
| 共识观点 | Markdown 清单/表格 | 是 | 多篇研报共同认可的逻辑和风险。 |
| 分歧对比 | Markdown 表格 | 是 | 评级、目标价、预测、逻辑、风险差异。 |
| 预测评级明细差异 | Markdown 表格 | 条件必出 | 涉及预测样本时，按机构列出日期、研报、评级、目标价/EPS/净利润预测、预测/评级变化和支持的判断。 |
| 证据强弱 | Markdown 表格/段落 | 是 | 来源数量、时点、片段支持、样本局限。 |
| 冲突与缺口 | Markdown 表格 | 条件必出 | 冲突来源、差异原因、暂定处理。 |
| `source_refs` | 结构化列表 | 是 | 传递给最终写作 Skill。 |

## 业务规则

- 多篇研报发布时间跨度较大时，必须说明时点差异。
- 不同机构预测口径不一致时，不强行平均。
- 涉及评级、目标价或盈利预测差异时，必须使用机构级预测明细单表；默认按研报发布日期倒序展示最近 5 家机构，同一机构只保留最新一篇。
- 预测明细表固定列为：日期、机构、研报、评级、目标价、T+1 EPS、T+2 EPS、T+3 EPS、T+1 净利润预测、预测/评级变化、支持的判断。
- 预测明细空字段统一写“—”，不得补估或编造。
- 当前样本不支持可比计算时，只列出样本，不计算比例。
- 不把机构共识写成确定事实或交易建议。

## 输出骨架

```markdown
## 对比范围

## 主要共识

## 分歧对比

## 预测评级与盈利预测差异
| 日期 | 机构 | 研报 | 评级 | 目标价 | T+1 EPS | T+2 EPS | T+3 EPS | T+1 净利润预测 | 预测/评级变化 | 支持的判断 |
|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |

## 冲突、缺口与样本局限

## 来源
```

## 验收标准

- 至少两篇可定位研报。
- 保留时点差异和来源差异。
- 不直接取数。
- 不输出交易建议。
