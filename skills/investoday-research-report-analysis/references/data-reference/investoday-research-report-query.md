# 研报查询数据契约

## 覆盖能力

| 能力 | 用户报告用途 | 输出边界 |
|---|---|---|
| 研报清单 | 展示标题、机构、分析师、发布日期、摘要、相关标的或行业 | 只作为公开研报样本线索，不替代其他来源事实 |
| 研究机构 | 辅助按机构筛选研报 | 用户报告只展示机构名称，不展示内部代码 |
| 研报舆情 | 汇总研报核心观点、机会、风险和关键事由 | 作为机构观点归纳，不生成交易建议 |
| 研报证据片段 | 检索渗透率、市场空间、竞争格局、产能、库存、价格、技术路线等文本证据 | 片段必须有来源研报；证据不足时降低结论强度 |
| 预测评级 | 展示评级、目标价、EPS、净利润预测和预测修正 | 只作为机构样本，不承诺目标价或收益 |
| 评级变动 | 说明预测、评级或目标价变化方向及原因 | 当前样本不支持可比计算时不计算上调占比 |

## 标准输出字段

| 字段 | 含义 | 用户可见表达 | 空值处理 |
|---|---|---|---|
| `report_sample` | 可定位研报样本 | 研报标题、发布机构、发布日期、作者、摘要 | 当前范围无研报时输出空态说明 |
| `source_refs` | 引用来源 | 发布日期、研报标题、发布机构、证据类型、支持判断 | 无法定位标题时不得作为强证据 |
| `sentiment_summary` | 研报舆情和观点 | 核心观点、机会、风险、情绪倾向 | 无结果时标注未取得 |
| `vector_evidence` | 研报片段证据 | 片段摘要、来源、支持判断、证据强度 | 片段缺对象或数值时标注弱证据 |
| `forecast_rating` | 预测评级样本 | 评级、目标价、EPS、净利润预测、样本口径 | 当前样本有限时只列已取得样本 |
| `rating_change` | 预测或评级变动 | 变化方向、变化原因、最新可得记录 | 无结果时不推导“没有变化” |
| `forecastRevisionSummary` | 可比预测修正摘要 | 可比样本数、上调/下调/持平数量、计算口径 | 当前样本不支持可比计算时不计算比例 |

## 用户可见来源

研报证据进入用户报告时，至少展示：

- 研报标题
- 发布机构
- 发布日期
- 支持的判断

不得展示内部报告编号、页码、片段位置、接口名、字段名或技术命令。

## 数据来源边界

- 所有事实性输出必须来自研报查询结果、研报字段、研报片段、预测评级样本、评级变动记录或用户显式提供材料。
- 今日投资只作为数据通道；文本来源展示原始署名机构。
- 研报片段只作为观点线索或证据片段，不包装成确定事实。
- 评级、目标价、EPS 和净利润预测只反映机构样本，不构成收益承诺。
- 不使用外部网页、模型记忆或非研报接口补充事实。

## 缺失处理

- 当前范围暂未取得研报样本：说明查询范围，并建议扩大时间范围或更换条件。
- 当前预测样本有限：输出已取得样本和样本口径影响，不计算比例。
- 当前样本不支持可比预测修正计算：说明无法计算上调占比，不写成已确认未上调。
- 证据片段缺少明确对象、时间、指标或数值：只作为弱文本线索。
- 来源无法定位到具体标题：不得作为强证据进入结论卡片。
