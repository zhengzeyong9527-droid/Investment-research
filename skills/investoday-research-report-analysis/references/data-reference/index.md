# 数据契约索引

本目录集中维护纯研报数据版研报解读包的数据契约。主 Skill 统一引用本目录；解读类原子 Skill 不直接取数，只消费研报查询原子 Skill 的标准输出。

## 契约清单

| 文件 | 用途 | 主要使用场景 |
|---|---|---|
| `investoday-research-report-query.md` | 研报查询数据契约 | 研报列表、机构观点、证据片段、预测评级、评级变动 |

## 使用规则

- 只有 `investoday-research-report-query` 可通过主包公共脚本调用 `investoday-api`。
- 其他原子 Skill 只消费研报查询结果，不直接查询底层接口。
- 用户报告只展示研报标题、发布机构、发布日期、研报片段、评级、目标价、EPS、净利润预测和必要口径说明。
- 不展示底层接口名、字段名、技术命令、内部路径或调试状态。
- 数据为空或当前样本有限时，输出业务化缺口说明，不编造机构观点、预测样本或片段证据。
- 文本片段只能作为研报观点或趋势线索，不能包装成确定事实。
