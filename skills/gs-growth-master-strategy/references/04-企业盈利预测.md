# 企业盈利预测

## 本文件定位

本 reference 承接成长大师企业盈利预测框架，负责在主 `SKILL.md` 编排下分析个股近年营收/净利润趋势、成长持续性、已取得的未来盈利预测、三情景预测、盈利确定性和 A 股财报雷区。它不是独立 skill，不维护底层查询口径。

## 调用链路

1. 主 skill 读取本 reference 后，调用 [财务分析](../references/gs-company-financial-analysis.md) 获取标准公司财务分析结论。
2. [财务分析](../references/gs-company-financial-analysis.md) 按其内部规则调用 [财务数据查询](../references/gs-company-financial-analysis.md/skills/gs-financial-data-query/SKILL.md) 生成财务 data pack，覆盖三大报表、财务指标、现金流、分红回购和行业对比。
3. 本 reference 基于外部分析 skill 返回结果，叠加成长大师盈利增长、三情景预测、成长确定性、财报雷区和业务证据校准。

这条链路是“成长大师 reference -> L2 分析 skill -> L1 查询 skill -> 数据服务 -> L2 返回标准输出 -> 成长大师方法论叠加”。

## 数据补充边界

完整报告和企业盈利预测单维度中，未来 1-3 年预测净利润必须通过 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出补充获取；该数据用于生成“未来预测”表格中的第一年、第二年、第三年预测净利润、对应增速、三年复合增速、预测口径说明、预测修正摘要和研报依据。`summary_fast` 轻量版也必须调用预测评级紧凑标准输出，但只吸收近期机构预测样本摘要、样本状态、预测方向和可靠性边界；不生成完整未来预测表，也不输出研报依据表。若 [财务分析](../references/gs-company-financial-analysis.md) 返回结果缺少业务规划、主营产品、产业链或研发费用证据，由财务分析及其绑定的财务查询 skill 在内部补足；若仍缺少分产品/地区收入、销量、单价、订单、客户、扩产、良率、研发、认证或供应链等研报类文本线索，完整报告、企业盈利预测单维度或用户明确追问时才消费 [研报数据查询](../references/gs-research-report-query.md) 的紧凑标准输出。补充数据只服务于盈利预测和雷区判断；用户可见输出可展示 `日期 + 研报标题 + 发布机构 + 用途` 作为来源表，不得暴露接口名、参数名、字段名、内部研报标识和原文定位信息或脚本名。

## 保留的业务框架

以下输入、预测、评分和输出框架继续沿用成长大师分析需求；数据链路统一由 L2/L1 原子 skill 提供标准输出。

## 输入要求

### 可接受输入

- A 股股票代码或完整股票名称。
- 主 skill 传入的股票代码、股票名称、行业名称和前置分析上下文。
- 用户明确只要求企业盈利预测或未来增速预测的请求。

### 最小输入

- 1 个可识别 A 股标的。

### 推荐输入

- 同时提供股票代码和名称。
- 主 skill 联动调用时传入行业生命周期和景气度结论，作为解释背景。

### 可选输入

- 可传入用户指定的关注期，例如未来 1-3 年；未指定时使用本 skill 默认口径。

### 默认假设

- 默认只基于公开披露数据、历史成长能力、研报预测评级样本和业务证据，不使用非公开信息。
- 完整报告和企业盈利预测单维度的未来 1-3 年预测净利润表格必须来自 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出；历史增速、行业合理区间、用户假设或前序分析结论不能替代该表格的预测净利润。`summary_fast` 轻量版不输出该表格。

### 输入校验

- 必须确认标的是 A 股且能获取基础财务数据；未来预测假设缺失时只能输出高不确定性情景。
- 预测口径必须保留不确定性说明，不输出确定收益或买卖建议。
- 若输出“预测上调占比”“机构预测是否上修”或类似表达，必须来自 [研报数据查询](../references/gs-research-report-query.md) 的预测修正摘要；不得根据未来预测净利润金额或模型推断自行判断上调。

### 缺失输入处理

- 无法识别标的时，要求补充股票代码或完整名称。
- 关键预测数据缺失时，按“失败处理”标注，不编造三情景预测。

### 示例输入

```text
分析 300750 宁德时代未来 1 到 3 年盈利增长。
仅调用企业盈利预测看看比亚迪未来增速。
```

### 反例输入

```text
用过去五年利润增速预测明年一定涨多少。
```

原因：不能把历史增速机械替代未来预期，也不能承诺结果。

## 触发方式

本文件不作为独立 Codex skill 触发，但支持由主 `SKILL.md` 单维度调用或全维度调用：
1. 用户要求完整成长大师分析时，作为第三个维度执行。
2. 用户明确只看企业盈利预测、盈利增长或未来增速时，作为单维度 reference 执行。
3. 用户普通单股轻量分析时，只作为 `summary_fast` 摘要来源，输出历史增长质量和最大缺口，不展开“未来预测”表格。

单维度执行时，只输出本文件定义的“企业盈利预测”；不得追加行业生命周期、行业景气度、PEG估值或成长股特征评级结论。主包只请求财务分析和研报查询的紧凑标准输出，不在本 reference 直接发起底层查询。


## 标准输出消费

主包只请求 [财务分析](../references/gs-company-financial-analysis.md) 的紧凑标准输出；财务分析内部负责调用 [财务数据查询](../references/gs-company-financial-analysis.md/skills/gs-financial-data-query/SKILL.md) 并处理缺口。若未来预测、业务规划或研报文本线索仍不足，再消费 [研报数据查询](../references/gs-research-report-query.md) 的紧凑标准输出。底层查询命令、分页、字段和原始返回只允许存在于 L1 查询 skill 内部。

本 reference 需要的标准输出分组：

- 历史经营趋势：近年营业收入、营业利润、归母净利润、扣非利润、同比和复合增速。
- 成长能力：营收增长、利润增长、每股收益增长、自由现金流增长及长期趋势。
- 现金流与资产负债表：经营现金流、收现能力、商誉、净资产、有息负债、应收账款、存货和利息覆盖能力。
- 治理和信用风险：股权质押、重大合同、诉讼仲裁、股权冻结、公告进展和信披风险线索。
- 未来预测样本：未来 1-3 年净利润或 EPS 预测、有效样本数量、样本分歧、预测口径、近 3 个月预测修正摘要和代表性研报来源。
- 业务证据：主营业务、战略规划、扩产、新业务、海外布局、核心产品收入/毛利贡献、产业链位置、上下游依赖和研发投入强度。

处理规则：

1. 历史趋势优先使用近 5 年公开财务标准输出；不足 5 年时按可得年度分析并降低置信度。
2. “未来预测”表格中的第一年、第二年、第三年预测净利润只能使用研报查询返回的预测样本，不得用历史增速、行业合理区间、用户假设或前序结论补填。
3. 乐观、中性、悲观情景只对有效预测样本做分位数、均值或中位数聚合；样本不足时保留字段并写“数据不足，无法判断”。
4. 当预测样本包含本次预测值和上次预测值时，必须由 [研报数据查询](../references/gs-research-report-query.md) 的预测修正摘要说明近 3 个月上调、下调、持平样本数和上调占比；若无法计算，必须写明是无预测样本、缺少上次预测值、同期限不可比或样本时间范围不足。
5. 业务规划、主营产品、产业链和研发投入只用于校准预测可靠性，不能编造销量、单价、客户结构、产能利用率、专利数量、研发人员或认证进度。
6. 若下游标准输出缺口无法补足，保留输出模板并说明“数据不足，无法判断”，不得在本 reference 中补写底层查询步骤。

## 营收增速合理性检查

在生成盈利预测前，必须对增速假设进行合理性校验：

**触发修正的阈值**：
- 用户指定的营收增速 > max(行业近3年平均营收增速 × 3, 50%) → 触发修正
- 用户指定的净利润增速 > max(行业近3年平均净利润增速 × 3, 50%) → 触发修正

**修正规则**：
1. 标准“未来预测”表格不使用用户指定增速填表，只使用 [研报数据查询](../references/gs-research-report-query.md) 返回的未来净利润预测样本。
2. 用户指定增速明显超出合理范围时，只在敏感性说明或风险讨论中说明该假设偏离 gs 返回的近期预测样本或行业合理区间。
3. 不得把用户指定增速、历史增速或行业平均增速修正后写入标准三情景预测净利润表。
4. 若无有效预测样本，保留输出字段并标注“数据不足，无法判断”，不直接拒绝分析。

## 三情景预测规则

### 乐观情景
- 净利润预测值取预测评级标准输出有效样本中的较高预测值或上分位数
- 净利润增速由预测净利润计算得到，不使用历史较高区间或行业合理上限估算
- 假设条件：行业景气持续上行、公司市场份额提升、核心产品产业链位置稳定且上下游扰动较小

### 中性情景（基准）
- 净利润预测值取预测评级标准输出有效样本的均值或中位数，优先使用中位数
- 历史增速趋势和主营产品收入/毛利结构只用于解释预测可靠性，不用于替代预测值
- 假设条件：当前态势延续、核心产品收入占比和毛利率保持稳定，无重大利好或利空

### 悲观情景
- 净利润预测值取预测评级标准输出有效样本中的较低预测值或下分位数
- 净利润增速由预测净利润计算得到，不使用历史低位或行业下行压力估算
- 假设条件：行业景气反转、政策收紧、竞争恶化或核心产品链条承压

## 盈利增长评级

| 评级 | 条件 |
|:----:|------|
| **高** | 历史增速稳定（标准差/均值<20%）+ 现金流与利润方向一致 + 预测假设来源清晰且口径可比 |
| **中** | 历史增速或已取得的未来盈利预测有一定波动（20%-40%）+ 业务证据能部分支撑 |
| **低** | 历史增速波动大（>40%）、预测假设缺失/来源不清，或现金流与利润明显背离 |

## A股财报雷区提示

分析中必须检查以下雷区信号（如有则强制标注）：

| 雷区 | 信号 | 检查方法 |
|------|------|----------|
| 商誉减值风险 | 商誉/净资产>30% | 使用资产负债表标准输出计算商誉占净资产比例 |
| 大股东质押风险 | 重要股东累计质押比例>60% | 使用治理与股权质押标准输出统计重要股东累计质押比例 |
| 存贷双高 | 货币资金高且有息负债高，利息保障倍数偏弱 | 使用资产负债表和财务衍生指标标准输出对照 |
| 应收款暴增 | 应收账款增速显著高于营收增速 | 使用资产负债表和利润表标准输出对照 |
| 现金流质量走弱 | 销售收现营收比或经营现金流营收比连续走弱 | 使用现金流与收现能力标准输出 |
| 扣非利润偏差 | 扣非/归母净利润<70% | 利润表对照 |

业务规划校准必须拆成四类证据：
- 公司文本证据：来自下游标准输出中的战略规划、项目进展、增长空间、产能和技术路径。
- 公告证据：来自下游标准输出中的近 6 个月公告和公开披露原文摘要。
- 机构预测样本纳入情况：判断公司规划是否已反映在 [研报数据查询](../references/gs-research-report-query.md) 获取的 gs 近期预测样本中。
- 潜在预期差：若公司文本或公告存在明确增量，但 gs 近期预测样本未体现，标注为潜在催化；若公告进展弱于文本规划，标注为压制因素。
- 主营产品与产业链证据：来自下游标准输出中的核心产品收入/毛利贡献、上下游依赖、产业链位置和研发投入强度；若只能取得产品收入/毛利而无销量/单价，不得编造量价拆分。

## 数据分析与结论生成规则

本节只用于内部分析检查，不定义用户可见的新结构。最终输出必须严格使用“输出格式”章节的 1-6 点标题、字段名和顺序，不得因为本节规则改写、合并、扩写或省略输出字段。

拿到数据后，必须先做口径核对和一致性检查，再组织用户可见输出。规则只约束分析方法，不预设结论方向；不得只罗列数据，也不得把接口返回值直接改写成结论。

### 1. 结论摘要生成

结论摘要必须放在输出的第一点，先回答“盈利增长怎么看”，再解释依据。至少包含：
- 盈利增长评级：只能使用高 / 中 / 低，不得使用“偏高”“高偏中”“中偏低”等过渡表述。
- 核心判断：未来 1-3 年增长中枢、盈利确定性、主要增长驱动和最大压制因素。
- 数据口径说明：使用主报告固定格式，写明“仅基于 gs 数据”、财务数据截至的报告期，以及机构预测样本为 gs 返回的近期预测样本；不得出现接口名、字段名或参数名。
- 不确定性提醒：明确预测假设不是公司承诺，且会随财报和行业变化更新。

### 2. 历史趋势分析

历史趋势不能只输出同比和复合增速，必须说明收入、归母净利润、扣非利润和现金流之间是否一致。
- 若收入增速、利润增速、现金流表现方向不一致，只描述不一致及其可能影响，不预设原因。
- 历史增速只能作为背景，不得替代未来预测假设。
- 历史趋势表的“同比”列必须优先输出数字百分比，不得只写“转亏”“扭亏”“亏损扩大”“亏损收窄”等状态词。
- 当利润由正转负、由负转正或亏损扩大/收窄时，仍按同比公式计算并输出数字百分比，状态说明放在括号中，例如 `-339.8%（转亏）`、`+42.1%（亏损收窄）`；前一年为负数时，用 `（本年利润 - 上年利润） / abs(上年利润)` 表达亏损扩大或收窄幅度；仅在前一年基数为 0、缺失或不可比时，才写“数据不足，无法判断”。
- 输出任何“利润增速高于/低于收入增速”的判断前，必须先比较同一时间范围、同一情景口径下的收入复合增速与净利润复合增速。

### 3. 预测假设与三情景分析

[研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出返回的未来净利润预测样本是未来情景的核心依据。必须同时说明“预测净利润”和“由预测净利润计算出的增速”，避免用户误以为增速是直接取得的确定事实；同时必须把代表性研报来源传递到“研报依据”字段。
- 乐观情景：使用有效预测样本中的较高预测值或上分位数；若极端值明显偏离基准，应说明样本分歧较大。
- 中性情景：使用有效预测样本的均值或中位数，优先使用中位数作为基准判断。
- 悲观情景：使用有效预测样本中的较低预测值或下分位数。
- 只要 gs 返回的近期预测样本中存在有效预测净利润数值，就必须把对应年度的预测净利润填入表格；不得用“数据分歧较大”“待后续数据复核”“预测样本出现亏损假设”等文字替代可取得的预测净利润。
- 样本分歧、预测方向冲突、样本时间差或口径变化只能写入“预测口径”“预测解读”或“假设前提”，不能替代未来预测表格中的金额和可计算增速。
- 风险点若来自研报文本线索，必须在风险说明中同步标注代表性研报出处（日期 + 研报标题 + 发布机构 + 用途）；不得展示内部研报标识和原文定位信息或字段名。
- 第一年的增速用“第一年预测净利润 ÷ 最近一年实际归母净利润 - 1”计算。
- 第二年和第三年的增速用相邻预测年度净利润计算。
- 三年复合增速用“第三年预测净利润 ÷ 最近一年实际归母净利润”的年化结果计算。
- 若最近一年实际归母净利润为负，第一年预测净利润为正时，第一年增速写“不适用（扭亏）”；若最近一年实际归母净利润为负且预测仍为负，可用 `（预测净利润 - 最近一年实际归母净利润） / abs(最近一年实际归母净利润)` 表达亏损扩大或收窄幅度，并在括号中说明。
- 若同时输出收入预测和净利润预测，必须分别计算收入复合增速和净利润复合增速，并在解释中保持大小关系一致。
- 若某预测年度有效样本不足，必须标注样本不足，并将确定性评级至少下调一级。
- 若预测样本跨度较大，必须说明预测不确定性较高，不能把基准值包装成强确定结论。
- 若预测修正摘要可得，`预测口径` 中必须写清“近3个月可比预测修正样本 xx 条，上调 xx 条，上调占比 xx%”；若不可得，必须写清具体缺口。不得只写“近期预测样本无法确认上调占比超过50%”。

### 4. 成长能力与业务证据分析

成长能力指标、公司文本、主营产品和产业链数据必须用于校准预测是否合理：
- 成长能力指标只用于辅助判断盈利确定性，不能替代未来预测假设。
- 主营产品和业务文本只用于说明预测假设的业务依据，不能编造销量、单价、客户结构或产能利用率。
- 若业务证据与 gs 返回的近期预测样本方向不一致，只说明差异和不确定性，不强行解释为催化或压制。
- 缺少销量、单价、产能利用率、客户结构等数据时，必须说明“无法做量价拆分”，不得编造。

### 5. 财报雷区分析

财报雷区必须解释“这个指标为什么重要”，不能只写“触发/未触发”：
- 现金流覆盖利润、商誉占净资产、应收账款、存货、有息负债、股权质押、扣非利润偏差均按阈值检查。
- 未触发阈值时，只说明“未构成主要观察风险”；触发阈值时，说明它可能如何影响盈利预测可信度。
- 不得因为单个财务指标良好就推出整体财务无风险。

### 6. 成长大师视角判断

成长大师视角只做收束判断，不新增段落结构：
- 必须输出固定字段 `盈利增长评级：高/中/低` 和 `评级依据：xxx`。
- 评级依据只能概括历史增长、已取得的未来盈利预测、现金流质量、主营增长证据和财报雷区对盈利确定性的影响。
- 不得在 `成长大师视角` 下改写成自由段落，或新增完整投资建议、估值判断、成长股特征判断。

输出强制约束：
- 必须完整保留 1-6 点编号和字段名。
- 若某字段数据不足，写“数据不足，无法判断”，不得删除字段。
- “历史趋势”表格的同比列必须直接写数字百分比；转亏、扭亏、亏损扩大或亏损收窄只能作为括号说明，不得替代同比数字。
- “未来预测”表格中的预测净利润只能来自 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出；不得用历史增速、行业合理区间、用户假设或前序分析结论补填。
- “未来预测”表格中已取得有效预测净利润时必须填入数值；预测样本分歧、方向冲突或可靠性不足只影响可靠性评级和解读，不得把可得数值改写为“数据不足”“数据分歧较大”或其他占位文字。
- “未来预测”表格前只输出 `预测口径` 和 `研报依据` 两个信息块，不得再拆成“预测样本数 / 预测假设可靠性 / 增速口径”三行；保持 C 端用户可读，不输出流程化解释。
- 预测修正摘要必须合并写入 `预测口径`，不得另起“上调占比说明”“预测修正过程”等流程化小节。可比样本可得时输出样本数、上调数和上调占比；不可得时输出具体缺口，不得泛泛写“无法确认”。
- 研报依据必须逐条展示，优先使用表格；不得把多个研报来源合并为一整段分号串联文本。
- 研报依据表是“未来预测”和“三情景预测”的硬绑定来源表：只要输出任一未来预测净利润、未来预测增速、三情景预测或基于机构预测的盈利增长评级，就必须在同一节内输出 `研报依据` 表格，且位置必须在三情景预测表之前。
- 若未来预测样本可得但研报日期、标题或机构缺失，不得删除 `研报依据` 表；必须保留表头并用“暂无可用数据”或“未能定位到具体标题，待后续数据复核”填充缺失单元格。
- 若 `## 企业盈利预测` 或完整报告的 `## 五、企业盈利增长预测` 已输出三情景预测表但没有 `研报依据` 表，视为本节未完成，必须先补齐来源表再输出最终答案。
- 研报依据只展示日期、研报标题、发布机构和用途；不得展示内部研报标识和原文定位信息、接口名或字段名。
- 若公开研报只定位到机构或日期、未能定位到具体标题，仍保留表格结构，并在对应单元格写“未能定位到具体标题，待后续数据复核”。
- 预测口径、预测解读、风险说明等字段必须分行呈现；同一字段文字较长时使用独立段落或列表，不把多个字段堆在同一自然段里。
- 不得把 `成长大师视角` 改写为自由段落；必须保留 `盈利增长评级` 和 `评级依据` 两个字段。

## 失败处理

- 无有效未来预测数据：保留“未来预测”表格和字段，预测净利润、增速、三年复合增速写“数据不足，无法判断”，并标注高不确定性；不得基于历史趋势或行业合理区间外推预测值
- 历史数据不足3年：提示"上市时间不足3年，历史数据有限，预测不确定性较大"
- 数据异常：不强行生成预测值，标注"数据存在异常波动，暂无法给出可靠预测"
- 用户自定义增速超出合理范围：按上述"营收增速合理性检查"规则作为敏感性说明或风险讨论，不写入标准三情景预测净利润表
- 补充标准输出缺失：标注"补充数据缺失，财报雷区/业务规划校准基于已获取数据完成"，不阻断盈利预测主流程
- 文本证据为空：不生成具体业务规划、项目进展或催化剂，标注"未获得明确文本证据"
