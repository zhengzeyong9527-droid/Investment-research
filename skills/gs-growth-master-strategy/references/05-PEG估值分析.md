# PEG估值分析

## 本文件定位

本 reference 承接成长大师 PEG 估值分析框架，负责在主 `SKILL.md` 编排下计算和解释 PEG、成长匹配、安全边际、周期股失效边界和慢增长型局限。它不是独立 skill，不维护底层查询口径。

## 调用链路

1. 主 skill 读取本 reference 后，调用 [估值分析](../references/gs-valuation-analysis.md) 获取估值分析结论。
2. [估值分析](../references/gs-valuation-analysis.md) 按其内部规则调用 [估值数据查询](../references/gs-valuation-analysis.md/skills/gs-valuation-data/SKILL.md) 获取 PE/PB/PS、市值、历史估值、行业估值、成长指标、分红回购和现金流辅助数据。
3. 若估值链路未返回未来 1-3 年净利润预测或预测增速，本 reference 消费 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出补充未来盈利预测，不依赖 `references/04-企业盈利预测.md` 先行输出。
4. 本 reference 基于估值数据和未来盈利预测，叠加成长大师 PEG 公式、成长匹配、周期股 PEG 失效和慢增长型 PEG 局限规则。

这条链路是“成长大师 reference -> L2 分析 skill -> L1 查询 skill -> 数据服务 -> L2 返回标准输出 -> 成长大师方法论叠加”。

## 数据补充边界

若 [估值分析](../references/gs-valuation-analysis.md) 返回结果缺少本 reference 必须使用的 TTM 市盈率、历史估值分位、行业估值对照或慢增长辅助证据，先由估值分析及其绑定的估值查询 skill 在内部补足；若仍缺少周期行业库存、价格、开工率、吨利或景气高低位等研报类文本线索，消费 [研报数据查询](../references/gs-research-report-query.md) 的紧凑标准输出。若缺少未来 1-3 年净利润预测、EPS 预测或可用预测增速，本 reference 可使用 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出作为 PEG 分母来源。补充数据只服务于 PEG 与成长匹配判断，最终用户输出不得暴露接口名、参数名、字段名、内部研报标识和原文定位信息或脚本名。

若行业 PEG 缺失但已能识别股票所属行业或行业代码，估值链路必须补齐“二级行业 -> 行业指数代码 -> 行业 PE -> 同口径行业基准预测增速”链路：由估值查询 skill 先取得个股稳定对比行业，再解析行业层级；若稳定对比行业为二级行业，直接使用该二级行业；若为三级或更细行业，先解析到同体系二级行业；只有二级行业无法形成有效行业指数 PE 或有效行业基准预测增速时，才回退同体系一级行业。回退时行业 PE、行业基准预测增速和行业名称必须全部来自同一一级行业口径。用户可见输出只展示行业名称和必要的“一级回退口径”说明，不展示行业代码。

行业 PEG 状态必须区分“数据未返回”和“数据已返回但公式不适用”。若二级行业指数估值已返回但行业 PE 为负数或为 0，不得写“行业估值未返回”“行业当前 PE 未返回”或“行业基准 PEG 未返回”；必须标注“二级行业 PE 为负/为 0，行业基准 PEG 不适用”，并继续尝试同体系一级行业回退。若一级行业 PE 与同口径行业基准预测增速均有效，必须输出一级回退行业基准 PEG；若一级回退也不可用，再说明对应缺口。

行业 PEG 不得停在行业行情统计或行业 PE 分位。若已取得行业代码，但只取得行业 PE/PB/PS 五年分位，必须继续解析行业指数代码并查询行业指数估值；五年分位只能说明估值水位，不能写成“行业当前 PE 未返回”，也不能替代行业当前 PE 计算行业 PEG。

外部估值分析 skill、估值查询 skill 或补充标准输出单点失败时，不得直接输出“数据服务不可用”。必须先由估值分析原子 skill 完成最小可用性判断：确认标的可识别，并尝试返回最新估值、历史估值、PE/PB/PS 或估值日期中的任一核心证据。只要任一核心估值证据可得，就输出有限 PEG 估值分析；未来预测、行业 PEG、分红回购或现金流辅助缺失时，只标注对应字段数据不足，不阻断 PEG 主流程。

即使用户要求列出调用接口、字段和参数，也必须优先遵守主 skill 的用户可见输出禁则：不得展示接口名、参数名、字段名、内部路径、原始 JSON 或 trace。应明确改为“无法展示内部调用明细，以下按业务口径说明数据来源和估值含义”，并继续输出业务化 PEG 分析。

用户同时请求 PEG 分析和工程明细时，必须先剥离工程明细请求，再按 PEG 分析流程取数和输出。不得因为不能展示接口、字段、参数、原始 JSON 或 trace，就输出“国信证券数据服务暂不可用”。若最小可用性探测未实际完成，也不得直接使用全局不可用提示；应输出有限 PEG 结构并标注“估值数据仍待后续数据复核”。

用户可见 PEG 输出必须服从主报告固定数据口径：只写“仅基于 gs 数据”，并区分行情估值日期、行业估值日期、财务报告期和机构预测样本口径。不得点名接口、参数或内部字段，也不得写成“资料参考：投资者关系、年报、季报”等未经当前链路逐项校验的具体资料清单。若预测依据来自 [研报数据查询](../references/gs-research-report-query.md) 的标准输出，且具备明确出处，可展示 `日期 + 研报标题 + 发布机构 + 用途` 作为研报出处；不得展示内部研报标识和原文定位信息、参数或内部字段。

## 保留的业务框架

以下输入、公式、情景测算、失效边界和输出框架继续沿用成长大师分析需求；数据链路统一由 L2/L1 原子 skill 提供标准输出。

## 输入要求

### 可接受输入

- A 股股票代码或完整股票名称。
- 主 skill 传入的股票代码、股票名称、行业名称、盈利预测和景气度上下文。
- 用户明确只要求 PEG、估值或市盈率成长匹配分析的请求。

### 最小输入

- 1 个可识别 A 股标的。

### 推荐输入

- 同时提供股票代码和名称。
- 主 skill 联动调用时传入盈利预测结论和行业生命周期阶段。

### 可选输入

- 可传入周期股、缓慢增长型或行业景气高低位等前置判断，用于解释 PEG 适用边界。

### 默认假设

- 默认使用 TTM 市盈率；未来 1-3 年净利润复合增速优先使用 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出、用户明确输入或主流程已传入的有效预测。
- PEG 仅作为成长股估值工具，不替代完整投资判断。

### 输入校验

- 必须确认标的是 A 股且能获取 TTM 市盈率；未来预测缺失时 PEG 只能标注为数据不足或不适用。
- 亏损、微利、负增长、周期波动较大、未来预测缺失或预测来源不清时，必须标注 PEG 参考价值有限。

### 缺失输入处理

- 无法识别标的时，要求补充股票代码或完整名称。
- 关键估值或预测数据缺失时，按“失败处理”标注，不编造 PEG。

### 示例输入

```text
分析 300750 宁德时代的 PEG。
仅调用 PEG 估值看看比亚迪现在贵不贵。
```

### 反例输入

```text
用 DCF 给宁德时代估个目标价。
```

原因：本 skill 处理成长大师 PEG 估值，不处理纯 DCF 或目标价承诺。

## PEG公式（A股本土化口径）

```
PEG = TTM市盈率 ÷ 未来1-3年净利润复合增速
```

- **分子**：最新TTM市盈率（滚动12个月PE），反映当下真实估值水平
- **分母**：未来1-3年净利润复合增速（非历史增速），使用 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出、用户明确输入或主流程已传入的有效预测
- **观察口径**：PEG < 1 表示估值倍数数值低于未来增速数值，需重点核查预测兑现质量；PEG ≈ 1 表示 PE 与未来增速数值接近；PEG > 1 表示未来成长兑现要求更高。不得据此直接输出估值吸引力定性结论。

## 触发方式

本文件不作为独立 Codex skill 触发，但支持由主 `SKILL.md` 单维度调用或全维度调用：
1. 用户要求完整成长大师分析时，作为第四个维度执行。
2. 用户明确只看 PEG、估值、成长匹配或当前贵不贵时，作为单维度 reference 执行。

单维度执行时，只输出本文件定义的“PEG估值分析”；不得追加行业生命周期、行业景气度、企业盈利预测三情景全文或成长股特征评级结论。主包只请求估值分析和研报查询的紧凑标准输出，不在本 reference 直接发起底层查询。

## 标准输出消费

主包只请求 [估值分析](../references/gs-valuation-analysis.md) 的紧凑标准输出；估值分析内部负责调用 [估值数据查询](../references/gs-valuation-analysis.md/skills/gs-valuation-data/SKILL.md) 并处理缺口。PEG 单维度请求可以直接消费 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出补充未来盈利预测，不要求先执行企业盈利预测 reference。底层查询命令、分页、字段和原始返回只允许存在于 L1 查询 skill 内部。

本 reference 需要的标准输出分组：

- 最新估值：TTM 市盈率、PB、PS、企业价值倍数、估值日期和可作为 PEG 分子的有效 PE。
- 历史估值水位：近年 PE 区间、中位数、分位位置和历史相对水位。
- 未来盈利预测：未来 1-3 年净利润预测、EPS 预测或可用预测增速、样本数量、分歧度和代表性研报来源。
- 行业估值对照：行业名称、行业层级、是否一级回退、行业平均 PE/PB/股息率、行业基准预测增速和行业基准 PEG 是否可得。
- 行业 PEG 原料：股票所属行业、行业名称、行业层级、行业指数 PE/PB、行业估值日期、行业基准预测增速、行业基准 PEG、行业 PEG 口径说明和不可得原因。
- 慢增长辅助证据：分红稳定性、回购、经营现金流、收现能力、货币资金、负债结构和商誉风险。
- 周期边界线索：库存、价格、开工率、吨利、景气高低位等用于解释 PEG 是否失真。

处理规则：

1. 若估值分析返回任一核心估值证据，必须继续输出有限 PEG 估值分析；未来预测、行业 PEG、分红回购或现金流辅助缺失时，只标注对应字段数据不足。
2. PEG 分子必须使用可解释的当前 PE；PB、PS、历史估值和估值日期只作辅助水位，不构成 PEG 可计算条件。
3. PEG 分母必须使用未来 1-3 年净利润复合增速、EPS 预测增速或用户明确输入的有效预测；不得使用历史增速、诊断 PEG 或行业增速替代。
4. 预测评级标准输出必须提供代表性研报来源；用户可见输出只展示日期、研报标题、发布机构和用途。
5. 行业 PEG 不可得前，必须确认已按二级行业优先、一级行业回退的顺序尝试行业层级解析、行业指数估值和同口径行业基准预测增速补充；不得跳过该链路直接写“行业PEG不可得/不适用”。若二级行业 PE 为负数或为 0，应先标注二级行业 PEG 不适用，再继续一级行业回退；不得把 PE 为负或为 0 写成数据未返回。若股票估值、财务评分或行业归属标准输出已返回对比行业，应先解析其层级，稳定落到同体系二级行业；不要改用行业名称模糊搜索，也不要额外指定与返回口径不一致的行业体系过滤条件，避免把可解析行业误判为空结果。
6. 慢增长辅助证据只在低增速、低成长或 PEG 失真场景展开；不匹配时只作为补充观察。

## PEG计算与中性观察

### 核心计算

1. 从估值分析标准输出获取当前 TTM 市盈率。
2. 从预测评级标准输出或已传入预测输入获取未来 1-3 年净利润复合增速。
3. 计算：`PEG = 当前 TTM 市盈率 / 未来净利润复合增速`

### 多情景PEG

| 情景 | 净利润增速 | PEG值 | vs 行业名称行业基准PEG | 观察含义 |
|------|-----------|-------|:--------------:|----------|
| 乐观 | xx% | x.xx | xxx | 成长兑现压力较低/中等/较高 |
| 中性（基准） | xx% | x.xx | xxx | 成长兑现压力较低/中等/较高 |
| 悲观 | xx% | x.xx | xxx | 成长兑现压力较低/中等/较高 |

该表格用于 PEG 单维度和完整报告；普通轻量版 `summary_fast` 不默认嵌入三情景 PEG 表格，也不为了补齐该表额外调用完整预测链路或行业 PEG 深链路。轻量版可复用 `forecast_snapshot` 的近期机构预测样本摘要，只输出估值成长匹配摘要；未展开的 PEG 三情景不写入用户可见占位。当用户明确询问 PEG、估值成长匹配或查看完整分析时，必须展示 `情景 / 净利润增速 / PEG值 / vs 行业名称行业基准PEG / 观察含义` 五列。`vs 行业名称行业基准PEG` 必须展示本次使用的行业名称，例如 `vs 电池行业基准PEG`；若使用一级回退，写成 `vs 电力设备行业基准PEG（一级回退口径）`。若 PE、未来净利润增速或行业基准 PEG 不足，完整/单维度先补齐必要链路；公式不成立写“不适用”，事实口径仍不能闭合时在风险/边界中自然说明“行业对照口径仍需复核”；不得用一句概括性文字替代表格，也不得编造 PEG 或行业 PEG。

行业侧默认只输出一个同口径行业基准 PEG，不随个股乐观 / 中性 / 悲观情景硬拆。三情景表中个股三行均与同一个行业基准 PEG 比较。只有底层明确返回同一预测期限、同一行业层级下的高 / 中 / 低预测情景，才允许额外输出行业侧三档 PEG，并必须在文本中说明该情景来源；不得把不同期限的预测字段拼接为行业侧三档 PEG。

### PEG数值区间与观察含义

- PEG < 0.5：估值倍数显著低于预测增速数值，需优先验证预测可靠性和盈利质量。
- 0.5 ≤ PEG < 1.0：估值倍数低于预测增速数值，成长兑现压力相对较低。
- 1.0 ≤ PEG ≤ 1.5：估值倍数与预测增速数值大致接近，需结合历史水位和兑现确定性观察。
- 1.5 < PEG ≤ 2.0：估值倍数高于预测增速数值，成长兑现压力较高。
- PEG > 2.0：估值倍数明显高于预测增速数值，对未来盈利兑现要求很高。

### 行业对照

- 个股PE vs 行业平均PE（由行业指数PE代表）
- 个股PB vs 行业平均PB（由行业指数PB代表）
- 个股股息率/分红稳定性 vs 行业平均股息率（由行业指数股息率代表）
- 个股PEG vs 行业名称行业基准PEG（行业指数 PE / 同口径行业基准预测增速）

行业 PEG 必须按以下链路形成，不得直接用行业代码查询行业 PE，也不得用行业 PE 分位替代当前 PE：

1. 个股行业 PEG 默认优先采用二级行业口径。先从估值数据、财务评分或行业归属标准输出取得稳定对比行业，再解析其行业层级；若返回二级行业，直接使用该二级行业；若返回三级或更细行业，解析到同体系二级行业；若只返回一级行业，可先按一级作为候选，但必须在内部记录二级行业不可得原因。
2. 用二级行业精确解析对应行业指数代码；行业代码不是行业指数代码，不能直接作为行业指数估值入参。若二级行业无法解析行业指数代码、无行业指数 PE、行业指数 PE 为负数或为 0，或无可用行业预测增速，才允许回退同体系一级行业。按行业名称模糊查询只作为最后补充路径，且多候选时不得计算行业 PEG。
3. 用解析得到的行业指数代码取得行业当前 PE/PB、股息率和估值日期，其中行业指数 PE 代表行业平均 PE。用户可见 `同行业对比` 必须写出行业名称和层级，如“行业对照：电池（二级行业）”；若回退一级，写“行业对照：电力设备（一级回退口径）”。
4. 用同一行业代码取得行业基准预测净利润增速。行业基准增速优先使用未来 1-3 年净利润预测的同口径复合增速；若底层提供 T+1、T+2、T+3 年度净利润预测增速，则用几何复合计算行业基准增速。若只有单一三年字段，必须确认其为未来三年复合预测口径；若与其他前瞻字段明显冲突，标注口径冲突，不直接采用。回退一级行业时，行业指数 PE 和行业基准预测增速必须同时使用一级口径。
5. 行业基准 PEG = 行业指数 PE / 行业基准预测净利润增速百分数；行业指数 PE 为负数或为 0、增速为负、接近零、缺失或口径冲突时不计算。行业指数 PE 与行业基准预测增速原则上必须来自同一稳定行业口径；若使用一级回退口径，内部需记录回退原因，用户侧只说明“一级回退口径”。
6. 行业行情统计中的 PE/PB/PS 五年分位只能说明水位，不能替代行业当前 PE，也不能单独支撑行业 PEG。
7. 行业 PEG 失败原因必须分成五类写入内部校验：二级行业无法解析、二级行业 PE 缺失、二级行业 PE 为负数或为 0 导致不适用、二级行业基准预测增速缺失/为负/接近零/口径冲突、一级回退也不可用。不得笼统写“行业当前 PE 未返回”。

## 周期股PEG失效规则

**以下行业类型必须标注PEG失效提示：**
- 煤炭、钢铁、有色金属、基础化工、建筑材料、汽车、农林牧渔（强周期行业）
- 景气高位：PE偏低但盈利处于周期顶峰，PEG虚低（价值陷阱）
- 景气低位：PE偏高或亏损，但盈利处于周期底部，PEG虚高（逆向机会）

周期股不适用标准 PEG 观察口径，需替代说明：
> 该股属于周期型行业，PEG 参考价值有限：当前处于行业景气 xxx 位，PE 和盈利增速均受周期影响，PEG 数值不能直接作为估值判断依据。

## 缓慢增长型PEG局限性

**以下情况须标注PEG参考价值有限的提示：**

- **缓慢增长型标的**（净利增速1%-3%）：低速增长使 PEG 天然偏高（分母极小），PEG<1 并不代表估值具备吸引力，可能只是成长性不足或盈利基数波动的反映。
- **微增长/零增长标的**（净利增速<1%）：增速接近零时PEG公式数学上发散，不具有计算意义。

对这些标的，在估值结论中强制追加如下提示：
> 该股属于缓慢增长型/低成长标的（净利增速 xx%），PEG 参考价值有限。低增速下 PEG 偏低不一定代表成长吸引力，可能反映标的缺乏成长性，不符合成长投资方法论对快速增长型公司的偏好。需要结合股息率、PB、现金流和资产负债表一起观察。

若触发慢增长型提示，必须补充三类证据：
- 股息证据：近3年分红是否稳定，股息率是否能支撑类固收逻辑。
- 现金流证据：销售收现营收比、经营现金流营收比是否稳定。
- 资产负债证据：货币资金、负债结构、商誉等是否存在削弱估值解释力的风险。

**缓慢增长型 PEG 与成长投资偏好对照**：
| 增速 | PEG<1 | PEG≈1 | PEG>1 |
|------|:-----:|:-----:|:-----:|
| <1%（微增长） | 数学发散，无意义 | 无意义 | 无意义 |
| 1%-3%（缓慢增长） | 成长性不足，需谨慎解释 | 成长兑现压力中等 | 成长兑现压力较高 |
| 3%-10%（稳健增长） | 成长兑现压力较低 | 成长兑现压力中等 | 成长兑现压力较高 |
| 10%-20%（快速增长） | 成长兑现压力较低 | 成长兑现压力中等 | 成长兑现压力较高 |
| >20%（高速增长） | 成长兑现压力较低 | 成长兑现压力中等 | 成长兑现压力较高 |

> 注意：增速越低的标的，PEG 偏低越不能直接解释为估值吸引力，需结合盈利质量、现金流和负债结构观察。

## 数据分析与结论生成规则

本节只用于内部分析检查，不定义用户可见的新结构。最终输出必须使用“输出格式”章节的 1-5 点标题、字段名和顺序，但各字段内容必须基于个股数据生成，不得机械照搬模板提示。

### 1. 结论摘要生成

- 结论摘要必须作为输出第一点。
- PEG 观察只能使用：成长兑现压力较低 / 成长兑现压力中等 / 成长兑现压力较高 / 不适用 / 数据不足。
- 必须先给中性观察，再用少量关键数据支撑；摘要中最多出现 1-2 个核心指标，例如 PEG、核心增速或历史/行业相对水位，不得完整罗列 PE、增速、PEG、历史分位和行业对比。
- 必须说明 PEG 计算口径的核心含义；不得把 PEG 单独写成完整投资结论。
- 若关键数据缺失，保留字段并写“数据不足，无法判断”。

### 2. 关键依据解释

- 关键依据是具体数据的主要承载位置，必须形成“数据 + 含义”的表达。
- 当前估值水平必须解释其历史/行业相对水位和成长兑现要求，而不是只列 PE/PB/PS。
- 未来增长预期必须解释其作为 PEG 分母的质量、确定性或分歧。
- 未来增长预期若来自机构预测样本，必须说明样本数量、预测期和分歧度的业务含义；来源统一写为“gs 返回的近期预测样本”。不输出接口名、字段名或内部调用细节；证券公司、研究机构或媒体名称只在具备明确研报出处时展示。
- 同行业对比必须解释相对估值位置或行业基准含义。
- 同行业对比必须写明行业名称、行业层级和是否一级回退；用户可见输出不得展示行业代码。
- 相对水位参考必须解释当前估值是否处于极端位置、中位附近或历史高低位。

### 3. PEG 口径核对

- PEG 必须基于当前估值水平和有效未来预测增速计算，不得使用历史增速替代。
- 若 PEG 单维度或完整报告执行时未收到已传入预测输入，必须先请求研报查询的预测评级标准输出；仍缺失后才能标注 PEG 分母不足。`summary_fast` 轻量版不为 PEG 分母额外触发完整补充，只复用 `forecast_snapshot` 的样本摘要；若样本为空，省略预测分句并降低估值成长匹配判断置信度。
- 输出任何 PEG 观察前，必须核对 PE、预测增速、行业对比和适用边界是否同一口径。
- 若预测增速为负、接近零、样本不足或分歧过大，必须标注 PEG 参考价值有限。

### 4. 情景测算与边界

- 个股情景测算只展示乐观 / 中性 / 悲观三种口径，不新增其他估值体系。
- 行业侧默认只展示行业基准 PEG；个股乐观 / 中性 / 悲观三行均对比同一个行业基准 PEG。不得用不同期限的行业预测字段拼接行业侧三档 PEG。若输出行业侧三档 PEG，必须确认底层存在同一预测期限下的高 / 中 / 低预测情景，并在同行业对比中说明。
- 行业 PEG、历史位置、股息、现金流、资产负债只作为辅助解释，不能替代 PEG 主结论。
- 适用边界必须按当前公司实际情况筛选输出：与当前公司不匹配的周期股提示、慢增长提示、亏损提示或微利提示不得出现。
- 强周期提示仅在公司所属强周期行业、景气高低位明显，或盈利波动会导致 PEG 失真时输出。
- 慢增长提示仅在预测净利润增速低于慢增长阈值时输出。
- 通用边界保留精简表达，重点说明预测假设偏差、PEG 不覆盖现金流和负债风险、单期 PE 受利润波动影响。
- 以下边界说明是候选提醒库，用于生成第 4 点时选择和改写；只输出与当前公司匹配的提醒，不得逐条照搬：
  - 周期股提示：若属于强周期行业，需结合行业景气位置理解估值，不宜机械套用 PEG。
  - 慢增长型提示：若增长较慢，PEG 偏低不一定代表估值吸引力，更可能反映成长性有限。
  - 补充观察：可结合股息、现金流、资产负债结构一起判断。
  - PEG 仅适用于盈利稳定增长的公司，对亏损/微利/周期波动大的公司参考价值有限。
  - PEG 未考虑负债结构、现金流质量、商誉等资产负债表风险。
  - PEG 基于未来预测假设，存在预测偏差。
  - 不同行业 PEG 可比性有限。
  - 单期 PE 受短期利润波动影响大，建议结合 3-5 年 PE 中位数综合判断。
- 不得在 PEG reference 中新增生命周期、景气度、盈利预测三情景全文或成长股特征评级结论。

### 5. 成长大师估值视角

- 成长大师估值视角只输出一条与当前股票最匹配的判断，不得把所有 PEG 场景模板全部列出。
- 判断格式为“PEG 状态 + 成长类型/盈利质量 -> 成长投资观察重点”，例如“PEG≈1 + 稳健增长型 -> 重点观察盈利兑现和现金流质量”。
- 判断后必须追加 1-2 句解释，说明该股票为什么匹配这一类；其中增长类型必须按上方“缓慢增长型PEG与成长投资偏好对照”的未来净利润增速区间确定，并在解释中写清楚对应区间和依据。
- 以下成长大师视角是候选判断库，用于生成第 5 点时选择最匹配的一条；不得全量输出：
  - PEG<1 + 成长期行业 + 盈利确定性高 → 成长兑现压力相对较低，继续验证预测质量
  - PEG≈1 + 稳健增长型 → 重点观察盈利兑现和现金流质量
  - PEG>1 + 缓慢增长型 → 成长兑现压力较高，需降低 PEG 解释权重
  - PEG<1 + 缓慢增长型 + 高股息 → 更接近防御型研究逻辑，而非高成长逻辑

## 失败处理

- 未来预测增速不可用：PEG 单维度或完整报告先请求研报查询原子 skill 的预测评级标准输出；仍不可用时，标注"该股票无有效未来预测增速数据，PEG无法计算"，不使用历史增速替代。`summary_fast` 轻量版只复用预测快照；样本为空时省略预测分句并降低估值成长匹配判断置信度。
- 未来 T+1 到 T+3 净利润预测不可得：可使用完整 EPS 预测增速作为弱代理并说明口径；若 EPS 预测也不可得，不使用诊断 PEG 替代，只保留 PE/PB/PS、历史估值水位和数据缺口说明
- TTM市盈率为负：标注"当前TTM市盈率为负，PEG不具有计算意义"，并给出PB等其他估值参考
- 未来预测来源不清、样本不足或假设跨度过大：标注"未来预测可靠性不足，PEG参考价值有限"
- 行业平均PE不可得：必须先尝试行业代码解析行业指数代码，并用行业指数估值补行业当前 PE；若已经拿到行业 PE/PB/PS 五年分位但未拿到当前 PE，不能停止，必须继续行业指数估值链路；仍不可得时，标注"行业平均PE不可得"，保留个股PEG测算，不编造行业PE
- 行业PEG不可得：必须先确认二级行业优先、一级行业回退链路均已尝试；当二级行业无法解析、二级行业 PE 缺失、二级行业 PE 为负数或为 0 导致不适用、二级行业基准预测增速缺失/为负/接近0/口径冲突，或一级回退也不可用时，标注对应原因，不编造行业PEG。若一级行业 PE 与行业基准预测增速均有效，必须输出一级回退行业基准 PEG，不能停留在二级行业“不适用”
- 估值数据日期有限：直接使用最近可得交易日估值，并在报告中标注数据日期
- 补充标准输出缺失：标注"补充数据缺失，慢增长辅助验证基于已获取数据完成"，不阻断PEG主计算
- 全局数据服务不可用：只有下游标准输出中的标的识别、最新估值、历史估值、行情估值和公开估值辅助证据均不可得时，才允许返回主 skill 的统一不可用提示；不得把单个标准输出缺失、预测缺口或用户索要工程细节升级为全局不可用。
