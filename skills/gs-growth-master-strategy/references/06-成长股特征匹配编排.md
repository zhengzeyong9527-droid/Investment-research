# 成长股特征匹配编排

## 本文件定位

本 reference 承接成长股特征匹配分析框架，负责在主 `SKILL.md` 编排下规定成长股特征 10 条特征匹配、定性状态、综合评级、批量筛选和成长投资方法论解释。它本身不是独立 skill；真正可独立调用的能力由 [成长股特征匹配](../references/gs-growth-master-growth-feature-match.md) 承载。

## 执行链路

1. 主 skill 读取本 reference 后，调用 [成长股特征匹配](../references/gs-growth-master-growth-feature-match.md) 获取单股或批量成长股特征匹配结果。
2. 成长股特征原子 skill 优先消费前四个 reference 的标准结论：`02-行业生命周期评估.md`、`03-行业景气度评估.md`、`04-企业盈利预测.md`、`05-PEG估值分析.md`。
3. 前四维未覆盖但成长股特征框架必须使用的数据，先检查已安装分析/查询 skill 是否能覆盖；若缺口属于赛道空间、渗透率、份额、壁垒、复购、机构覆盖、预测修正、战略清晰度等研报类证据，完整报告、成长股特征单维度或筛选 route 才调用 [研报数据查询](../references/gs-research-report-query.md) 的标准输出补充。`summary_fast` 轻量版不补跑这些深层证据，只输出匹配倾向和最大缺口。
4. 本 reference 最终只规定成长股特征匹配和综合评级的编排与输出边界，不重复展开前四维完整报告。

## 数据映射

- 特征 1-2：复用 [行业分析](../references/gs-industry-analysis.md) 的行业空间、周期、竞争和政策线索；行业查询层由其内嵌的 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 提供。
- 特征 3、7、10：复用 [财务分析](../references/gs-company-financial-analysis.md) 的成长持续性、利润质量、现金流质量、资产负债表稳健性、股东回报和治理相关证据；财务查询层由其内嵌的 [财务数据查询](../references/gs-company-financial-analysis.md/skills/gs-financial-data-query/SKILL.md) 提供。
- 特征 4：复用 [估值分析](../references/gs-valuation-analysis.md) 的 PEG、估值分位、成长匹配、安全边际、个股行情估值日期、稳定对比行业和行业估值日期；估值查询层由其内嵌的 [估值数据查询](../references/gs-valuation-analysis.md/skills/gs-valuation-data/SKILL.md) 提供。
- 特征 5、6、8、9：优先复用前四维结果和已安装查询 skill；若赛道空间、渗透率、份额、壁垒、复购、机构覆盖、预测修正、股东结构、管理层战略或认知差数据未覆盖，完整报告、成长股特征单维度或筛选 route 优先消费 [研报数据查询](../references/gs-research-report-query.md) 的研报文本、预测评级、预测修正摘要、评级变化和机构关注度标准输出；`summary_fast` 轻量版不输出深层特征证据占位。

## 数据补充边界

补充数据只服务于成长股特征匹配，不得改变 10 条特征库、定性匹配规则、综合评级和输出框架。最终用户输出可展示研报出处（发布日期 + 研报标题 + 发布机构），不得暴露接口名、参数名、字段名、内部研报标识和原文定位信息或脚本名；缺口无法补足时按“数据不足，无法判断”处理，不编造匹配状态。公开研报文本线索弱于结构化财务、估值、公告、合同和行业数据，只能用于解释匹配依据或风险短板。

## 保留的业务框架

以下输入、成长股特征库、定性匹配、批量筛选和输出框架继续沿用成长大师分析需求；数据链路统一复用前四维和 [成长股特征匹配](../references/gs-growth-master-growth-feature-match.md) 原子 skill。

## 输入要求

### 可接受输入

- A 股股票代码或完整股票名称。
- 主 skill 传入的生命周期、景气度、盈利预测和 PEG 上下文。
- A 股成长股特征批量筛选、行业成长股候选筛选或单股成长股特征匹配分析请求。

### 最小输入

- 单股模式：1 个可识别 A 股标的。
- 批量筛选模式：A 股全市场、行业范围或候选方向。

### 推荐输入

- 单股模式同时提供股票代码和名称。
- 主 skill 联动调用时传入前四个 reference 的结论，避免重复推断。
- 批量筛选模式明确行业、候选范围或筛选约束。

### 可选输入

- 可传入用户关心的成长股特征，例如成长速度、赛道空间、机构覆盖或管理层质量。

### 默认假设

- 单股模式默认输出成长股特征匹配报告。
- 批量筛选模式默认使用本 skill 固定候选行业与筛选规则，不自行扩展行业清单。

### 输入校验

- 单股模式必须确认标的是 A 股。
- 批量筛选模式必须剔除 ST、*ST、退市整理和上市不满 1 年标的。
- 不得把单一指标直接等同于成长股特征结论。

### 缺失输入处理

- 无法识别标的或筛选范围时，要求补充股票代码、完整名称、行业或筛选范围。
- 数据缺失时，按“失败处理”标注，不编造匹配状态。

### 示例输入

```text
分析 300750 宁德时代有没有成长股特征匹配潜力。
帮我筛选 A 股里未来可能出成长股特征的候选方向和标的。
```

### 反例输入

```text
用技术指标筛选短线高收益标的。
```

原因：本 skill 处理成长大师成长股特征，不处理纯技术面或短线交易筛选。

## 触发方式

本文件不作为独立 Codex skill 触发，但支持由主 `SKILL.md` 单维度调用或全维度调用：
1. 用户要求完整成长大师分析时，作为第六个维度执行。
2. 用户明确只看成长股特征、成长股特征匹配或批量筛选时，作为单维度 reference 执行。

单维度执行时，只输出本文件定义的“成长股特征匹配分析”；不得追加完整行业生命周期、行业景气度、企业盈利预测或 PEG 报告。主包只请求成长股特征匹配原子 skill 的紧凑标准输出，不在本 reference 直接发起底层查询。

**上下文复用**：可复用主 skill 已传入的生命周期、景气度、盈利预测和 PEG 观察；若未提供，则按本 reference 的数据映射补齐必要证据后形成定性匹配状态。单维度调用成长股特征时，即使不展开 PEG 完整报告，也必须消费估值分析的紧凑标准输出，补齐个股行情估值日期、稳定对比行业、行业估值日期和行业 PEG 可得性说明，用于固定数据口径与特征 4 判断。

## 标准输出消费

先复用前四个 reference 的行业、财务、估值和 PEG 标准结论，再请求 [成长股特征匹配](../references/gs-growth-master-growth-feature-match.md) 的紧凑标准输出。成长股特征原子 skill 内部负责消费行业、财务、估值和研报查询 skill 的标准输出并处理缺口；本 reference 只定义 10 条特征、定性状态、综合评级和输出边界。底层查询命令、分页、字段和原始返回只允许存在于 L1 查询 skill 内部。

本 reference 需要的标准输出分组：

- 成长能力：营收、利润、每股收益、自由现金流增长及趋势稳定性。
- 盈利质量：毛利率、ROE、营业利润率、净利率及行业相对位置。
- 财务健康：现金流、负债、利息覆盖、股东权益、财务风险和现金转化质量。
- 主营业务与产品：主营业务描述、产品结构、核心产品贡献、业务集中度、产品毛利率和普通投资者可理解程度。
- 赛道与壁垒：赛道空间、渗透率、市场份额、竞争格局、品牌渠道、技术路线、复购和产业链位置。
- 治理与管理层：战略清晰度、资本配置、回购或增发、关联交易、核心管理层变化、违规处罚、诉讼仲裁、股权冻结和信披质量。
- 机构关注与认知差：预测评级样本、预测修正摘要、覆盖变化、机构关注度、调研频次、股东户数、机构持股、筹码集中或扩散变化。
- 估值口径与行业对照：个股行情估值最近交易日、稳定对比行业、行业层级、行业估值最近交易日、行业平均 PE/PB、行业基准预测增速、行业基准 PEG 或明确不可得原因。
- 批量筛选基础：候选池、所属行业、上市时间、特别风险标识、总市值或成交活跃度等筛选辅助信息。

处理规则：

1. 特征 1-4 优先复用前四维标准结论，不重复展开完整行业、盈利或 PEG 报告。
2. 特征 5、8、9、10 如缺少公开文本证据，按 `references/08-调用链路与数据补充.md` 请求研报查询的紧凑标准输出；文本线索缺少对象、时间、指标或明确方向时，只能列为需验证线索，不参与匹配判断。
3. 主营产品、产业链和研发投入只用于校验核心产品贡献、业务简单性、壁垒和供应链依赖；不得推断供应商名单、专利质量、研发人员规模或认证进度。
4. 机构覆盖、调研、持股、筹码变化和预测修正摘要只能作为特征 9 的辅助证据，不得用单一覆盖数量或单一上调占比直接形成匹配结论。若使用“近期预测上调占比”解释认知差，必须来自研报查询原子 skill 的预测修正摘要；可比样本不足时写明缺口，不得泛泛写“无法确认”。
5. 固定数据口径中的“行业估值截至”不得仅因未运行完整 PEG 维度而写“未返回”。若已识别稳定对比行业，必须先由估值分析标准输出补齐二级行业优先、一级回退的行业估值日期；只有稳定对比行业无法解析、行业指数估值缺失或回退口径也不可用时，才允许省略标题下行业估值分句，并在特征 4 的风险或边界中用业务语言说明“行业对照口径仍需复核”。
6. 批量筛选由成长股特征原子 skill 生成候选池和代表性个股；本 reference 不维护候选池底层查询参数。
7. 若下游标准输出缺口无法补足，保留 10 项特征并写“数据不足，无法判断”，不得在本 reference 中补写底层查询步骤。

## 特征匹配与定性规则

单项特征固定 10 项，且每项只输出以下状态：`符合 / 较符合 / 不符合 / 数据不足`。不得新增状态，不得输出主观潜力分或非公式分值。综合评级只能按下述匹配状态公式计算，同一 10 项状态输入必须得到同一综合评级。

确定性计分公式：

- `符合 = 1分`
- `较符合 = 0.5分`
- `不符合 = 0分`
- `数据不足 = 0分`
- 总分满分 10 分，计算式为 10 项状态分数求和。

综合评级规则：

- `数据不足`：`数据不足` 项达到 5 项及以上；该规则优先于高 / 中 / 低。
- `高`：总分 `>=7.0`，且 `不符合` 不超过 2 项。
- `中`：总分 `>=4.0 且 <7.0`。
- `低`：总分 `<4.0`。

综合评级必须由匹配状态内部计算得出，但用户可见输出只展示 `综合评级`、`评级依据`、`核心匹配点`、`主要短板` 和 `需验证事项`；不得展示总分、状态数量、计算式、工程字段、内部调用过程或 trace。

| 特征编号 | 特征 | 匹配状态口径 | 证据要求 |
|:--------:|------|--------------|----------|
| 1 | 快速增长型/困境反转型 | 按公司类型与成长阶段定性判断 | 需要生命周期、历史成长或困境反转证据 |
| 2 | 行业成长期/景气上行 | 按行业阶段和景气方向定性判断 | 需要行业生命周期、景气指标或明确文本证据 |
| 3 | 净利润复合增速≥15% | 预测增速清晰且可解释时可标注符合或较符合 | 需要公开预测样本或有效预测增速 |
| 4 | PEG<1（TTM口径） | 只说明 PEG 数值与成长兑现压力，不给估值结论 | 需要 PE 和有效未来增速 |
| 5 | 中小盘+大赛道+渗透率 | 市值、赛道空间和渗透率证据共同支持时较符合 | 需要市场空间、渗透率或产能释放证据 |
| 6 | 业务简单易懂 | 业务模式可用普通语言解释时较符合 | 需要主营业务和产品结构证据 |
| 7 | 财务健康+无高负债 | 现金流、负债和财务风险证据稳定时较符合 | 需要财务分析标准输出 |
| 8 | 细分龙头/壁垒/复购 | 龙头地位、壁垒或复购证据明确时较符合 | 需要市场份额、毛利率、研发、渠道或复购证据 |
| 9 | 机构覆盖低/散户认知滞后 | 只能基于覆盖变化、预测修正摘要、调研、持股或认知差代理证据说明 | 不得用单一覆盖数量或单一上调占比直接下结论 |
| 10 | 管理层评估 | 只做证据说明，不给主观分数 | 需要战略、资本配置、人事稳定和信披质量证据 |

### 特征10「管理层评估」证据口径

| 子维度 | 定性判断口径 | 证据要求 |
|--------|--------------|----------|
| 管理层言论与战略清晰度 | 清晰一致 / 不清晰 / 数据不足 | 公开战略、发展规划或研报文本线索 |
| 资本配置效率 | 较稳健 / 存疑 / 数据不足 | ROE、回购、增发、关联交易和资本开支证据 |
| 关键人事稳定性 | 较稳定 / 波动较大 / 数据不足 | 核心管理层变化和治理公开资料 |
| 信息披露质量 | 风险较低 / 存在风险 / 数据不足 | 违规处罚、诉讼仲裁、公告和调研记录 |

## 批量筛选模式

当用户请求"A股有哪些符合成长大师成长股特征的股票"时，行业口径与行业生命周期、行业景气度 reference 一致：**一级行业**。候选行业来自 `references/growth-master-six-types.md` 的成长大师六类映射；候选池构建由成长股特征原子 skill 及其下游查询 skill 内部完成，主包不维护候选池查询参数。

### 候选一级行业（固定清单）

仅从 `references/growth-master-six-types.md` 的 **快速增长型**、**困境反转型** 相关行业映射中取行业（名称与本表一致）：

| 成长大师类型 | 一级行业 |
|----------|----------|
| 快速增长型 | 电子 |
| 快速增长型 | 计算机 |
| 快速增长型 | 通信 |
| 快速增长型 | 机械设备 |
| 快速增长型 | 国防军工 |
| 困境反转型 | 房地产 |
| 困境反转型 | 建筑装饰 |
| 困境反转型 | 传媒 |
| 困境反转型 | 休闲服务 |
| 困境反转型 | 纺织服装 |

### 执行步骤

1. 用上表 10 个 **一级行业名称** 作为候选范围（勿自行扩展）。
2. 请求成长股特征原子 skill 返回候选池标准输出，包括代表性个股、所属行业、候选池规模、排除规则和证据完整度。
3. 每个一级行业按总市值、成交活跃度或下游标准输出定义的代表性规则取 Top 3-5 只个股，剔除 ST、*ST、退市整理、上市不足 1 年标的。
4. 对候选股批量请求成长股特征原子 skill 的紧凑标准输出，按特征匹配规则形成定性状态和综合评级；管理层、认知差、筹码结构、主营产品、产业链和排除规则均消费对应标准输出。
5. 按综合评级和证据强度筛选 Top 10-20，报告中行业字段统一只写 **一级行业名称**；不得输出内部候选池构建细节。

## 数据分析与结论生成规则

本节只用于内部分析检查，不定义用户可见的新结构。最终输出必须严格使用“输出格式”章节的编号、字段名和顺序，不得因为本节规则改写、合并、扩写或省略输出字段。

### 1. 结论摘要生成

- 结论摘要必须作为输出第一点。
- 综合评级只能使用：高 / 中 / 低 / 数据不足。
- 必须先说明综合评级、评级依据、核心匹配点、主要短板和需验证事项，再进入特征匹配表。

### 2. 特征匹配分析

- 每项匹配状态必须来自已获取数据或已取得的前序分析结论，不得为了凑满 10 项编造证据。
- 数据缺失项必须保留并标注“数据不足”，不能删除或用主观判断补齐。
- 综合评级必须由 10 项匹配状态按固定公式内部计算得出；不得另行按语感、证据强度或主要短板自由改写评级；用户可见输出不得展示总分、状态数量或计算式。

### 3. 批量筛选分析

- 批量模式必须说明行业范围、筛选标准、候选池规模和排除规则。
- 不得把批量筛选结果写成确定收益排序；只能写“候选”“匹配状态”“核心亮点”和“需验证事项”。

### 4. 成长大师视角

- 成长大师视角只做特征匹配结果的收束说明，不新增段落结构。
- 不得在成长股特征 reference 中新增完整生命周期、景气度、盈利预测或 PEG 报告。
- 不得出现“买入/卖出”等交易指令。

## 失败处理

- 数据不足无法完成全部10项匹配：标注已验证项、需验证项和数据不足项，提示“以下 x 项因数据缺失仅作线索，综合评级待后续数据复核”
- 批量筛选时候选池标准输出超时：逐步缩减候选股票数量，优先分析行业龙头
- 概念分类数据缺失：使用所属行业与已获得的公开信息进行辅助判断，标注"概念分类数据未获取，赛道判断基于现有公开资料整理"
- 补充标准输出缺失：标注"补充数据缺失，成长股特征匹配基于已获取数据完成"，不阻断已有特征匹配
- 行业估值日期缺失：若稳定对比行业已识别，先补齐行业估值标准输出；仍缺失时省略标题下行业估值分句，并在风险或边界中自然说明“行业对照口径仍需复核”，不得直接把特征 4 或固定数据口径判为已完整
- 文本证据为空：不生成具体赛道空间、壁垒、战略清晰度判断，标注"未获得明确文本证据"
- 估值数据日期有限：直接使用最近可得交易日估值，并在报告中标注数据日期
