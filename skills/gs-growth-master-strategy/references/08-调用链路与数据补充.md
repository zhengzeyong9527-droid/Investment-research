# 调用链路与数据补充

## 核心链路

成长大师主 skill 只负责编排和叠加方法论，不把外部分析 skill 与查询 skill 写成“优先/次级”关系。标准链路固定为：

```text
成长大师主 SKILL.md
→ 对应 reference
→ 外部分析 skill
→ 外部查询 skill
→ 数据服务
→ 外部分析 skill 返回紧凑标准输出
→ 成长大师 reference 叠加成长大师方法论
→ 主 SKILL.md 汇总输出
```

最终用户输出不得暴露接口名、参数名、字段名、脚本名、安装目录或内部调用细节。

主 skill 和 `references/` 可以命名需要调用的 L2/L1 skill、所需标准输出分组和缺口处理规则，但不得写可执行 CLI/API 命令、分页参数、原始字段、接口路径或直接补接口步骤。`04/05/06` 只做业务编排、评分口径和输出模板，不维护查询参数。

## 数据缺口补充

1. 先使用对应 reference 的外部分析 skill 返回结果。
2. 若结果缺少成长投资方法论框架必须使用的数据，确认该分析 skill 是否可通过其绑定查询 skill 补足。
3. 若常规查询 skill 未覆盖该必要数据，先判断是否属于研报类缺口；属于研报类缺口时调用 [研报数据查询](../references/gs-research-report-query.md) 的标准输出补充。
4. 补充数据只能用于完成当前 reference 的判断，不得改变既定分析框架、输出结构或证据准入规则。
5. 仍无法补足时，写“数据不足，无法判断”或降低确定性，不编造结论。

向量证据准入规则：

1. 必须有查询文本，并具备股票、行业、机构或分类之一作为过滤范围。
2. 只有片段同时出现对象、时间、指标、数值或明确方向时，才进入对应维度判断。
3. 片段缺少对象、时间、指标、数值或方向时，只能写为“公开研报文本线索不足，待后续数据复核”。
4. 生命周期、景气度和成长股特征判断中的向量证据只做辅助解释，不并入行业景气硬评分，不替代结构化财务、估值、公告或合同证据。
5. 用户可见输出统一归入固定数据口径中的“gs 返回的近期预测样本”或文本线索，并可展示代表性研报出处（发布日期 + 研报标题 + 发布机构）；不得输出底层接口名、参数名、内部研报标识和原文定位信息或命令。

PEG 估值分析的未来盈利预测是独立补充口径：单维度 PEG 和完整报告不要求先执行企业盈利预测 reference；若估值分析/估值数据未返回未来 1-3 年净利润预测或预测增速，调用 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出补充 PEG 分母。`summary_fast` 轻量版不为 PEG 分母额外触发完整补充，只复用预测快照；样本为空时省略预测分句并降低估值成长匹配判断置信度。补充失败时只标注 PEG 分母不足，不把预测缺口升级为全局数据服务不可用。

PEG 估值分析的行业 PEG 也是独立补充口径：若估值分析/估值数据未返回行业 PEG，必须先由估值查询 skill 使用估值数据、财务评分或行业归属标准输出中的稳定对比行业解析行业名称、行业层级和行业指数；行业 PEG 固定优先使用同体系二级行业，三级或更细行业先解析到二级行业，只有二级行业无法形成有效行业基准 PEG 时才回退一级行业。行业指数 PE 来自行业指数估值，行业基准预测增速来自同一行业代码的行业预测标准输出或前序行业维度结果；回退一级行业时，行业 PE 与行业基准预测增速必须同时使用一级口径。行业侧默认只输出行业基准 PEG：优先使用未来 1-3 年净利润预测的同口径复合增速；若底层提供 T+1/T+2/T+3 年度预测净利润增速，则用几何复合计算；若只有单一三年字段，必须确认其为未来三年复合预测口径且不存在明显口径冲突。不得把不同期限字段拼接为行业侧三档 PEG。若已取得行业 PE/PB/PS 五年分位但未取得当前 PE，不能停止，必须继续行业指数估值链路。只有二级行业无法解析、二级行业 PE 缺失、二级行业基准预测增速缺失/不可用/口径冲突或一级回退也不可用时，才在风险/边界中自然说明“行业对照口径仍需复核”，不得在标题数据口径或 PEG 表中写占位话术。

企业盈利预测的“未来预测”表格在完整报告和盈利预测单维度中必须使用 [研报数据查询](../references/gs-research-report-query.md) 的预测评级标准输出获取未来 1-3 年预测净利润，并由预测净利润计算对应增速和三年复合增速；历史增速、行业合理区间、用户假设或前序分析结论只能用于解释可靠性和风险，不能补填该表。`summary_fast` 轻量版不输出该表。

机构评级趋势和预测修正的补充口径：个股完整/单维度模式下需要“近3月评级上调占比”“机构预测是否上修”时，必须消费 [研报数据查询](../references/gs-research-report-query.md) 的预测修正摘要。该摘要优先来自近期预测评级样本的本次预测值与上次预测值对比；评级变化标准输出只在用户明确询问变化原因时补充变动方向和原因，不作为轻量版默认调用。若只有预测样本但没有上次预测值或同期限可比字段，写“可比预测修正样本不足，无法计算上调占比”；不得把该缺口简化成“无法确认”，也不得用历史增速、文本片段或模型判断替代。`summary_fast` 轻量版不输出预测修正占位。

行业直问下的景气评分边界：行业生命周期和行业景气度可以通过 [行业分析](../references/gs-industry-analysis.md) 与 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 取得行业预测、景气、行情扩散、行业研报文本和政策/供需线索；这些证据只进入趋势依据、未来展望、核心驱动和景气拐点信号。当前 [研报数据查询](../references/gs-research-report-query.md) 的预测修正摘要是股票级标准输出，不作为行业直问评分项。行业直问不得临时挑选龙头股、代表股或单一研报样本替代行业级口径，也不得输出“机构评级趋势 0/1”；`03` 行业直问硬评分固定为 `ROE趋势x/2 + 毛利率趋势x/1 + 净利率趋势x/1 = x/4`。

## 成长股特征补充口径

成长股特征 reference 调用 [成长股特征匹配](../references/gs-growth-master-growth-feature-match.md)，并优先复用前四维结果：

- 行业空间、生命周期、景气、竞争和政策线索来自 `02-行业生命周期评估.md` 与 `03-行业景气度评估.md`。
- 成长、盈利质量、现金流、资产负债表和股东回报来自 `04-企业盈利预测.md` 与 [财务分析](../references/gs-company-financial-analysis.md)。
- PEG、估值分位、成长匹配和安全边际来自 `05-PEG估值分析.md` 与 [估值分析](../references/gs-valuation-analysis.md)。
- 主营业务、产品链、管理层、机构覆盖、股东结构和认知差若未被已安装 skill 覆盖，优先复用 [研报数据查询](../references/gs-research-report-query.md) 的研报文本、预测评级、评级变化和机构关注度标准输出；补充结果只进入成长股特征原子 skill 的标准输出。

单维度成长股特征调用不要求展开完整 PEG 报告，但不能跳过估值链路中的固定数据口径。若主流程未传入 `05` 的标准结论，成长股特征原子 skill 仍必须请求估值分析返回紧凑标准输出，至少覆盖个股行情估值日期、稳定对比行业、行业估值日期、行业平均 PE/PB、行业基准 PEG 可得性或不可得原因。固定数据口径中的“行业估值截至”必须来自行业指数估值最近交易日；行业 PE/PB/PS 五年分位、行业行情统计或行业实时行情不能替代该日期。

行业估值补充顺序与 PEG 行业对照一致：优先使用稳定对比行业解析同体系二级行业并取得行业指数估值；只有二级行业无法解析、二级行业指数估值缺失或同口径行业基准增速不可用时，才允许回退一级行业。回退失败后不得在用户可见数据口径中写“行业估值截至暂无可用数据”，应省略标题下行业估值分句，并在对应风险/边界中说明“行业对照口径仍需复核”。若稳定对比行业已经能解析并取得行业指数估值日期，不得输出“行业估值截至未返回”。
