# 行业层级与代码口径

> 个股成长大师全维度分析仍固定使用个股所属一级行业。涉及行业识别、行业层级确认和行业数据获取时，由行业 reference 调用 [行业分析](../references/gs-industry-analysis.md)，并由其通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 获取行业口径和行业数据；查询 skill 未覆盖但成长投资方法论框架必须使用的数据，按 `references/08-调用链路与数据补充.md` 先判断研报类与非研报类缺口，研报类缺口统一调用 [研报数据查询](../references/gs-research-report-query.md) 标准输出补充。用户可见输出始终使用用户原始输入的行业名称。

## 使用说明

- 一级行业代码为 **6 位数字**，末 4 位为 `0000`（如 `270000` = 电子）。
- 个股模式通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 由股票反查一级、二级、三级行业名称与代码，但成长大师全维度分析和个股行业维度 reference 均使用一级行业作为分析口径。
- 行业直问模式通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 的行业基础能力识别用户行业词。若最佳匹配为一级行业，直接使用该一级行业取数；若结果中存在二级行业，优先选择排序最靠前的二级行业分析；若用户命中三级行业，保留用户原始行业名称用于展示，并按 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 的三级回退规则确认所属二级行业后作为内部取数口径。
- 对三级行业进行分析时，若景气度和预测可用但行情、估值、研报等接口缺失，应回退二级行业作为内部取数口径，并在报告中用自然语言说明结合上级行业数据分析。
- 行业类数据口径由 [行业分析](../references/gs-industry-analysis.md) 通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 统一确认；主 skill 和两个行业 reference 不直接展示或传递底层参数名。
- 主 Skill 行业名称与本表对齐：基础化工→**化工**，商贸零售→**商业贸易**，社会服务→**休闲服务**，纺织服饰→**纺织服装**。
- 成长大师六类 × 一级行业名称对照见 `references/growth-master-six-types.md`；成长股特征批量候选行业代码见 `references/06-成长股特征匹配编排.md`。
