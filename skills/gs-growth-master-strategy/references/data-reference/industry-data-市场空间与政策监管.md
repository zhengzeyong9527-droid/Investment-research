# 文本增强 / 市场空间与政策监管

---

## 研究报告

接口路径：`report/research`  
请求方式：**`POST`**  
tool_id：`list_report_research`

接口说明：支持通过股票代码、行业代码、行业一级代码、研究机构或栏目分类筛选证券研究报告，返回报告标题、作者、发布时间、机构、关键字和正文内容。适合抽取市场规模、行业天花板、渗透率、替代空间、政策支持、行业生命周期、周期属性、需求特征和竞争格局等文本线索。

**常用输入**

| 参数名 | 说明 | 示例 |
|--------|------|------|
| `industryCode` | 申万二级行业代码 | `740100` |
| `industryCodeLv1` | 申万一级行业代码 | `640000` |
| `beginDate` | 开始日期 | `2025-01-01` |
| `endDate` | 结束日期 | `2025-12-31` |
| `pageSize` | 页长 | `10` |

**接口示例**

```bash
node scripts/gs-api.js report/research --method POST --body-json '{"industryCodeLv1":"640000","beginDate":"2025-01-01","endDate":"2025-12-31","pageNum":1,"pageSize":10}'
```

## 新闻与资讯

接口路径：`news`  
请求方式：**`POST`**  
tool_id：`list_news`

接口说明：按时间、标题、情绪、新闻类型、新闻等级等条件筛选新闻资讯，适合按关键词查询政策事件、监管新闻、技术迭代、价格竞争、需求变化和替代风险。

**接口示例**

```bash
node scripts/gs-api.js news --method POST --body-json '{"beginTime":"2025-01-01","endTime":"2025-12-31","title":"政策","pageNum":1,"pageSize":10}'
```

## 实体相关新闻

接口路径：`news/entity-related`  
请求方式：**`POST`**  
tool_id：`list_entity_related_news`

接口说明：通过行业代码、股票代码或概念代码查询相关实体新闻，适合按行业代码追踪政策事件、行业事件、情绪、价格竞争、技术替代和需求风险线索。

**接口示例**

```bash
node scripts/gs-api.js news/entity-related --method POST --body-json '{"beginTime":"2025-01-01","endTime":"2025-12-31","industryCode":"640000","title":"监管","pageNum":1,"pageSize":10}'
```

## 上市公司公告

接口路径：`announcements`  
请求方式：`GET`  
tool_id：`list_announcements`

接口说明：通过股票代码查询上市公司公告列表，可按标题和日期筛选。该接口是公司维度，用于行业分析时需要代表公司或股票列表，可辅助抽取产能、订单、价格、客户、资本开支和风险提示。

**接口示例**

```bash
node scripts/gs-api.js announcements stockCode=600519 beginDate=2025-01-01 endDate=2025-12-31 title=产能 pageNum=1 pageSize=10
```

## 输出边界

- 市场规模、行业天花板、渗透率、替代空间来自研报或新闻文本时，必须标注“文本口径”或“研报口径”。
- 行业生命周期、周期属性、需求特征和竞争格局标签来自研报、新闻或公告时，必须标注“文本抽取”或“规则化标签”。
- 政策支持度、监管强度不是直接字段，只能基于政策新闻、研报观点和公告事件做摘要。
- `CR3/CR5`、市场份额、利润池分布和价格战强度若来自研报、新闻或公告，必须保留来源；若来自接口样本估算，必须标注“样本观察”、样本来源和样本范围。
- 研报和新闻直接披露的信息可以直接作为文本线索输出，但必须标注标题、日期、来源；不得改写为未披露的确定性数值。
- 政策事件频率可以统计，但必须说明关键词、时间范围、来源和样本数量。
- 公告是公司维度，不能直接当成行业整体公告；需要说明代表公司或样本口径。

## 推荐输出结构

1. 开头先给文本线索摘要：市场空间、渗透率、替代空间、政策方向。
2. 中间列出来源表：报告/新闻/公告标题、日期、来源、关键句摘要。
3. 结尾标注文本口径限制：样本数量、时间范围、不可得字段。
