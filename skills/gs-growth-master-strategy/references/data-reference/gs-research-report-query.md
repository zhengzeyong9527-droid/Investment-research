# 研报数据查询数据契约

本文件集中约束 `gs-research-report-query` 研报查询原子能力的数据请求边界、标准输出字段和用户可见口径。具体接口细节由本目录内的研报分组契约维护，主 Skill 和其他原子 Skill 只消费标准输出，不直接读取原始响应。

## 数据契约边界

- 当前 skill 只能使用本文件索引的研报数据契约和分组 reference。
- 上层 skill 只能消费本 skill 的标准输出字段，不得读取原始接口响应、临时变量或未定义字段。
- 用户可见输出可展示研报出处（发布日期 + 研报标题 + 发布机构），不得暴露底层接口名、参数名、字段名、报告 ID、页码、片段位置或命令。
- 网络、权限、CLI 配置或数据为空时，输出业务化缺口说明，不编造研报结论。

## 标准输出使用方

| 标准输出 | 主要使用场景 | 使用边界 |
|---|---|---|
| `report_list` | 查询研报清单和摘要 | 只作为公开研报样本线索，不替代结构化财务数据 |
| `vector_search` | 补充渗透率、市场空间、竞争格局、产能、订单等文本证据 | 片段需具备对象、时间、指标、数值或明确方向，否则只写证据不足 |
| `forecast_rating` | 补充未来 EPS、净利润预测、评级、目标价字段和预测修正摘要 | PEG 分母、盈利预测和机构评级趋势只使用公开预测样本，不承诺目标价 |
| `rating_change` | 补充预测或评级变化原因 | 只解释变化方向和样本分歧，不输出交易指令；不能在缺少可比样本时单独计算上调占比 |
| `source_refs` | 为上层报告提供可展示研报出处 | 只展示发布日期、研报标题、发布机构、证据类型和用途；内部 ID、页码和片段位置不得进入用户可见输出 |

## `source_refs` 最小字段

| 字段 | 含义 | 用户可见 |
|---|---|:---:|
| `title` | 研报标题 | 是 |
| `publish_date` | 发布日期 | 是 |
| `institution` | 发布机构 | 是 |
| `evidence_type` | 证据类型，如 `forecast_rating`、`vector_search`、`report_list`、`rating_change` | 可转写为业务语言 |
| `used_for` | 上层使用位置，如盈利预测、风险提示、渗透率证据 | 可转写为业务语言 |

若无法定位具体研报标题，标准输出必须写“公开研报来源未能定位到具体标题，待后续数据复核”。内部可保留 `reportId/page/position` 供 L1 溯源，但不得传入上层用户可见报告。

## 预测修正摘要

当上层 skill 需要“机构评级趋势”“近3月评级上调占比”“盈利预测有没有上调”或类似判断时，本 skill 必须在 `forecast_rating` 标准输出中附带预测修正摘要：

| 字段 | 含义 | 口径 |
|---|---|---|
| `validSampleCount` | 可比预测修正样本数 | 近 3 个月内，本次预测值和上次预测值均可得且同期限可比的样本数 |
| `upRevisionCount` | 上调样本数 | 当前预测值高于上次预测值 |
| `downRevisionCount` | 下调样本数 | 当前预测值低于上次预测值 |
| `flatRevisionCount` | 持平样本数 | 当前预测值等于上次预测值 |
| `upRevisionRatio` | 上调占比 | `upRevisionCount / validSampleCount` |
| `basis` | 计算口径说明 | 默认优先比较 T+1 净利润预测；不可比时依次使用 T+2/T+3 净利润预测，净利润不可比但 EPS 可比时使用同期限 EPS |

约束：
- 近 3 个月无预测样本时，写“近3个月未取得有效预测样本”。
- 有预测样本但缺少上次预测值或同期限可比字段时，写“近3个月预测样本可得，但可比预测修正样本不足，无法计算上调占比”。
- `rating_change` 可补充预测变动方向和原因，但若只返回单条或汇总记录，不能单独换算为近 3 个月上调占比。
- 当前预测修正摘要仅定义为股票级标准输出；输入必须能识别到单只 A 股股票。行业研报列表、行业研报文本、行业预测或行业景气数据不得被包装成行业级预测修正摘要。
- 上层行业直问不使用本摘要作为景气度硬评分项；行业直问应采用 4 分制，不得用单一代表股、行业研报热度、行业预测或行业景气数据补造“机构评级趋势”。

## 分层规则

研报查询原子 Skill 的 endpoint、请求方法、入参、返回字段和 CLI 示例以本目录分组契约为准。成长大师主 Skill、行业/财务/估值分析 Skill 和成长股特征 Skill 只能读取研报查询标准输出，不得绕过该能力直接维护研报接口调用口径。
