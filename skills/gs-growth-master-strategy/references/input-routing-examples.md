# 输入分流示例

本文件用于辅助识别用户意图，不是固定输出模板。

## 单股分析

示例：

- `分析 600519`
- `用成长大师视角分析宁德时代`
- `看看比亚迪值不值得关注`

处理：

- 默认进入 `single_stock_light_readable`。
- 读取 `light-fast-summary.md` 生成四块快速画像，不读取 `01-06` 完整维度 reference；最终只输出轻量可读版公司分析。
- 如果用户明确说“完整分析”“全面分析”“深度分析”“查看完整分析”“五维度分析”或“六维度分析”，再进入完整六维度 reference 编排流程。

## 诊股意图

示例：

- `宁德时代还能持有吗`
- `寒武纪这个票怎么样`
- `这个位置还能进比亚迪吗`

处理：

- 仍进入 `single_stock_light_readable`，不切换成自定义诊股模板。
- 用户明确要求完整或深度时，再进入完整六维度 reference 编排流程。

## 多标的分析

示例：

- `对比贵州茅台和五粮液`
- `立讯精密 vs 歌尔股份`
- `比较比亚迪、宁德时代和汇川技术`

处理：

- 每个标的默认独立执行摘要级对比；只有用户明确要求完整/深度/六维对比时，才逐一执行完整六维度流程。
- 按标的分组输出，不做主 skill 自定义横向模板。

## 成长股特征批量筛选

示例：

- `筛选A股成长股候选`
- `哪些行业容易出成长股特征`
- `帮我筛选AI应用行业的成长股特征匹配标的`

处理：

- 读取 `references/06-成长股特征匹配编排.md` 的批量筛选模式。

## 单维度分析

示例：

- `仅调用行业景气度，分析宁德时代`
- `只看宁德时代的行业生命周期`
- `只分析比亚迪未来盈利增速`
- `仅看贵州茅台 PEG`
- `只看寒武纪有没有成长股特征匹配`
- `分析电池行业景气度，不要其他维度`

处理：

- 进入 `single_dimension_analysis`，只读取并输出用户指定的单个 reference。
- 行业生命周期：只输出 `references/02-行业生命周期评估.md` 定义的“行业生命周期分析”。
- 行业景气度：只输出 `references/03-行业景气度评估.md` 定义的“行业景气度分析”。
- 企业盈利预测：只输出 `references/04-企业盈利预测.md` 定义的“企业盈利预测”。
- PEG估值分析：只输出 `references/05-PEG估值分析.md` 定义的“PEG估值分析”。
- 成长股特征匹配：只输出 `references/06-成长股特征匹配编排.md` 定义的“成长股特征匹配分析”。
- “仅调用/只看/单独分析”只限制成长大师主流程的维度数量；该维度内部仍需按自身 reference 规则获取完成判断所需证据。
- 不输出用户未指定的其他四个维度结论。

## 行业直问聚合分析

示例：

- `分析食品饮料行业`
- `分析白酒行业`
- `锂电池行业怎么看`
- `电池板块现在景气度怎么样`
- `通信行业怎么看`
- `计算机行业怎么看`

处理：

- 行业直问进入分析前，先确认用户行业词能否匹配到唯一公开行业口径。
- 先保留用户原始行业词用于最终展示。
- 传给外部行业分析 skill 的规范化提示词必须去除末尾泛化后缀：行业、板块、赛道、方向、产业、领域。
- 两个行业 reference 调用 [行业分析](../references/gs-industry-analysis.md)，由其通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 的行业基础能力识别行业层级，不把带后缀的原始短语作为底层查询口径。
- 若 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 命中一级行业，直接使用该一级行业分析。
- 若 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 返回可用二级行业，优先选择排序最靠前的二级行业分析。
- 若用户关注的是三级行业，保留三级作为用户关注对象，但实际分析按 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 的回退规则使用其所属二级行业。
- 固定读取 `references/02-行业生命周期评估.md` 和 `references/03-行业景气度评估.md`，并调用 [行业分析](../references/gs-industry-analysis.md)。
- 不进入个股六维度全流程。

典型处理：

| 用户输入 | 用户可见展示 | 内部取数口径 |
|----------|--------------|--------------|
| `分析食品饮料行业` | 食品饮料行业 | 通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 识别后使用匹配到的一级行业取数 |
| `分析白酒行业` | 白酒行业 | 通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 识别后使用匹配到的二级行业取数 |
| `分析锂电池行业` | 锂电池行业 | 通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 识别后使用所属二级行业补足取数 |
| `分析电池行业` | 电池行业 | 通过 [行业数据查询](../references/gs-industry-analysis.md/skills/gs-industry-data/SKILL.md) 识别后使用匹配到的二级行业取数 |

## 行业范围澄清

示例：

- `AI行业怎么看？`
- `人工智能行业分析`
- `新能源行业怎么看？`
- `机器人行业怎么看？`
- `火星采矿行业怎么看？`

处理：

- 若用户行业词命中跨行业主题词，先追问细分行业，不直接进入行业直问聚合分析。
- `AI` / `人工智能` 固定提示：`AI行业不是单一公开行业分类，通常可拆为通信、计算机、电子/半导体、传媒/AI应用等方向。您想分析哪个细分行业？`
- `新能源` 固定提示：`新能源行业不是单一公开行业分类，通常可拆为电力设备、汽车、有色金属、基础化工、公用事业等方向。您想分析哪个细分行业？`
- `机器人` 固定提示：`机器人行业不是单一公开行业分类，通常可拆为机械设备、电子、计算机、汽车等方向。您想分析哪个细分行业？`
- 若未匹配到公开行业分类，固定提示：`暂未匹配到公开行业分类，请补充更标准行业名称或代表性公司`
- 若返回多个候选行业，用自然语言列出候选行业名称，并要求用户选择一个细分行业后再分析。
- 澄清阶段不得输出行业生命周期、行业景气度、PEG、盈利预测或成长股特征分析，也不得展示接口名、参数名、字段名或行业代码。

二轮确认：

| 上轮输入 | 澄清后用户回答 | 处理 |
|----------|----------------|------|
| `AI行业怎么看？` | `通信` | 重新进入输入预检；若确认唯一行业口径，则进入行业直问聚合分析 |
| `新能源行业怎么看？` | `电力设备` | 重新进入输入预检；若确认唯一行业口径，则进入行业直问聚合分析 |
| `机器人行业怎么看？` | `机械设备` | 重新进入输入预检；若确认唯一行业口径，则进入行业直问聚合分析 |

反例：

- 不得把 `AI行业怎么看？` 自行拆成通信、计算机、电子、传媒后直接生成综合分析。
- 不得把 `新能源行业怎么看？` 自行拆成电力设备、汽车、有色金属等多个方向后直接生成综合分析。
- 不得对无法匹配公开行业分类的行业词编造生命周期、景气度或行业代码。

## 行业归类查询

示例：

- `半导体属于成长大师哪一类`
- `传媒板块按成长大师六分类怎么定义`
- `化工行业对应成长大师哪一类`

处理：

- 读取 `references/growth-master-six-types.md`
- 必要时结合 `references/industry-codes.md`
- 不进入六维度 reference 编排

## 无法识别标的

示例：

- `帮我看看最近涨得好的`
- `分析下这个票`
- `这是一家高成长公司，帮我分析一下`

处理：

- 返回固定补充提示。
- 不调用任何 reference 或外部 skill。
