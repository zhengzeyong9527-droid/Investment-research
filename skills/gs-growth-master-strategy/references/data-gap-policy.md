# 数据缺失与市场局限处理

## 基本原则

- 不得编造数据。
- 不得用行业均值替代个股关键数据而不标注。
- 不得生成未经数据支撑的明确结论。
- 每个关键判断必须至少绑定一种依据，例如财务指标、历史趋势、行业对比、公司公告、定期报告、监管公开信息、新闻资讯、估值分位、现金流数据或股权结构数据。
- 无法获得某项数据时，输出“暂无足够数据”或“暂无足够数据”，不得猜测排名、百分位、市场份额、财务指标或公告内容。

## 常见场景

### reference 或外部分析 skill 返回数据不全

- 保留该 reference 或外部分析 skill 自身的失败说明、不确定性说明和数据缺口边界。
- 主 skill 继续编排其他可完成的 reference。
- 若缺口属于成长投资方法论框架必须使用的数据，按 `references/08-调用链路与数据补充.md` 的规则先走对应分析/查询 skill 链路；查询 skill 未覆盖时，先判断是否属于研报类缺口。研报类缺口调用 [研报数据查询](../references/gs-research-report-query.md) 标准输出补充，非研报类缺口再按对应补充口径处理。

### 非 A 股主流市场标的

- 应明确提示该标的不属于 A 股主板、创业板或科创板主流分析范围。
- 需要说明部分业务或财务数据可能未公开披露，相关判断基于现有公开信息整理。

### 历史数据不足

- 若上市时间较短或历史样本不足，应明确说明分析不确定性更高。
- 不因样本不足而强行补齐长周期结论。

### 轻量可读版数据不足

- 轻量版仍应输出可验证的初步分析，但必须在开头或相关字段中提示：
  > 当前公开数据不足以支持完整判断，以下仅为基于有限信息的初步分析，需结合后续财报、公告和行业数据继续验证。
- 对无法支撑强判断的核心字段，写“暂无足够数据”。
- 不得因为轻量版篇幅较短而省略数据缺口说明。

### 轻量可读版框架不适配

- 如果公司属于高技术迭代、强周期、强政策、早期成长、高杠杆或商业模式复杂类型，必须降低框架适配度或分析置信度，并提示：
  > 该公司部分特征不完全符合成长投资方法论框架的典型适用范围，适合降低分析置信度，并重点关注行业周期、政策变化、技术路径变化或盈利兑现情况。
- 框架适配度低时，“下一步可以继续了解”优先推荐“为什么它不太适合成长大师框架？”或类似问题。

### 风险显著高于优势

- 如果风险明显高于优势，不得强行总结为典型成长股。
- 推荐表述：
  > 从当前信息看，公司仍存在较多需要验证的问题，暂不宜简单归类为典型成长投资方法论下的成长机会。
- 主要风险必须写清“为什么重要”和“需要观察”，不得只写抽象风险名称。

### 估值或成长匹配无法判断

- 如果缺少盈利、现金流、有效未来预测、PEG 或可比估值数据，不得对估值与成长匹配给出明确判断。
- 推荐表述：
  > 由于 PEG 或成长匹配所需关键数据不足，当前不宜对估值与成长是否匹配给出明确判断。
- 对应核心判断表中 `PEG成长观察` 写“不适用”或“数据不足”，并在依据中说明缺少哪类公开数据。

### 单个 reference 失败

- 继续执行剩余 reference。
- 在对应位置保留失败说明，不替换为主 skill 自造摘要。

### 所有 reference 均失败

- 先回到主 `SKILL.md` 的“数据可用性守门”逐项核对，不得仅凭 reference 返回失败就判定全局不可用。
- 只有标的/行业识别、当前 route 核心数据、最小补充口径和已取得上下文均不可用时，才返回统一提示：`数据服务当前不可用，请稍后重试`。
- 如果任一 reference 已取得核心事实或代理证据，输出有限分析和缺口说明，不得把局部失败升级为全局不可用。
- 不返回空白报告。
