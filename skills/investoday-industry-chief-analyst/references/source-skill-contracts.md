# 子 Skill 交接契约

主 Skill 只读取 7 个子 Skill 的标准输出字段，不读取原始接口响应、临时变量或未定义字段。所有交接字段进入正式报告前必须完成口径脱敏：不展示 `Investoday`、子 Skill 名、内部分类编号、指数编号、endpoint、接口字段、原始参数或成分股数量。

## 禁止传递到用户侧正文

- 子 Skill 原始 API 响应。
- 未在子 Skill 输出契约中定义的临时字段。
- 调试日志、fallback_trace、source_trace 等内部工程字段；即便子 Skill 标准输出包含该类追踪字段，主 Skill 也只能内部消费，不得进入用户侧投研正文。
- API key、token、认证信息、CLI 初始化细节。
- 内部分类编号、指数编号、endpoint、接口字段、原始参数、`Investoday`、子 Skill 名。
- 成分股数量或成分股总数。
- 字母证据等级。
- 研报目标价转化后的买卖建议、收益空间或仓位动作。
- 配置建议、超配/标配/低配、推荐顺序、规避名单等操作化表达。

## 主 Skill 汇总规则

- 同一结论同时有结构化数据和研报证据时，结构化数据优先，研报作为解释或交叉验证。
- 子 Skill 结论冲突时，必须列入“关键分歧”，不强行合并为单一判断。
- 每个章节必须使用子 Skill 标准输出事实、指标、分析结论或研报证据展开；无数据时正式报告省略对应指标、表格行或章节，内部摘要记录缺口。
- 量化评分、分位、评级、集中度和产业链弹性仅能来自子 Skill 标准输出；不得为了凑齐 PDF 方法论而读取原始接口响应或模型补数。
- 对结构化缺口做研报补证时，主 Skill 只能向 `investoday-research-report-query` 传递 `vector_keyword_queries`；每个 `query` 只含一个关键词或短关键词短语，不得拼入行业名、公司名、日期、筛选条件或分析句。
- 研报向量片段命中后只能作为文本证据或弱补充，不能替代同口径结构化集中度、库存、订单、ASP 或海外数据；无命中时正式报告不写检索缺口，内部摘要记录。
- 研报列表、研报舆情、研报向量片段和预测评级样本进入正式正文或引用来源前，主 Skill 必须校验 `source_refs` 是否同时包含发布时间、发布机构和研报标题；不完整来源只进入内部摘要，不写成用户侧“研报片段：日期，主题，机构”。
- PDF 中的配置建议、超配/低配、最优投资层位、推荐顺序进入主 Skill 时必须改写为研究观察优先级、验证环节、风险条件。
- 任何公司池或重点公司结论必须能追溯到行业结论、财务摘要、估值摘要、行业数据代表公司候选、研报证据或用户输入之一。
- 完整公司池正式表只展示龙头型、弹性型、防御/高股息型、景气反转型、风险暴露型中已验证、证据充足且不重复的实名代表公司；无法补齐任一类型或重复候选无法补齐时，正式报告省略该类型，内部摘要记录。
- 风险暴露型代表公司必须至少有两个可追溯风险因子，其中至少一个来自财务或估值标准输出；不得只用公司类型、行业环节、概念词或单一高估值因素替代公司名称。
- 完整报告至少选择 1-2 家可验证代表公司做深度分析；若样本有限，重点公司深度分析只能覆盖已验证且不重复样本，不在正式正文说明公司池缺口。
- 子 Skill 无数据时，不调用其他未声明 Skill 替代。
