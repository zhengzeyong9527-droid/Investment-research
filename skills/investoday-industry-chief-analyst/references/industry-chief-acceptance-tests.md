# 行业首席验收测试

## 测试目标

- 验证需求表 23 个模块全部可被主流程或模块框架覆盖。
- 验证自包含包只包含指定 7 个子 Skill。
- 验证完整报告输出结构、证据链、引用来源和免责声明。
- 验证正式报告不暴露 `Investoday`、子 Skill 名、内部字段名、成分股数量、内部取数字段、分类编号、指数编号、endpoint、接口字段或原始参数。
- 验证正式报告不输出旧版证据矩阵，不使用字母证据等级。
- 验证完整报告包含产业链价值排序表、公司池映射表、风险与跟踪指标表；缺少数据支撑的行、指标或章节不进入正式报告。
- 验证完整报告公司池只展示可验证、证据充足且不重复的实名代表公司；同一家公司不得作为多个公司类型的正式代表。
- 验证公司池类型候选不足、重复候选无法补齐或证据不足时，正式报告省略缺失类型，内部 `数据缺口验收摘要` 记录缺失类型和触发原因。
- 验证每个正文维度都基于子 Skill 输出事实、指标、分析结论或研报证据展开。
- 验证 S1-S7 单模块可独立调用，并统一输出核心结论、数据支撑、分析展开、风险反证、跟踪指标和引用来源。
- 验证景气评分、估值分位、政策评级、CR3/CR5/HHI、产业链盈利弹性等量化项仅在有数据支撑时输出；无数据、空结果或不可计算时正式报告省略。
- 验证研报向量补证时 `query` 只传关键词或短关键词短语，行业/公司/时间/topK 作为过滤条件。
- 验证完整报告第 4-9 章采用“结论、关键证据、解释与影响、反证”短块结构，不输出长篇连续段落。
- 验证正式报告章节从 `## 1. 首席结论卡` 开始，不出现 `## 0` 或 `## 0A`。
- 验证正式报告顶部三行口径包含分析日期、数据口径和说明；不再单独输出 `研究边界与数据可用性` 章节。
- 验证正式报告前部包含 `术语速查`，只解释正文实际使用的核心财务/经营指标；不包含行业技术名词。
- 验证完整报告包含独立 `行业介绍` 章节，且包含行业定义、多维分类体系和行业生意特征。
- 验证产业链章节包含产业链全景表、重点细分领域发展、产业链价值排序表和环节解读。
- 验证正式报告正文和引用来源中的研报列表、研报舆情、研报向量片段和预测评级样本均包含发布时间、发布机构和研报标题；不输出半截研报来源。
- 验证普通用户完整行业报告不展示内部 `数据缺口验收摘要`；测试、质检、验收或调试场景可单独输出该摘要。
- 验证高风险交易请求被拒绝并转为非操作性研究。

| 短块结构 | 输出模板第 4-9 章包含 `结论`、`关键证据`、`解释与影响`、`反证` |
| 普通投资者可读性 | 输出模板包含术语速查、研究决策锚点、行业介绍规则 |
| PDF 追踪矩阵 | `references/pdf-requirements-traceability.md` 存在，覆盖 S1-S7、P0/P1/P2、合规改写、正式报告省略规则和内部摘要规则 |
| 单模块格式 | `module-output-frameworks.md` 包含统一单模块输出格式，S1-S7 均引用 |
| 核心表 | 包含产业链全景表、重点细分领域发展、产业链价值排序表、公司池映射表、风险与跟踪指标表；产业链表后有 `环节解读`，公司池表不输出表后归因小节 |
| 公司池表字段 | 正式公司池表包含 `主类型判定证据`、`关键验证变量`、`主要风险`，不包含 `剔除因子` 列 |
| 禁止项 | 模板不包含用户侧成分股数量、旧版证据矩阵、字母证据等级 |
| 正式报告脱敏 | 正式报告模板不得要求展示 `Investoday`、子 Skill 名、内部字段名、内部分类编号、指数编号、endpoint、接口字段或原始参数 |
| 正式报告缺口禁词 | 正式报告模板不得要求输出 `数据不足`、`未返回`、`不可计算`、`评分不可计算`、`公司池完整性不达标` 等缺口话术 |
| 内部摘要 | 工作流和输出模板包含 `internal_data_gap_acceptance_summary` 和单独的 `数据缺口验收摘要` |
| 量化省略 | 规则文件要求缺少量价利库、估值历史、政策文本、CR3/CR5/HHI、价格或毛利率时不硬打分，正式报告省略该项 |
| 合规改写 | 规则文件要求配置建议、超配/低配、最优投资层位、推荐顺序改写为研究观察优先级、验证环节和风险条件 |
| 公司样本 | 完整报告公司池只展示来自今日投资数据源或用户输入的实名代表公司；同一家公司不得重复占多个类型；风险暴露型不得只给公司类型 |
| 旧降级口径 | 正式报告全文不出现旧版样本不足、样本不可做、筛选框架退路、公司类型占位等表达 |
| 研报候选闭环 | 研报子 Skill 若作为公司池候选来源，必须输出 `company_pool_candidates` 并标注 `source_refs` 和 `data_gaps` |
| 术语覆盖 | `术语速查` 只覆盖正文实际出现的核心财务/经营指标；通信行业样例不得把 CPO、800G/1.6T 等行业技术名词放入术语速查 |
| 研报引用三要素 | 正式报告中每条研报引用必须包含发布时间、发布机构和研报标题；禁止半截研报片段来源进入引用来源 |
| 合规 | 禁止交易动作、目标价、仓位、收益承诺 |
