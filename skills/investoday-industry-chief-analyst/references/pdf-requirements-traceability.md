# PDF 需求追踪矩阵

来源：`行业首席Skill需求.pdf`。本文件用于把 PDF 中的 S1-S7 原子模块、P0/P1/P2 功能、测试用例和合规要求映射到当前 `investoday-industry-chief-analyst`，并明确已覆盖、需增强和当前不纳入范围。

## 总体结论

| PDF 要求 | 当前处理状态 | 当前 Skill 落点 | 处理说明 |
|---|---|---|---|
| 从行业数据解读到产业链机会识别 | 已覆盖 | 完整报告主流程、产业链价值排序、公司池映射 | 统一改写为“行业判断 -> 产业链环节 -> 公司池 -> 财务/估值/风险 -> 首席观点”，不输出交易动作 |
| S1-S7 原子模块 | 已覆盖，需增强单模块契约 | `module-output-frameworks.md` | 7 类原子模块可被单独调用，统一单模块输出格式 |
| 量化评分和分位 | 已增强 | 业务规则、模块框架、输出模板 | 有今日投资数据源支撑才输出分数/分位；无数据、空结果或无法得出时正式报告省略，内部摘要记录 |
| 正式报告缺口省略 | 已覆盖 | 输出模板、工作流、业务规则、验收测试 | 正式报告只展示有数据支撑的结论、指标和表格项；缺口单独进入内部验收摘要 |
| 内部数据缺口验收摘要 | 已覆盖 | 工作流、输入输出契约、输出模板、验收测试 | 汇总缺失数据、无法得出指标、缺失公司类型、被省略章节/表格项、触发原因和验收状态 |
| A股/港股/美股多市场覆盖 | 当前不纳入 | Assumptions / 业务规则 | 当前以 A 股行业研究为主；港股/美股完整覆盖等待对应子 Skill 能力 |
| 快速/标准/深度三模式 | 部分采纳 | 意图路由、模块规则 | 不做版本区分；用户说“快速/只看”时走单模块或精简模块 |
| 配置建议、超配/标配/低配、推荐顺序 | 当前不纳入 | 合规规则 | 改写为“研究观察优先级、验证环节、风险提示” |
| 宏观首席联动、推送提醒、历史回测 | 当前不纳入 | 数据契约、验收说明 | 不新增依赖，不新增 endpoint，不做自动提醒或回测 |

## S1-S7 原子模块映射

| PDF 原子模块 | PDF 核心输出 | 当前模块 | 增强后的用户侧输出 |
|---|---|---|---|
| S1 行业生命周期分析 | 阶段、TAM、增速趋势、投资主线、海外对标 | 模块 4、完整报告第 2 章 | 生命周期阶段、置信度、依据、反证、长期空间；TAM/海外对标仅在今日投资数据源返回证据时使用 |
| S2 景气度分析 | 0-100 评分、拐点、量价利库、跟踪指标 | 模块 5、完整报告第 3 章 | 景气评分、量/价/利润/库存四维判断、拐点信号；评分缺关键数据时正式报告省略 |
| S3 估值分析 | 历史分位、合理性、横向比较、A/H/美对比 | 模块 6、完整报告第 7 章 | PE/PB/PS/PEG、3年/5年/10年分位、盈利匹配、横向比较；不机械输出高估/低估 |
| S4 政策分析 | 五级评级、政策时间线、受益/受损、持续性、历史复盘 | 模块 7、完整报告第 4 章 | 政策方向五级、政策时间线、受益/承压子行业、持续性、反转风险；历史复盘仅在有证据时输出 |
| S5 竞争格局分析 | CR3/CR5/HHI、护城河、格局趋势、龙头优势 | 模块 8、完整报告第 6 章 | CR3/CR5/HHI、护城河类型、格局趋势；无直接披露时正式报告省略集中度指标 |
| S6 产业链分析 | 产业链图谱、盈利弹性、最优层位、价格传导 | 模块 9、完整报告第 5 章 | 产业链价值排序、盈利弹性评分、价格传导时滞；“最优层位”改为“更值得验证的环节” |
| S7 行业比较分析 | 综合评分矩阵、推荐/规避、轮动路径、风格预警 | 模块 10-12 | 多行业研究观察矩阵，维度为景气、估值、政策、资金/情绪、风险；不输出配置建议 |

## P0/P1/P2 功能处理

| PDF 功能 | 优先级 | 当前状态 | 处理方式 |
|---|---|---|---|
| 生命周期判断 | P0 | 已覆盖，需补置信度 | 增加阶段置信度、依据、反证 |
| 景气度综合评分 | P0 | 需增强 | 有量价利库数据时输出 0-100；缺数据不打分 |
| 估值历史分位 | P0 | 已覆盖，需细化期限 | 明确 3年/5年/10年分位可用性 |
| 政策影响评级 | P0 | 需增强 | 五级方向、时间线、持续性和反转风险 |
| 竞争格局评估 | P0 | 已覆盖，需补 HHI | CR3/CR5/HHI 有证据才输出 |
| 产业链盈利弹性矩阵 | P0 | 已覆盖，需补评分省略 | 有数据输出评分；无数据时正式报告只保留有证据的定性排序，内部摘要记录缺口 |
| 行业综合评分矩阵 | P0 | 已覆盖，需合规改写 | 排序为研究观察优先级，不写配置建议 |
| 景气拐点预警 | P1 | 部分采纳 | 输出观察信号，不做推送提醒 |
| 宏观-行业联动 | P1 | 当前不纳入 | 不新增宏观首席依赖；仅可引用今日投资数据源已返回宏观背景 |
| 产业链价格传导计算 | P1 | 部分采纳 | 仅在数据支持时输出传导方向、时滞和弹性，不做价格预测 |
| 海外对标行业追踪 | P1 | 部分采纳 | 仅在今日投资数据源研报/文本证据返回时作为参考 |
| 多模式调用 | P1 | 部分采纳 | 完整报告不分版本；单模块/快速请求走统一单模块格式 |
| 行业轮动历史回测 | P2 | 当前不纳入 | 不做回测和收益验证 |
| 产业链知识图谱维护 | P2 | 当前不纳入 | 使用子 Skill 返回产业链，不在主 Skill 维护外部图谱库 |

## 合规改写规则

| PDF 表述 | 当前 Skill 用户侧改写 |
|---|---|
| 配置建议、超配、标配、低配 | 研究观察优先级、验证顺序、风险提示 |
| 推荐行业排名、规避行业清单 | 观察排序、压力行业、需谨慎验证的行业 |
| 最优投资层位 | 更值得验证的产业链环节 |
| 重点跟踪标的推荐逻辑 | 代表样本研究逻辑、公司池筛选逻辑 |
| 明天涨停、必涨、保证收益 | 合规拒绝，转为非操作性研究框架 |

## 当前不纳入项

- 不新增 westock、neodata、GS 或 PDF 中其他外部数据源名称。
- 不新增 `investoday-api` endpoint。
- 不新增任何未授权综合诊断 Skill。
- 不提供自动推送、提醒、回测、调仓或交易执行。
- 不承诺港股/美股完整覆盖，除非现有 7 个子 Skill 明确返回可用数据；正式报告不展示内部 Skill 名。
