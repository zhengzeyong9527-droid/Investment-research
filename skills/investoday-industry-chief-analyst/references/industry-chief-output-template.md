# 行业首席统一输出模板

所有正式完整行业分析统一使用“数据驱动的首席深研版” Markdown 报告，不区分免费版和付费版。

## 核心原则

- 报告正文只展示用户可读数据口径，不展示成分股数量、内部分类编号、指数编号、endpoint、接口字段或原始参数。
- 正式报告章节必须从 `## 1. 首席结论卡` 开始编号，不得出现 `## 0`、`## 0A`。
- 原“研究边界与数据可用性”不再作为独立章节输出，必须合并到标题下方三行口径中的 `数据口径`。
- 每个章节都必须从 7 个子 Skill 的标准输出中提取真实数据、指标、分析结论或研报证据展开，不能只写通用行业常识。
- 缺失、空结果和无法得出项不进入正式报告正文，统一进入内部 `数据缺口验收摘要`。
- 首席结论卡后必须输出 `术语速查`，但只解释正文实际使用的核心财务/经营指标；行业技术名词不得进入 `术语速查`，应在正文首次出现时就地解释。
- 正文和引用来源中凡使用研报列表、研报舆情、研报向量片段或预测评级样本，必须展示完整研报出处：发布时间、发布机构、研报标题。
- 首席结论卡必须包含非交易化 `研究决策锚点`，只能使用 `优先验证`、`等待确认`、`谨慎观察`、`暂不强判断` 四类。

> 数据口径：基于今日投资数据源，分析对象为[自然语言行业/赛道口径]；行情估值截至 YYYY-MM-DD，实时行情样本截至 YYYY-MM-DD，行业财务截至 YYYY年X季报，研报样本为 YYYY-MM-DD 至 YYYY-MM-DD 期间可得样本。

- 最关键变量：<从景气、价格、库存、政策、CapEx、盈利预测中选择 1-2 个最关键变量。>

- 可选量化摘要：<仅在有数据时写生命周期阶段/置信度、景气评分、估值分位、政策方向、竞争格局、验证环节；无数据时省略该项。>

|---|---|
| ARPU | 单用户平均收入，用于观察运营商或订阅型服务的单客价值 |
| CapEx | 资本开支，企业用于扩产、设备、厂房等长期资产的投入 |
| ASP | 平均售价，用于观察产品价格变化 |

| FCF | 自由现金流，经营现金流扣除资本开支后的剩余现金 |

| 库存周期 | 库存从积累、去化到补库的经营循环 |
| 稼动率 | 产能实际利用程度 |
| 毛利率 | 销售收入扣除直接成本后的盈利比例 |

## 模板使用规则

- 报告头部必须使用三行口径说明，成分股数量不进入用户侧报告。
- 不输出旧版证据矩阵，不使用字母证据等级。
- 第 4-9 章必须使用“结论、关键证据、解释与影响、反证”四个短块；每章默认 2-4 条关键证据，每条只放一个数据点或证据点。
- 第 3 章必须包含 `行业介绍`，并固定输出 `行业定义`、`多维分类体系`、`行业生意特征`。
- `行业生意特征` 控制在 200-300 个中文字符；通信行业需区分运营商/通信服务与通信设备两类商业逻辑。
- 首席结论卡后必须输出 `术语速查`，只解释正文实际使用的核心财务/经营指标；不得包含行业技术名词。
- 行业技术名词在正文首次出现时就地解释，后文直接使用简称。
- 产业链章节必须包含 `产业链全景表`、`重点细分领域发展`、`产业链价值排序表` 和 `环节解读`。
- 公司池必须先生成候选池并完成五类实名代表公司校验；不能凭空编造。
