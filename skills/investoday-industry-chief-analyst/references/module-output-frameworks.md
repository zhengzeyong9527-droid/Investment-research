# 模块输出框架

本文件逐项映射需求表 23 个模块，定义输出格式、分析框架、调用子 Skill、必出字段和空值处理。所有模块都必须基于 7 个子 Skill 的标准输出展开，不能只写空泛定义、行业常识或浓缩摘要。

通用展开规则：`子 Skill 输出事实 -> 指标变化 -> 业务解释 -> 对行业/环节/公司的影响 -> 风险或反证`。

完整报告第 4-9 章表达规则：统一使用“结论、关键证据、解释与影响、反证”短块结构；每章默认 2-4 条关键证据，每条只放一个数据点或证据点，避免长段堆数据。缺失数据、空结果和无法得出项不进入正式报告短块，统一进入内部 `数据缺口验收摘要`。单模块仍使用下方统一单模块格式。

研报缺口补证规则：库存、订单、ASP、渗透率、CR3/CR5/HHI、市占率、海外收入、产能利用率等结构化缺口，只通过关键词式向量检索补证；`query` 只传关键词，行业/公司/时间/topK 作为过滤条件。

普通投资者可读性规则：完整报告首席结论卡后必须输出 `术语速查`，只解释正文实际使用的核心财务/经营指标，不包含行业技术名词；行业技术名词在正文首次出现时就地解释。完整报告首席结论卡必须包含非交易化研究决策锚点；第 3 章必须输出独立 `行业介绍`，包含行业定义、多维分类体系和 200-300 字行业生意特征。

研报引用规则：正式报告正文和引用来源中使用研报列表、研报舆情、研报向量片段或预测评级样本时，必须同时列出发布时间、发布机构和研报标题；缺任一项的研报片段不进入正式报告，进入内部验收摘要。

## 单模块统一输出格式

当用户明确说“只看/单独分析/快速看一下”生命周期、景气度、估值、政策、竞争、产业链或行业比较时，不输出完整 13 段报告，统一使用以下结构：

```markdown
# [行业] [模块名]分析

## 核心结论
1-2 句结论，说明判断强度。

## 数据支撑
3-5 个关键指标，包含数值、时间、来源或缺口。

## 分析展开
子 Skill 输出事实 -> 指标变化 -> 业务解释 -> 影响路径。

## 风险与反证
列出可能推翻结论的信号。

## 跟踪指标
3-5 个后续观察指标。

## 引用来源
按实际使用列出。
```

单模块共用约束：

- 只读取 7 个子 Skill 的标准输出，不读取原始接口响应。
- 量化评分、历史分位、政策评级、CR3/CR5/HHI、盈利弹性评分和价格传导弹性必须有数据依据；缺失、空结果或无法得出时正式报告省略，内部摘要记录。
- 单模块结论也必须保留合规边界，不输出配置建议、超配/低配、买卖建议、目标价、仓位或收益承诺。
- 单模块报告可以追加专项表，但必须服务于该模块，不强行复制完整报告 3 张核心表。
- 如果单模块需要研报向量补证，必须沿用关键词式查询；多个关键词拆成多次查询并去重来源。
- 单模块同样执行术语解释规则：可在数据支撑或分析展开前集中解释本模块实际使用的核心财务/经营指标；行业技术名词在正文首次出现时就地解释。完整报告必须使用 `术语速查`，单模块不强制输出完整报告的研究决策锚点和行业介绍，除非用户请求生命周期/行业本质相关内容。

## 1. 行业首席分析师

调用子 Skill：全部 7 个子 Skill 按需协同。

输出格式：数据驱动深研版完整 Markdown 报告。

框架：首席结论卡 -> 术语速查 -> 行业介绍 -> 行业本质 -> 供需景气 -> 政策约束 -> 产业链价值 -> 竞争护城河 -> 估值匹配 -> 公司池映射 -> 代表公司深度分析 -> 风险跟踪 -> 首席观点。研究边界与数据可用性合并到报告头部 `数据口径`，不单独成章。

必出字段：三行数据口径、首席结论卡、研究决策锚点、术语速查、行业介绍、产业链全景表、重点细分领域发展、产业链价值排序表、公司池映射表、公司池完整性状态、1-2 家代表公司深度分析、风险与跟踪指标表、引用来源、免责声明。

空值处理：公司池只展示已验证、证据充足且不重复的实名代表公司；任一类型无法补齐不重复样本时正式报告省略该类型，内部摘要记录缺失类型和证据缺口；任何核心数据缺失时正式报告省略对应指标、表格行或章节。

## 2. 行业首席自上而下研究编排

调用子 Skill：行业数据、行业深度、研报查询、财务分析、估值分析。

输出格式：结论链 + 数据来源说明。

框架：行业属性、生命周期、景气、政策、竞争、估值先行，再映射环节、公司池、代表公司和重点验证指标。

必出字段：链路步骤、使用的子 Skill 输出、输出结论、传递字段、数据缺口。用户侧不得展示内部取数字段、覆盖数量或原始参数。

空值处理：上游结论不足时，不进入强公司池结论；候选公司不足或重复候选无法补齐时，正式公司池省略对应类型，内部摘要记录。

## 3. 研报证据查询与观点验证

调用子 Skill：研报数据查询。

输出格式：证据摘要 + `source_refs`。

框架：研报列表、向量片段、盈利预测评级、评级变化，区分文本证据与结构化数据。

必出字段：发布日期、发布机构、研报标题、证据类型、支持判断、使用位置、`source_refs`；正式报告使用时三要素缺一不可。

空值处理：无研报结果时说明查询口径，不推导无风险或无机会。

## 4. 行业生命周期分析

调用子 Skill：行业数据、行业深度、研报查询。

输出格式：统一单模块格式；核心结论写生命周期判断 + 置信度。

框架：导入/成长/成熟/衰退/反转，结合收入利润增速、渗透率、资本开支、利润率、需求空间和文本证据。TAM、海外对标和 S 曲线路径仅在今日投资数据源返回市场空间、渗透率或研报证据时使用。

必出字段：阶段标签、置信度、数据依据、长期空间、商业逻辑说明、反证、数据口径、观察指标。完整报告中的行业生意特征仅在 `行业介绍` 输出；单模块可按需简述商业逻辑。

空值处理：渗透率、TAM 或海外对标缺失时，不编造市场空间；只输出阶段倾向、置信度降低原因和待验证项。

## 5. 行业景气度分析

调用子 Skill：行业数据、行业深度、研报查询。

输出格式：统一单模块格式；如数据充足可附量价利库评分摘要。

框架：需求、供给、价格、库存、开工、ROE、毛利率、净利率、净利润同比和研报景气线索；可按量/价/利润/库存四维组织。

必出字段：当前景气位置、变化方向、驱动因素、反向风险、跟踪指标；有数据时输出 0-100 景气评分、量价利库分项、拐点信号。

空值处理：量价利库关键维度缺失时正式报告不输出景气评分，使用有证据的财务和文本线索辅助，内部摘要记录无法得出原因。

## 6. 行业估值分析

调用子 Skill：行业数据、估值数据、估值分析、研报查询。

输出格式：统一单模块格式；必要时附估值分位摘要。

框架：PE/PB/PS/PEG、3年/5年/10年历史分位、横向比较、盈利预期匹配、风险溢价、周期位置。

必出字段：估值指标、历史分位期限、对比口径、成长匹配、现金流或盈利匹配、风险提示。

空值处理：行业分位或盈利预测缺失时只展示可得估值事实，不输出“高估/低估”强判断；历史分位不代表未来走势。

## 7. 行业政策与监管环境分析

调用子 Skill：行业数据、行业深度、研报查询。

输出格式：统一单模块格式；有证据时可附政策时间线。

框架：国内政策、监管约束、海外约束、卡点环节 -> 需求/供给/成本/利润/竞争/估值影响；政策方向可分为正面强、正面弱、中性、负面弱、负面强。

必出字段：政策/监管事件、来源、影响方向、影响环节、持续性、反转风险、可验证后续信号。

空值处理：无政策文本时，正式报告不输出政策评级或政策时间线；不生成虚假政策时间线，内部摘要记录。

## 8. 行业竞争结构分析

调用子 Skill：行业数据、行业深度、研报查询。

输出格式：统一单模块格式；有数据时可附集中度/护城河摘要。

框架：CR3/CR5/HHI、份额、进入壁垒、竞争方式、价格战、龙头优势、利润质量、潜在颠覆。

必出字段：竞争结构标签、头部企业线索、集中度口径、CR3/CR5/HHI 可用性、壁垒类型、价格战强度、利润质量风险。

空值处理：没有 P0 直接披露或同口径公司级数据时，只输出样本观察或梯队线索，不写真实全行业 CR/HHI。

## 9. 产业链分析

调用子 Skill：行业数据、行业深度、研报查询。

输出格式：统一单模块格式；默认包含产业链全景表、重点细分领域发展、产业链价值排序表。

框架：按真实环节拆解利润池、价格传导、传导时滞、议价能力、资本开支、现金流压力、受益/承压顺序；PDF 中“最优投资层位”统一改写为“更值得验证的环节”。

必出字段：产业链全景表、重点细分领域发展、环节、景气/兑现判断、价值来源、关键证据、主要风险；表后必须输出 `环节解读`，逐环节说明为什么重要、利润如何兑现、最该验证什么；有数据时可输出盈利弹性评分和价格传导方向。

空值处理：利润池、价格、毛利率或上下游传导缺失时，只输出有证据的环节逻辑；不硬算盈利弹性评分，内部摘要记录省略项。

## 10. 行业比较分析

调用子 Skill：行业数据、行业深度、估值分析、研报查询。

输出格式：统一单模块格式；默认包含多行业研究观察矩阵。

框架：景气、估值、政策、资金/情绪、风险、盈利质量和观察排序。

必出字段：行业列表、各维度得分/标签、优势、劣势、排序理由、风险、研究观察优先级。

空值处理：部分行业缺字段时，正式矩阵省略该维度或不打分，不标注缺口话术；内部摘要记录，排序不代表配置建议。

## 11. 行业综合评价矩阵

调用子 Skill：行业数据、行业深度、估值分析。

输出格式：统一单模块格式 + 标准化评分表。

框架：多行业按景气度、估值、政策、盈利、资金、风险等维度评分、排名和解释。

必出字段：评分维度、评分依据、权重或排序规则、总分、排名、强弱解释、缺失维度降权说明。

空值处理：评分不可黑箱；缺少依据的维度不打分或降权，并说明。

## 12. 行业轮动信号分析

调用子 Skill：行业数据、估值数据、研报查询。

输出格式：统一单模块格式 + 轮动信号清单。

框架：景气拐点、估值分位、盈利预期、资金流、宏观环境和风格变化。

必出字段：信号、触发条件、对应行业、可信度、风险条件、观察周期、合规说明。

空值处理：资金流或宏观数据缺失时，只输出可验证的景气/估值信号。

## 13. 行业内代表公司筛选

调用子 Skill：行业数据、财务数据查询、公司财务分析、估值数据、估值分析、研报查询。

输出格式：公司池映射表。

框架：先生成公司池候选池，再按龙头、弹性、防御/高股息、景气反转、风险暴露分层；五类都必须给出可验证实名代表公司。

必出字段：公司池候选来源、公司池完整性状态、公司类型、代表公司/样本、对应环节、主类型判定证据、关键验证变量、主要风险。公司池归因合并写入 `主类型判定证据`，正式公司池表不展示剔除因子，剔除因子只进入内部证据链。

空值处理：无公司样本或任一类型缺失时，正式公司池省略该类型，不编造代表公司，不用公司类型替代公司名称；内部摘要记录缺失类型。

## 14. 龙头标的筛选

调用子 Skill：行业数据、公司财务分析、估值分析、研报查询。

输出格式：龙头代表样本分析。

框架：市占率、盈利能力、现金流、估值、竞争优势、品牌/渠道/技术壁垒。

必出字段：代表公司、龙头依据、财务质量、估值溢价来源、行业地位、风险。

空值处理：市占率缺失时，用收入排名或样本份额线索替代，并标注口径。

## 15. 弹性标的筛选

调用子 Skill：行业数据、公司财务分析、估值分析、研报查询。

输出格式：弹性代表样本分析。

框架：价格敏感度、成本结构、产能、经营杠杆、利润率、现金流和估值消化能力。

必出字段：代表公司、弹性来源、敏感因素、财务验证、估值风险、触发条件。

空值处理：价格或产能缺失时，只输出有证据的弹性假设和验证指标；内部摘要记录省略项。

## 16. 防御/高股息标的筛选

调用子 Skill：公司财务分析、财务数据查询、估值数据、估值分析。

输出格式：防御/高股息代表样本分析。

框架：股息率、分红率、自由现金流、经营现金流、ROE、PB、盈利波动、资产负债率、回购。

必出字段：代表公司、股息吸引力、现金流覆盖、分红可持续性、资产负债稳健性、估值水位。

空值处理：分红或 FCF 缺失时，不输出防御属性强结论。

## 17. 行业结论到公司池映射

调用子 Skill：行业深度、行业数据、研报查询、公司财务分析、估值分析。

输出格式：公司池映射表。

框架：行业结论传导到公司池候选池、公司类型、环节受益、利润弹性、景气反转、风险暴露。

必出字段：行业结论、映射环节、公司池候选来源、公司类型、代表公司/样本、主类型判定证据、关键验证变量、主要风险、完整性状态。剔除因子仅进入内部证据链，不进入正式表格。

空值处理：行业结论本身证据不足时，不生成公司入选结论。

## 18. 行业内公司财务与经营对比

调用子 Skill：财务数据查询、公司财务分析、估值数据、估值分析。

输出格式：同行对比表。

框架：收入、利润、ROE、毛利率、净利率、经营现金流、自由现金流、资产负债率、研发、资本开支、存货/应收、分红回购和估值分位。

必出字段：公司、维度、指标、行业对比、优势、短板、风险。

空值处理：同行样本不足时，输出单公司分析并说明不可横向比较。

## 19. 公司财务分析

调用子 Skill：财务数据查询、公司财务分析。

输出格式：财务质量摘要。

框架：利润质量、现金流质量、成长持续性、资产负债稳健性、资本开支、研发投入、分红回购和股东回报。

必出字段：财务摘要、关键指标、质量判断、风险项、与行业结论关系。

空值处理：L1 财务数据不完整时只做有限分析，不编造缺失字段。

## 20. 个股估值分析

调用子 Skill：估值数据、估值分析、公司财务分析。

输出格式：估值匹配表。

框架：PE/PB/PS/PEG、历史分位、行业相对估值、成长匹配、安全边际、股息/回购、自由现金流。

必出字段：估值指标、行业相对位置、成长匹配、现金流匹配、估值风险。

空值处理：盈利为负或预测不可得时，PEG 不适用，转向 PB、现金流或股息辅助。

## 21. 重点公司深度分析

调用子 Skill：公司财务分析、财务数据查询、估值分析、估值数据、行业深度、研报查询。

输出格式：代表公司深度分析。

框架：业务与行业位置、关键证据与解读、财务质量、估值匹配、景气传导、风险暴露、后续跟踪指标。

必出字段：代表公司、行业位置、关键证据与解读、收入/利润/ROE/毛利率/净利率/现金流/负债、PE/PB/PS/PEG、风险、跟踪指标。关键证据必须说明数据含义，不能只列指标。

空值处理：缺少业务结构或公司材料时，输出财务/估值有限底稿并列待补资料。

## 22. 个股风险联动分析

调用子 Skill：行业深度、行业数据、公司财务分析、估值分析、研报查询。

输出格式：风险传导路径说明。

框架：政策、供需、价格、库存、竞争、产业链利润转移、估值分位、资金拥挤和事件风险传导到公司层。

必出字段：行业风险、传导路径、敏感公司类型、代表公司风险暴露、缓冲因素、触发指标。

空值处理：不能确认公司敏感性时，不点名公司；若风险暴露型缺少合格实名样本，正式公司池省略该类型，内部摘要记录，不用公司类型层风险替代代表公司。

## 23. 行业风险识别与预警

调用子 Skill：行业数据、行业深度、估值分析、研报查询。

输出格式：风险与跟踪指标表。

框架：基本面、政策、估值、竞争、产业链、财务和交易结构风险，统一映射为风险、触发信号、影响环节/代表公司类型、跟踪指标。

必出字段：风险、触发信号、影响环节/代表公司类型、跟踪指标。

空值处理：风险证据不足时以“潜在风险/待验证风险”表达，不写确定性风险爆发。
