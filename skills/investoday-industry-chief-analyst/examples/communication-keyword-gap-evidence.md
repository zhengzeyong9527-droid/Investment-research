# 通信行业关键词补证与普通投资者可读性示例

本示例用于验收 `1.4.0` 的输出规范：研报向量 `query` 只传关键词，完整报告第 2-7 章不输出长篇连续段落，术语集中进入 `术语速查`，正式报告不输出数据缺口话术。

## 用户输入

```text
通信行业完整分析，重点看 AI 算力、光模块、运营商云网和估值风险。
```

## 缺口识别

行业数据和行业深度分析返回后，如未取得同口径集中度、订单、库存、ASP 高频序列或海外完整口径，主流程先生成内部 `evidence_gap_pack`。

| 缺口维度 | 选用关键词 | 过滤条件示例 | 说明 |
|---|---|---|---|
| 集中度 | `CR5`、`市场份额`、`市占率` | 通信行业过滤、近 12 个月、topK=5 | 不把“通信行业CR5怎么看”写进 query |
| 订单 | `订单`、`在手订单`、`订单能见度` | 通信行业过滤、近 12 个月、topK=5 | 每个关键词单独查询 |
| 库存 | `库存`、`去库存`、`渠道库存` | 通信行业过滤、近 12 个月、topK=5 | 命中后只作为文本证据 |
| ASP/价格 | `ASP`、`均价`、`产品价格` | 通信行业过滤、近 12 个月、topK=5 | 不替代结构化价格序列 |
| 海外口径 | `海外收入`、`海外需求`、`出口` | 通信行业过滤、近 12 个月、topK=5 | 不编造海外完整口径 |

正确 query 示例：

```json
{"query":"库存"}
{"query":"订单"}
{"query":"ASP"}
{"query":"CR5"}
```

禁止 query 示例：

```json
{"query":"通信行业库存和订单怎么看"}
{"query":"请查通信行业CR5和市场份额证据"}
```

## 输出片段示例

```markdown
## 0. 首席结论卡

- 当前判断：通信行业处于成熟服务底盘与 AI 算力结构性成长并存的阶段，设备和光互联链条更需要验证订单兑现。
- 研究决策锚点：优先验证。当前证据更适合继续跟踪订单、库存、毛利率和现金流，不构成买卖或仓位建议。
- 最关键变量：云厂商 CapEx 和光模块订单能见度。

## 0A. 术语速查

| 术语 | 含义 |
|---|---|
| CapEx | 资本开支 |
| ARPU | 单用户平均收入 |
| ASP | 平均销售价格 |
| CR3/CR5/HHI | 集中度指标 |
| CPO | 共封装光学，高速光互连技术路线之一 |
| 800G/1.6T | 高速光模块传输速率规格 |
| MPO | 多芯光纤连接器，用于高密度数据中心布线 |

## 2. 行业本质、生命周期与长期空间

**结论**：通信行业整体偏成熟，但 AI 算力和光互联链条带来结构性再成长，判断强度取决于订单和利润兑现。

**关键证据**
- 行业财务/2026Q1：营收同比增长但利润承压，说明收入改善尚未完全转化为利润。
- 研报向量/近 12 个月：AI 算力、光模块、数据中心互联等片段可作为结构性需求线索。

**行业生意特征**：通信行业大致分为运营商/通信服务和通信设备两类生意。运营商依靠牌照、网络资产、用户规模和 ARPU 获得服务收入，核心看用户留存、云网业务和单位用户价值；设备商依靠技术代际、客户认证、订单交付和规模制造赚钱，收入受订单、ASP 和产能利用率影响，利润取决于毛利率、研发、折旧、回款和 CapEx。普通投资者优先验证订单、毛利率和经营现金流。

**解释与影响**：运营商服务更依赖牌照、网络资产和客户规模，通信设备更依赖技术代际、客户认证和交付能力。AI 算力需求会先影响设备和光互联订单，再传导到毛利率和现金流。

**反证**：若云厂商 CapEx 下修、订单延期或技术路线切换，长期空间判断需要降级；海外需求强度只在有同口径证据时展示。
```

```markdown
## 6. 竞争格局、护城河与利润质量

**结论**：通信设备环节竞争更偏技术代际和客户认证，服务环节更偏规模与成本效率；同口径集中度不足时不输出硬集中度评分。

**关键证据**
- 行业数据/最近报告期：通信设备毛利率、净利率（净利润占收入的比例）优于通信服务，可作为利润质量分化证据。
- 研报向量/关键词 `CR5`：如命中片段，只能标注为研报口径或样本观察。

**解释与影响**：光模块、连接器和光纤光缆等环节的护城河更多来自客户验证、产品迭代和供应链稳定性。若利润改善来自主营业务而非一次性收益，估值容错率更高。

**反证**：若新进入者压低价格、客户切换供应商或技术路线改变，既有护城河判断需要下修；CR3/CR5/HHI 只在有同口径证据时展示。
```
